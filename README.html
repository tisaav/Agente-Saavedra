🔌 3. Gateway & Conectores Sankhya

Exemplo prático de consulta utilizando a biblioteca desacoplada em Python:

Python (sankhya_client.py) 
from sankhya_client import SankhyaClient

# Inicialização automática com variáveis do .env
client = SankhyaClient()
client.authenticate()

# Consulta de parceiros com paginação nativa
parceiros = client.load_records(
    entity_name="Parceiro",
    fields=["CODPARC", "NOMEPARC", "CGC_CPF"],
    criteria="this.CODPARC > 0"
)
print(f"Total de registros carregados: {len(parceiros)}")

📊 5. Otimizações de BI e Dashboards

Correções estruturais aplicadas nos painéis do ERP Sankhya Om:

Dashboard 2302 - Licitações e Contratos Públicos

Inclusão da coluna MODALIDADE para diferenciação visual instantânea entre Pregões Eletrônicos e Termos Aditivos de Contrato via consultas às tabelas LGH_LICCAB e LGH_LICMOD.

Correção do Gadget 57: Reestruturação das somas e programações para anular duplicidades e eliminar o bug de saldos negativos em múltiplos aditivos contratuais (caso HCPA).

Dashboard 1502 - Estoque de Terceiros em Nosso Poder

Refatoração de metadados em dashboardMetadata_otimizado.xml para minimizar joins analíticos pesados e acelerar a exibição de inventário em consignação hospitalar.

⚙️ 7. Instalação e Configuração

⚠️

Segurança de Credenciais

Nunca envie o arquivo .env para o controle de versão. Todas as chaves do Sankhya e Gemini devem ser mantidas locais e restritas.

Passo 1: Criar o arquivo .env 
cp .env.example .env
Passo 2: Preencher com credenciais do Sankhya 
# API Gateway Sankhya Om
SANKHYA_CLIENT_ID=seu_client_id_aqui
SANKHYA_CLIENT_SECRET=seu_client_secret_aqui
SANKHYA_X_TOKEN=seu_x_token_aqui
SANKHYA_ENV=sandbox # ou production
