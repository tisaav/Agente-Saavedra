# Sankhya OK

O aplicativo **Sankhya OK** permite que documentos feitos pelo nosso ERP sejam liberados ou negados, ou seja, determinados usuários possuem atribuições para que algumas rotinas no sistema prossigam ou sejam barradas, por exemplo: 

Caso seja lançada uma Nota de Venda através do **Sankhya Om** e queira conceder ao cliente um percentual de desconto, cujo valor ultrapasse o limite previamente estipulado, através do aplicativo** **um liberador poderá avaliar se autorizará ou não a concessão do desconto.

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31174385101463)

 O **Sankhya OK** não oferece suporte para visualizar os itens da nota diretamente pela tela [Venda Assistida](https://ajuda.sankhya.com.br/hc/pt-br/articles/4466143201431).

Este aplicativo poderá ser instalado em aparelhos com sistema Android ou IOS. Esta aplicação está disponível para download nas lojas online [Google Play](https://play.google.com/store/apps/details?id=br.com.sankhya.labs.liberacoes) e [Apple Store](https://apps.apple.com/br/app/sankhya-ok/id1265245741), conforme o sistema operacional de seu dispositivo.

### **Requisitos para utilização do aplicativo:**

- Deve-se possuir o Módulo Financeiro ou Comercial, devidamente configurado para gerar eventos de liberação no **Sankhya Om**, como, por exemplo, desconto na nota, confirmação de nota, limite de crédito, entre outros;

- Para haver o correto funcionamento das notificações push, o **Sankhya Om** deve estar na versão 3.30 ou superiores;

- As licenças de uso para o aplicativo Sankhya OK devem ser adquiridas.

### **Configurações**

Através dessa tela, é possível visualizar os dados gerais do aplicativo, como o **"Nome do servidor"**, o **"Endereço"** e a **"Versão do aplicativo"**. Além disso, ao acionar a marcação **"Notificações"** é possível ativar o envio de notificações.

![Tela Configurações- Sankhya OK.jpg](https://ajuda.sankhya.com.br/hc/article_attachments/20024254495639)

Quando a marcação **"Tentar confirmar a nota automaticamente" **estiver acionada, ao liberar um evento, a nota será confirmada automaticamente se não houver mais solicitações pendentes. Se houver outras liberações pendentes, não será exibida nenhuma mensagem; o usuário será notificado somente quando não houver mais eventos e a nota for confirmada.

Se a marcação **"Fazer compensação automática (caso exista)"** estiver habilitada e o cliente tiver créditos a serem compensados, a compensação será realizada automaticamente, sem questionar o usuário.
