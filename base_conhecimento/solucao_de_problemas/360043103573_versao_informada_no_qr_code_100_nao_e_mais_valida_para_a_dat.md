 MENSAGEM:**

[903-Rejeição]: Versão informada no QR-Code (“100”) não é mais válida para a data de emissão.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16447734711831)

 SOLUÇÃO:**

Para correção desta mensagem, seguir os passos abaixo.

 

#### **SANKHYAW**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16447734716439)

 Acessar "**[Empresa](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045114893)"** (Caminho de acesso: *Comercial » Preferências » Empresa*)
Aba: "**NF-e/NFC-e"**
**"Usar QR Code versão 2.0"** [marcado]

 

![Sem_t_tulo3.png](https://ajuda.sankhya.com.br/hc/article_attachments/14387383119767)

 

**MGE/MITRA**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16447734716439)

Acessar "**Empresa**" (Caminho de acesso: *MGE/Mitra » Menu » Avançado » Preferencias » Empresa*)
Aba: "**NFC-e", ****"Usar QR Code versao 2.0?"** [marcado]

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16447727572119)

 Acessar : "**[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834)"** (Caminho de acesso: *Configurações » Avançado » Preferências*)

 CAUSA:**

Quando for emitida uma NFC-e (modelo 65) com data de emissão posterior a "30/09/2018" e o parâmetro "Versão" informado no** QR-Code** for **"100"**, haverá a rejeição.
