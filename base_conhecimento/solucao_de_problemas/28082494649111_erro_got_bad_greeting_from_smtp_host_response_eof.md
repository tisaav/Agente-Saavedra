SOLUÇÃO:**

Acione o responsável pelo provedor de e-mail para o fazer a liberação do IP: 140.238.189.183.

Esse IP precisa ser liberado para que a comunicação com o SankhyaW aconteça corretamente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28082466882839)

CAUSA:**

Ao testar o envio de e-mail nas telas  **"Servidor Smtp"** ou **"Contas Smtp", **sem possuir o IP acima liberado, o erro é apresentado.
