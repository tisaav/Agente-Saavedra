 SOLUÇÃO:**

Para a resolução do incidente, siga os passos abaixo: 

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16371070685975)

 Cadastre esse CNPJ informado na mensagem no Sankhya Place pelo caminho **Sankhya Place » Informações Cadastrais » Dados Cadastrais.**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16371061223703)

 Após isso, aguarde a liberação;

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16371061225751)

 Caso já tenha feito o processo, cadastre novamente e encaminhe um print para [suporte@sankhya.com.br](mailto:suporte@sankhya.com.br) para que possa ser analisado  juntamente com o setor Comercial da Sankhya.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16371061229975)

 ATENÇÃO:**

Essa correção é válida tanto para linha W como para linha  G.
