 MENSAGEM**

1054 Rejeição: Crédito Presumido para o IBS não informado [nItem: 999]

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455955351)

 SITUAÇÃO**

A nota fiscal foi emitida com item que prevê a informação de Crédito Presumido do IBS, sem que esse dado tenha sido registrado no respectivo item do documento.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137466517271)

 SOLUÇÃO**

Para solucionar esta rejeição, siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137466519191)

 Identifique qual é o item mencionado na mensagem de erro [nItem: 999].

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455969687)

 Entre na tela de cadastro de produtos ou na tela de emissão da nota fiscal.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455972375)

 Localize o campo específico para informar o Crédito Presumido do IBS para o item em questão.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137466530199)

 Consulte a legislação vigente para determinar o valor correto do Crédito Presumido a ser aplicado ao item.

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455976727)

 Após realizar as correções necessárias, tente emitir a nota fiscal novamente.

 

**

![Observação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455978007)

 OBSERVAÇÃO**

Esta validação faz parte das novas regras tributárias relacionadas ao IBS e CBS, conforme indicado no contexto sobre **"Validação da Base de cálculo dos tributos IBS e CBS"**. Assim como outras validações relacionadas aos novos tributos, esta regra pode estar sujeita a atualizações conforme novas orientações normativas sejam publicadas.

É importante manter o sistema atualizado para garantir que todas as regras de validação estejam em conformidade com a legislação vigente.

Esta rejeição está relacionada às regras de validação da SEFAZ para o novo sistema tributário brasileiro, que inclui o IBS como parte da Reforma Tributária. Caso a rejeição persista após seguir estas orientações, verifique se há atualizações disponíveis para o sistema que possam incluir novas regras de validação relacionadas ao IBS.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38137455980823)

 CAUSA**

Esta rejeição está relacionada à nova sistemática tributária do IBS, que faz parte da Reforma Tributária. O sistema da SEFAZ verifica se o campo de Crédito Presumido para o IBS foi devidamente preenchido nos itens da nota fiscal onde este crédito é aplicável.
