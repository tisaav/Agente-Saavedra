O campo 'Superior Imediato' disponível na aba Lotação do Cadastro de Funcionários é usual.

A intenção desses campos é permitir a vinculação e ser possível identificar através de relatórios quais seriam as equipes e seus gestores para o Módulo Gestão de Pessoas.

Esses campos no cadastro do funcionário só estarão disponíveis para cadastro do colaborador quando houver preenchimento das opções no menu Arquivos >> Cadastro >> Cargos >> aba Rede de Avaliadores >> botão Superiores.
