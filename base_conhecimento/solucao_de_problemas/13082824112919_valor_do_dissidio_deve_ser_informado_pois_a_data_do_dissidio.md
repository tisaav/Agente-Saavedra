 MENSAGEM:**

136 - Valor do dissidio deve ser informado pois a data do dissidio está preenchida na GRRF.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17318429074327)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17318473531159)

 Para ajuste desse erro, apague a data do campo **"Data de Homologação".** Esse campo só deve ser preenchido quando for GRRF por Dissidio.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/13420523556887)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17318429082135)

 Após deletar essa data, gere novamente o arquivo e importe na GRRF.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17318473541399)

 CAUSA:**

Ocorre quando a data de homologação é preenchida indevidamente.
