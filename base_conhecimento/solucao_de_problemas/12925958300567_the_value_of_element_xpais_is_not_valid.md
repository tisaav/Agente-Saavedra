 MENSAGEM:**

Erro durante validacao do XML do lote: cvc-pattern-valid: Value " is not facet-valid with respect to pattern I-Mill -MO.} p-yll111[!-A{1}' for type 1#AnonType_xPaisTEnderecol. cvc type.3.1.3: The value " of element 'xPais' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147654688791)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147642330647)

 Identifique qual o estado referente a nota apresentada na rejeição na tela de cadastro de estados;

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147654696983)

 Informe o código do país em questão;

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147642335383)

 Redigite alguma informação no cabeçalho da nota (por exemplo código do parceiro);

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147642337815)

 Salve;

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147654705047)

 Gere lote novamente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17147654709399)

 CAUSA:**

O erro ocorre quando o código do País informado na tela de cadastro de estado não está informado, assim não levando o conteúdo para o xml da nota.
