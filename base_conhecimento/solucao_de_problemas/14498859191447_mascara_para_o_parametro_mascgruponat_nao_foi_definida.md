 MENSAGEM:**

[CORE_E03882]: Máscara para o parâmetro **"MASCGRUPONAT"** não foi definida.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16276369152663)

CAUSA:**

Ocorre quando o parâmetro MASCGRUPONAT não está devidamente configurado.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16276377050647)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16969820691479)

 Para que seja possível a inclusão do(s) Grupo(s) de Natureza, inicialmente configure o parâmetro Máscara para o Grupo de Naturezas - MASCGRUPONAT.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14498835262487)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16969820694167)

 Após a configuração deste parâmetro é possível efetuar a configuração dos Grupos de Natureza.

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450655794199)

 Para mais informações acesse o manual da tela [Grupo de Naturezas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044598514-Grupo-de-Naturezas).
