 **MENSAGEM:**

cvc-type.3.1.3: The value '0' of element 'RegimeEspecialTributacao' is not valid.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19606377037975)

CAUSA:**

Ao emitir uma NFS-e, o erro é apresentado.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19606377032599)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19612761275287)

 Valide com a prefeitura de emissão da NFS-e ou contabilidade qual o Regime correto para ser informado na nota.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19612761284631)

 Após validar o regime, vá na tela Empresa (preferências), aba Documentos Fiscais Eletrônicos, sub-aba NFS-e, e preencha o campo 'Regime Esp. Tributação ISS (NFS-e)', ele deverá ser preenchido conforme informação passada pela prefeitura ou contabilidade.
