 MENSAGEM:**

Registro de Base de Dados
A base de dados em uso pelo sistema ainda não foi registrada.
O registro é necessário para um melhor controle e segurança das informações por parte do sistema.
Realize o registro assim que possível para evitar a indisponibilidade do sistema, que pode ocorrer a partir de 15 dias.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603132458903)

 CAUSA:**

Ao atualizar o sistema para versão 3.31 ou superior no primeiro acesso será necessário registrar a base atualizada, informando um apelido e o 'Tipo da Base'. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603127415319)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603127418903)

 Logado com o usuário SUP, clique em **"Registrar Base Agora"**:

![304.jpg](https://ajuda.sankhya.com.br/hc/article_attachments/360081090793)

**Nota**: Se após 15 dias o registro não for feito, ao acessar o sistema, apresentara a seguinte mensagem: O período de tolerância para o registro da base de dados terminou, algumas funcionalidades estarão travadas

**Observação:**

- Caso a mensagem acima não apresente a opção 'Registrar Base Agora', basta acessar 'Administração do Servidor' >> Aba 'Registro de base de dados' [Logar com usuário SUP].

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603132464023)

 Dentro de** 'Apelido para a Base'** dê um nome para a sua base. 

**Exemplo: *****SANKHYA PROD***

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603132466199)

 Em seguida defina se trata-se de uma base produção, teste ou treinamento no campo** 'Tipo da Base'**:

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603132467863)

Clique em 'Salvar', confira os dados, em seguida clique em CONCLUIR. 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603127424151)

 Realizada a configuração acima será possível acessar o sistema normalmente.
