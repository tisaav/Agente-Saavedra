 MENSAGEM:**

[LIV_E00038]: Não é possível Enviar Eventos, pois existem registros com status "Aguardando Correção" para a sequência atual. É necessário Gerar Eventos novamente.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777577232279)

 SITUAÇÃO:**

Ao tentar transmitir o REINF a mensagem é apresentada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777555055767)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777577235863)

 Verifique se para o mesmo parceiro e referência existem notas com % de INSS diferentes, fazendo com que o campo indCPRB fique diferente;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777555059863)

 Assim que identificar a nota que está com % de INSS incorreto, realize os devidos ajustes e gere os eventos novamente;

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777577240343)

 Analise todos os eventos que tiveram seu envio para RFB e analise ponto a ponto, sobre cada erro especificamente, pois a causa é genérica, ou seja, pode partir de qualquer evento.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16777555068311)

CAUSA:**

Ocorre quando algum evento apresentou erro na validação na receita federal.
