 MENSAGEM:**

[CORE_E03426] Já existe faturamento para este contrato. Não é permitido modificar o tipo de pagamento.

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19147545835927)

 SITUAÇÃO:**

Ao alterar o tipo de pagamento do contrato a mensagem é apresentada.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19147578320023)

 CAUSA:**

Tentar alterar o tipo de pagamento de um contrato que já teve faturamentos.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19147578327191)

 SOLUÇÃO:**

Ao alterar o campo **"Tipo Pagamento" **e salvar a modificação, o sistema verificará se o Contrato já foi faturado. Se estiver faturado, a mensagem abaixo será apresentada e não será possível a alteração do mesmo.

***"Já existe faturamento para este contrato. Não é permitido modificar o tipo de pagamento."***

![contratos 17-11.png](https://ajuda.sankhya.com.br/hc/article_attachments/19147545849239)

Não é possível fazer a alteração em contratos faturados. Dessa forma, crie um novo Contrato utilizando o Tipo de Pagamento desejado. Pois, visando manter a integridade das informações e cálculos já realizados até o momento, o sistema impede alteração do tipo de pagamento.

Sugerimos criar um novo contrato usando a opção duplicar o contrato alterando o tipo de pagamento, na qual o primeiro contrato você deve desativar, pois a partir de agora ira usar apenas o novo contrato com nova forma de pagamento para ser faturado para as próxima competências.
