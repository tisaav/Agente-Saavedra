# Erro ao enviar whatsapp. Não foram encontrados dados de destinatário para o respectivo título

 **MENSAGEM:**Erro ao enviar whatsapp. Não foram encontrados dados de destinatário para o respectivo título. 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36594350779671)

SOLUÇÃO:**

**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36594355982231)

 **Acesse a tela ****[''Régua de Cobrança''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044602534-R%C3%A9gua-de-Cobran%C3%A7a)** **(Financeiro » Cobrança » Régua de Cobrança).

**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36594350780695)

 **Verifique para quem o envio está configurado: **Parceiro** ou **Contato do Parceiro**.

 

![essencial FINAL (1).png](https://ajuda.sankhya.com.br/hc/article_attachments/36595651745943)

 Essa verificação é essencial, pois **determina onde o número** de celular **deve estar cadastrado**.

 

**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36595456293143)

 **Quando o **envio **for** destinado a um parceiro, **acesse a tela **''Parceiros'' **(Configurações » Cadastros » Parceiros).

**

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36595441858455)

** Na aba **''Endereço''**, certifique-se de que o campo **''Celular/Fax''** está preenchido com o número de celular do parceiro (**incluindo o DDD**). Esse preechimento é obrigatório para que o WhatsApp seja enviado corretamente.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/36594355982487)

 

**

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36595441859735)

 **Quando o **envio **for **destinado a um contato específico do parceiro,** ainda na tela **''Parceiros'' **acesse a aba** ''Contatos''**.

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36595456298263)

 Verifique quais contatos estão configurados para receber cobranças, e, para cada um deles, certifique-se de que: 

- 

O campo **“Celular”** está preenchido com um número válido.

- 

Na aba ''**Geral''**, a opção **“Responsável pela cobrança”** está habilitada.

![7 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36749154277399)

 Somente com essas informações preenchidas o sistema conseguirá realizar o envio do WhatsApp de forma correta.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/36594350781207)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36594350781463)

CAUSA:**

O erro ocorre porque a Régua de Cobrança tenta executar o evento **“Envio de WhatsApp”**, porém **não há número** de celular **cadastrado** nos campos obrigatórios do **parceiro** ou do **contato responsável pela cobrança**.

Sem essa informação, o sistema não consegue completar o envio.
