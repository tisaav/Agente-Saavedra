# Nota associada por remessa não pode ser alterada

 MENSAGEM:**

[CORE_E02721] Nota associada por remessa não pode ser alterada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578717079)

 SOLUÇÃO:**

Caso seja necessário realizar alguma correção e/ou atualização de impostos em notas de compra, que possuem "Número de Remessa", faça a configuração das opções abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105546811799)

 Acesse a Tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** *(Configurações » Avançado)*.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578718487)

 Busque pela chave **"ALTERANUREM - Alterar notas com NUREM"**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578719127)

 Altere para Ligado:

 

![ALTERANUREM.png](https://ajuda.sankhya.com.br/hc/article_attachments/12291909631639)

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105546813591)

 Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios)"**, localize o usuário que terá permissões para alterar notas ligadas pelo número de remessa.

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105546814103)

 Na aba **"Segurança",** marque a opção **"Permite alterar notas ligadas pelo número de remessa"**:

 

![permite_alterar_notas_ligdas_usu_rios.png](https://ajuda.sankhya.com.br/hc/article_attachments/14501016994583)

 

**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578720407)

 Permite alterar notas ligadas pelo número de remessa:** Esta opção permite ao usuário realizar a edição em notas ligadas por remessa. Caso seja necessário realizar alguma correção e/ou atualização de impostos em notas de compra, a utilização desta opção se faz necessária para conclusão do fechamento do mês. Para que esta opção seja apresentada na tela para utilização, ative o parâmetro Alterar notas com NUREM - ALTERANUREM.

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578720407)

 Além da marcação acima, valide se a opção **"Altera registros confirmados" **está marcada.

 

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105546814871)

 Além disso, para sucesso na edição de uma nota, vá até a TOP utilizada no lançamento da mesma, acesse a aba **"Geral"** e marque o campo **"Permitir alteração após confirmar"****. **Por fim, a própria nota deve possuir o campo **"Nro Remessa"** preenchido com um valor diferente de "0" (zero).

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16105578721431)

 CAUSA:**

Mensagem apresentada ao tentar alterar notas que possuem "Nro Remessa" preenchidos, sem que as devidas permissões tenham sido aplicadas.
