# Não foi possível buscar autorização de nenhuma das notas selecionadas

 MENSAGEM: **

[CORE_E04885]  Não foi possível buscar autorização de nenhuma das notas selecionadas. Isso geralmente acontece quando o órgão que recebeu (SEFAZ/SCAN) as notas está indisponível no momento.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603542586519)

 CAUSA: **

Este erro ocorre quando a SEFAZ de algum estado está passando por instabilidade, assim, não é possível aprovar nenhuma nota. 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603490656791)

 SOLUÇÃO**

É necessário que as emissões sejam realizadas em contingência. E caso a nota não seja aprovada mesmo após a regularização do serviço, entre em contato com o Service Desk.
