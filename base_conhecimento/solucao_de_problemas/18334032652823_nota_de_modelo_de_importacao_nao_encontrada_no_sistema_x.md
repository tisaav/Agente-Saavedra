 **MENSAGEM:**

Nota de modelo de importação não encontrada no sistema: 'X'.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18334012543383)

CAUSA:**

Ocorre quando o modelo vinculado a um destes cenários citados acima não existe no sistema.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18334043022487)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18341954512407)

 Será verificado se o parceiro fornecedor do XML é produtor rural; se for, será utilizado o modelo de importação definido para esses fornecedores (Portal de importação de XML, botão Outras Opções, Preferências para importação de NF-e, campo Modelo de importação para Produtor Rural), se não;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18341961337751)

 O sistema analisa se o parceiro fornecedor do XML possui algum modelo de importação determinado como fixo (Cadastro de Parceiros, aba Fiscal, campo Modelo para Importação de XML Compra); se possuir, este modelo será utilizado, se não;

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18341954538007)

 Será verificado se existe alguma combinação de CFOP(s) com o(s) CFOP(s) do XML (Portal de importação de XML, botão Outras Opções, Configuração de Modelo p/ Compra por CFOP); se existir, o modelo de importação encontrado na combinação será utilizado, se não;

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18341954544919)

 O sistema irá verificar se o XML possui o campo xPed preenchido para obtenção do Tipo de Operação; se houver, essa busca será feita, se não;

 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18341954550935)

 Por fim, o sistema irá verificar se existe modelo de importação de XML nas Preferências da Empresa destinatária da nota importada.

 

**Atenção:** Valide todas as informações acima utilizando o usuário SUP.
