 MENSAGEM**:

[CORE_E01212] Não há nenhum arquivo cadastrado para o relatório.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603399634967)

 CAUSA:**

Ocorre quando no relatório criado, não foi inserido o arquivo *.jrxml, que é o relatório feito em Ireport.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18603396592663)

 SOLUÇÃO:**

Solicite o responsável que acesse a tela, em que foi criado o Relatório, podendo ser (Relatório Formatado, Modelo de Impressão (Nota/Pedido), Modelos de Boleto(s)), ou algum relatório personalizado.

Na aba: 'Arquivos', deve conter o relatório, criado em formato *.jrxml (Ireport).

*

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360089687633)

*

Caso este relatório, não esteja disponível nesta aba, devera solicitar ao criador deste relatório, que faça a devida manutenção para que seja disponibilizado, este deve ser inserido  pelo botão **"Adicionar Arquivo..."**
