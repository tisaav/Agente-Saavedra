 MENSAGEM:**

cvc-datatype-valid.1.2.3: '193785' is not a valid value of union type 'tpDDDNulo'.
cvc-type.3.1.3: The value '193785' of element 'DDDPrestador' is not valid.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453908154007)

 SITUAÇÃO:**

Ao gerar lote de uma NFS-e, é apresentada a mensagem de rejeição.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453908165655)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28458195637399)

 Acesse: "[Empresas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112913)" *(Caminho de acesso: Configurações » Cadastros » Empresas)*

- Aba: '**Endereços"**

- Campo "**Telefone":** ajuste para que o DDD seja de apenas 3 números.

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453892964503)

 **CAUSA:**

Ocorre quando o número de DDD está com 4 casas decimais no cadastro da Empresa emitente da NFS-e.
