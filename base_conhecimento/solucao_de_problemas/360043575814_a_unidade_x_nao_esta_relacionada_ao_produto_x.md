# A Unidade 'X' não está relacionada ao produto 'X'

 MENSAGEM:**

[CORE_E03128] A Unidade 'X' não está relacionada ao produto 'X'. Relacione a Unidade através das configurações de Unidade padrão, Unid. Compra ou Unidade Alternativa. Caso seja uma Unid. de Compra, ela também deve estar cadastrada como Unid. Alternativa.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16171297815063)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16171297817239)

 Acesse o cadastro do respectivo produto: Tela **"Produtos"** (Configurações » Cadastros » Produtos).

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16171297820311)

 Certifique-se que a unidade mencionada na mensagem de validação encontra-se devidamente cadastrada para esse produto, conforme exemplo abaixo:

- Aba **Geral** » Campo **"Unid.Compra":**

 

![produto7.png](https://ajuda.sankhya.com.br/hc/article_attachments/14691749939479)

- Aba **Unidades Alternativas**: Cadastre a respectiva unidade corretamente. Para mais detalhes: [Clique aqui.](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Produtos-#abaunidadesalternativas)

 

![produto8.png](https://ajuda.sankhya.com.br/hc/article_attachments/14691785034135)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16171313464343)

 Realizado o cadastro da respectiva unidade corretamente, refaça a importação do XML.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16171297835927)

 CAUSA:**

Mensagem apresentada, quando a **Unidade** referenciada para o respectivo produto no XML, não encontra-se cadastrada para esse produto no sistema.
