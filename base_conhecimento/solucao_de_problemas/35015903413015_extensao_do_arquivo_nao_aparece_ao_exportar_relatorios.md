# Extensão do arquivo não aparece ao exportar relatórios

 **SITUAÇÃO**

Ao exportar relatórios ou arquivos no sistema Sankhya, alguns usuários percebem que, ao alterar o nome do arquivo e salvar, a extensão não é exibida. Essa situação pode gerar dúvidas quanto ao correto salvamento do arquivo.

 

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35015903403031)

 **SOLUÇÃO**

Para exibir corretamente as extensões ao salvar arquivos exportados pelo sistema, é necessário ajustar a **configuração do Windows**.

 

#### **No Windows 10**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412738199)

 Abra o **"Explorador de Arquivos"**.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412740247)

 Acesse a aba **"Exibir"** no menu superior.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412742295)

 Marque a opção **"Extensões de nomes de arquivos"**.
 

#### **No Windows 11**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412738199)

 Abra o **"Explorador de Arquivos"**.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412740247)

 Selecione **"Visualizar"** no menu superior.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412742295)

 Acesse o submenu **"Mostrar"**.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35472412743447)

 Ative a opção **"Extensões de nomes de arquivos"**.
 

Após a alteração, todos os arquivos serão exibidos com suas respectivas extensões, incluindo **relatórios exportados** do Sankhya.

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/35015903403927)

 **CAUSA**

O fato de a **extensão não aparecer** ao salvar arquivos não indica falha no sistema Sankhya, mas sim uma **configuração padrão do Windows** que oculta as extensões. Com o ajuste no Explorador de Arquivos, o usuário passa a visualizar corretamente as extensões, garantindo maior clareza na identificação dos arquivos salvos.
