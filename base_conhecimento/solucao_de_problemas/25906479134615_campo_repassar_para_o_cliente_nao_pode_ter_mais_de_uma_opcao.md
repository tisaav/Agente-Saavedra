 **MENSAGEM:  **

[CORE_E02113] Campo **"Repassar para o cliente" **não pode ter mais de uma opção marcada

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/25916224527511)

 SOLUÇÃO:**

Podem haver duas causas para essa mensagem do sistema:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/25906479125783)

 Marcar dois campos da seção **"Repassar para o cliente" ** conforme explicado pela mensagem e estar com o parâmetro **"****HABFORMASREPRED"** ativado.

 

![Campo Repassar para o cliente não pode ter mais de uma opção marcada 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/25917048790167)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/25906503442071)

 Trabalhar com o parâmetro HABFORMASREPRED desligado e informar algum valor no campo "**% a  Base ICMS**"

 

![Campo Repassar para o cliente não pode ter mais de uma opção marcada 2.png](https://ajuda.sankhya.com.br/hc/article_attachments/25917109695639)

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450324026007)

 Para o primeiro cenário, escolha apenas uma marcação de fato, pois na atual estrutura apenas uma é suportada pela aplicação.

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450324026007)

Para o segundo cenário, não se pode alimentar o campo citado estando com o parâmetro desabilitado.
