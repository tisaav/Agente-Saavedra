 MENSAGEM:**

[COM_E00545]: Erro interno: O registro localizado no banco não contém informações de layout.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806879192727)

 SOLUÇÃO:**

Na maioria dos casos, a mensagem é retornada quando o layout utilizado no respectivo lançamento foi corrompido. Dessa forma, será necessário seguir os passos abaixo para criação de um novo layout:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806879194903)

 Acesse a tela **"Configurador de Layout da Nota"** *(Caminho de acesso: Comercial » Configuração)*.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806847457047)

 Localize o layout utilizado atualmente para o respectivo lançamento.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806847461143)

 Verifique e/ou tire um 'print screen' das informações contidas no botão**"Visualizar TOPs"**.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806847462807)

 Verifique e/ou tire um 'print screen' da marcação **"Usar como padrão para este tipo de movimento?".**

 

Com os dados acima,** duplique o layout atual**, criando um novo layout.

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806879201943)

 Desmarque a opção Usar como padrão para este tipo de movimento? (caso ela esteja marcado) e faça essa marcação no novo layout criado.

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806879203607)

 Desvincule as TOP'S selecionadas no layout antigo e vincule as mesmas no novo layout (Botão **"Visualizar TOPs"**).

![7 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16806879205655)

 Finalizadas as configurações acima, o layout **"corrompido"** poderá ser excluído e um novo lançamento poderá ser realizado utilizando o novo layout.
