 MENSAGEM:**

[CORE_E02845] Valor acima do permitido.

[CORE_E03924] valor acima do permitido.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117523099159)

 SITUAÇÃO:**

Ao tentar efetuar a liberação de limites, ocorre a mensagem.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117515708567)

 CAUSA**:

Ocorre quando o usuário definido como liberador não possui alçada suficiente para conceder a liberação de limites do respectivo evento.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117523106455)

 SOLUÇÃO:**

Para solução será necessário acionar um superior que tenha maiores limites para liberação, para que o mesmo efetue a ação ou conceda um limite superior ao que o liberador possui atualmente.

Para ajustar as alçadas do liberador:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117515689239)

 Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios)"*** (Caminho de acesso: Configurações » Controle de Acesso » Usuários)*;

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117523111063)

 Selecione o usuário que receberá os ajustes de limites.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117515696407)

 Acione o botão **"Outras Opções"** » **"Limites para Liberação"**; 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117515699223)

 Selecione o evento que ocasionou a mensagem e edite o campo **"Valor limite"** para o desejado.

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117523123351)

Feito isso, tente realizar a liberação novamente.

 

![mceclip0__1_.png](https://ajuda.sankhya.com.br/hc/article_attachments/14607250966551)

 

**

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/12096667978263)

**

Valide com os responsáveis pela alçada de liberação na empresa, se esse valor deve ser ajustado, seguindo com a liberação após ajustes.  Caso o limite não possa ser aumentado, redefina o usuário liberador para um com alçada suficiente. 

Para redefinir o usuário liberador utilize a opção "Outras Opções..."/"Ver solicitações de liberação" dentro da Central de Notas, no PopUP Liberações solicitadas selecione um liberador pelo campo de pesquisa conforme imagem.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/16474190132503)

 

**Caso de trate de liberação de limite para notas de bonificação siga as orientações abaixo:**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117515689239)

 Para liberar a bonificação deverá ser realizado um cadastro dentro da tela **"Limites de bonificação." **Acesse: *Comercial » Avançado » Limites de Bonificação, *cadastre o usuário liberador, a data início e fim e o limite de bonificação.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16117523111063)

 Para cadastro dos limites de bonificação acesse: usuários *» outras opções » limites para liberação » evento de bonificação.*
