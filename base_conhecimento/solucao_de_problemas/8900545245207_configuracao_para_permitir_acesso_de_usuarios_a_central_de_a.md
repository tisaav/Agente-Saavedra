SOLUÇÃO:**

A Gestão de acessos para a Central de Ajuda deverá ser realizada pelo **Administrador do Place **(toda empresa possui um usuário que é definido como Admin do Place);

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597521130775)

 Administrador do Place loga em:

- Sankhya:[http://place.sankhya.com.br/](http://place.sankhya.com.br/)

- Jiva:[http://place.jiva.com.br/](http://place.sankhya.com.br/)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597510903831)

 Uma vez logado, localiza o menu 'Informações Cadastrais' >> Dados Cadastrais;

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597521134615)

 Selecione o contato ao qual deseja conceder o acesso;

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597510910871)

 Através da opção **editar **marque a opção **"Suporte"**:

 

![Configuração para permitir acesso de usuários à Central 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597496495895)

 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16597521143063)

 Clique em **"Salvar"**;

 

Após este procedimento, o usuário/Contato da empresa estará liberado para acessar a central de ajuda e realizar abertura de tickets quando necessário.
