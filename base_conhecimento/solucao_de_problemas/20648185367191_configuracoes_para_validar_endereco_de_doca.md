 SITUAÇÃO:**

Quais configurações corretas para o sistema validar um determinado endereço como doca?

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/20648185354263)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/20651048378647)

 Acesse a tela **Endereço de armazenamento** *(WMS » Cadastros » Endereço de Armazenamento) *e configure os campos abaixo da seguinte forma: 

- 
**Endereço Ativo -** Marcado
**Exclusivo para conferência -** Desmarcado
**Analítico -** Marcado

![indefinido 17-01.png](https://ajuda.sankhya.com.br/hc/article_attachments/20651048386455)

Aba Geral:

- 
**Campo Multi Produto -** Marcado
**Campo Permite fragmentar estoque -** Marcado

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/20821834661015)

- 
**Permite expedição -** Desmarcado
**Picking -** Desmarcado
**Situação do Estoque -** Disponível
