 SOLUÇÃO:**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16343684652055)

 Filtre o respectivo produto na tela 'Gerência de produtos' e analise na  aba 'Extrato' se houve movimentações  para esse produto no período analisado;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16343684656407)

 Se houve movimentações, identifique o 'Tipo de Operação' utilizada para estas movimentações;

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16343670442903)

 Acesse o cadastro dessa TOP e verifique se o campo **"Bonificação" **está marcado como 'S'. 

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16343684659223)

 CAUSA:**

Se o campo Bonificação estiver marcado = 'S', o GOL desconsidera o **valor de venda** nas análises, porém,  considera os valores de **custo **dos produtos nas análises (RENTABILIDADE).

 

**

![Observação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16343684661015)

 OBSERVAÇÃO: **

- Caso essa marcação seja indevida, será necessário ajustá-la, mas lembramos que essa marcação é histórica, desta forma, o ajuste só valerá para novos lançamentos.

- Caso seja necessário ajustar configurações anteriores, este **deverá ser realizado via banco por um profissional com conhecimento para tal**, de forma a evitar possíveis intervenções incorretas que possam afetar demais lançamentos.
