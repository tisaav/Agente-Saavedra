  MENSAGEM**:

[CORE_E04170] Empresa não optante pelo simples deve usar regime tributário 'Regime Normal'.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16337761520663)

 CAUSA:**

O erro ocorre pela falta de marcação no campo de optante pelo Simples nacional.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16337761522711)

 SOLUÇÃO:**

Para a resolução do erro, siga os passos mostrados abaixo: 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16337761524503)

 Verifique na tela** Configurações>Cadastro>Empresas > Aba Natureza**, campo **"Cód. Regime Tribut";**

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16337779749783)

 Informe o regime que a empresa se enquadra;

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15775648550679)
