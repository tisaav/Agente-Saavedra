# Não é possível instalar o add-on xxxxxx.ext

 **MENSAGEM:**

Não é possível instalar o add-on xxxxx.ext. Para instalá-lo, solicite que a empresa desenvolvedora do mesmo o publique no Sankhya Place, e então busque o add-on na loja de soluções para realizar a instalação.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30880691036055)

 SITUAÇÃO:**

Ao tentar realizar a instalação de uma extensão/add-on (EXT), via gerenciador de pacotes a mensagem mencionada é apresentada.  

 

![Screenshot_7.png](https://ajuda.sankhya.com.br/hc/article_attachments/30800490967703)

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30795766979223)

SOLUÇÃO**

Solicite ao desenvolvedor do add-on que faça publicação dele no Sankhya Place. 

Confira abaixo a documentação do processo de publicação de Add-ons no Sankhya Place:

[Obtenção de App key através da Área do Desenvolvedor](https://ajuda.sankhya.com.br/hc/pt-br/articles/26667791519255-Obten%C3%A7%C3%A3o-de-App-key-atrav%C3%A9s-da-%C3%81rea-do-Desenvolvedor)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30795766980887)

CAUSA:**

Para clientes com contratos lançados a partir de 03/2023 só é possivel realizar o processo de instalação de add-ons via Sankhya Place, não sendo permitido o uso do Gerenciador de Pacotes.
