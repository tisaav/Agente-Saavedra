 MENSAGEM**:

[CORE_E02192] Data da baixa fora do período permitido. A data limite para Lançamentos Futuros é xx/xx/xxxx.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16192806471703)

 SOLUÇÃO: **

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16192842900503)

 Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874)"** (Caminho de acesso: *Configurações »  Controle de Acesso » Usuários*):

- Botão: **"Outras Opções"**, opção **"Configurações Usuário"**

- Campo **"Dias para Lançamentos Futuros": **alterar o valor deste campo

![conf_dos_usuarios.png](https://ajuda.sankhya.com.br/hc/article_attachments/14608625374359)

![conf_dos_usuarios2.png](https://ajuda.sankhya.com.br/hc/article_attachments/14608701892759)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16192806476183)

 Após o ajuste, efetue a baixa novamente dos títulos.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16192842902935)

 CAUSA**:

Ocorre quando um usuário tenta efetuar a baixa de um título com data futura maior que o permitido em suas configurações, sendo necessário aumentar o valor neste campo.
