# Checkout não exibe campos para login/inicialização

 Ao acessar a tela de login do **Sankhya Checkout**, os campos **Usuário** e **Senha** não são exibidos, impossibilitando a inicialização do sistema. No lugar dos campos de login, é apresentado apenas um fundo ou uma imagem de publicidade.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/43729709205527)

 

![Situação](https://ajuda.sankhya.com.br/hc/article_attachments/43548952201879)

 **SITUAÇÃO**

Esse comportamento ocorre principalmente quando a **assinatura do Checkout se torna inválida**, ocasionando a criação de um novo cadastro e gerando uma duplicidade.

Como consequência, o Checkout não consegue identificar corretamente a **Base** vinculada à estação, permanecendo no processo de **Identificando Base**.

![Solução](https://ajuda.sankhya.com.br/hc/article_attachments/43548952204055)

 **SOLUÇÃO**

##### Para tratar essa situação, é necessário acionar o **Service Desk**, que realizará os ajustes necessários para regularizar a licença e restabelecer o acesso ao **Sankhya Checkout**.
