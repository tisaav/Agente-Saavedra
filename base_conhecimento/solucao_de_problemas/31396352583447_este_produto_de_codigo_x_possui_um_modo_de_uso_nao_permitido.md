 **MENSAGEM:**

[CORE_E07834] Este produto de código: X possui um modo de uso não permitido. Verifique a configuração 'Usado como' em seu cadastro.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31396327003927)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31396327006743)

 Localize o produto na tela de **"Produtos"** *(Configurações » Cadastros » Produtos » Produtos);* 

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31396327010327)

 Na aba **"Geral"** busque pelo campo **"Usado Como";**

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31396352559767)

 Verifique se o produto esta marcado como **"Consumo", **essa classificação é destinada a produtos utilizados internamente pela empresa e não para comercialização. Caso o produto seja de venda será necessário alterar essa classificação para que ele seja elegível para venda no PDV Web.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31396327015959)

 CAUSA**:

Produtos cujo campo Usado como está configurado com a opção **"Consumo"** não são permitidos para venda no **PDV Web**. Essa restrição é implementada para garantir que apenas produtos destinados à revenda, venda direta ou prestação de serviços sejam comercializados através do PDV Web.
