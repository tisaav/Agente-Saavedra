Para se realizar a baixa de uma receita como perda, siga os passos abaixo: 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16490590626455)

 Entre na tela: **Configurações >> Cadastros >> Bancários >> Contas**, e inclua uma conta bancaria de controle;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16490598817431)

 implante o saldo para essa conta com data retroativa de 01 ano a data de seu cadastro em Outras Opções / Implanta Saldo Bancário, fazer a baixa desses títulos usando essa conta;

 

**

![Observação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16490598826647)

 OBSERVAÇÃO:**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450923661463)

 Essa conta deverá ser desconsiderada para geração de relatórios e análise gerenciais que levam em consideração saldo bancário;

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450923661463)

 Ideal que seja criada uma regra, através do módulo Central de Certificações, para que permita a utilização dessa conta por pessoas chave na empresa, evitando baixas indevidas de títulos para a conta que na verdade deveria entrar em contas custo que os saldos são considerados para análises gerenciais.

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450923661463)

 A TOP utilizada na baixa deve ser diferente da TOP utilizada em uma baixa convencional por conta das configurações contábeis.
