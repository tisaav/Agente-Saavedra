 SITUAÇÃO:**

Ao realizar impressão de holerite o arquivo é impresso de forma desconfigurada. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292319820567)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292290812311)

 Abra o Navegador 'Internet Explorer'.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292319846935)

 Acesse a 'Barra de Menus' >> Arquivo >> **Configurar Página**:

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292290830871)

 IMPORTANTE: **

Caso não localize a 'Barra de Menu' reportada acima, clique com o botão direito na tela (Internet Explorer) e marque a opção 'Barra de Menus';

 

**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292319859863)

 **Em** "Configurar Página"** serão apresentadas as opções que permitem ao usuário definir a margem que as impressões feitas irão respeitar, a partir dessas margens o usuário pode definir qual o melhor tamanho para utilizar.

O modelo de holerite padrão, disponível no site [Place Sankhya](http://place.sankhya.com.br/), de forma geral funciona bem com as configurações acima, mas em alguns casos pode ser necessário algum ajuste a mais. Em caso de modelos personalizados o padrão acima pode não atender, sendo necessário que os devidos ajustes sejam realizados.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292319865623)

 CAUSA:**

Ao realizar impressão de holerite o arquivo é impresso de forma desconfigurada, em sua maioria, essa situação é causada por uma configuração de página incoerente com o esperado.
