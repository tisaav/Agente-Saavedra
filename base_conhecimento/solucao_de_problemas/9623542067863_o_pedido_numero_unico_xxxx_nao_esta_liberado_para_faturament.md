 MENSAGEM:**

[CORE_E05083] O pedido número único: XXXX não está liberado para faturamento. Existem itens que não foram enviados para Separação no WMS.

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19357253915543)

 SITUAÇÃO:**

Ao tentar faturar um pedido de venda a mensagem é apresentada.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19357259180311)

 CAUSA:**

Quando algum item do pedido esta pendente e não foi enviado para o WMS.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19357253937815)

 SOLUÇÃO:**

Verifique no pedido se todos os itens foram enviados para o WMS, caso tenham sido enviados parcialmente, realize o envio da quantidade restante do pedido.

Caso não seja necessário o envio da quantidade restante para a expedição, realize o corte no pedido.
