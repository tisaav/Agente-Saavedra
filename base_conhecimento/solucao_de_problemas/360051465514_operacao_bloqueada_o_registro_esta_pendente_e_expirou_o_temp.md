 MENSAGEM**: 

[CORE_E05566] Operação Bloqueada: O registro está pendente e expirou o tempo de carência. Avise o administrador para que o mesmo ajuste o registro da base na tela de Administração do servidor.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15936000443927)

 CAUSA:**

Após atualização de versão, caso a base esteja registrada com nome/domínio antigo é preciso atualizar os dados.

**

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15936000444951)

 SOLUÇÃO:**

![1](https://ajuda.sankhya.com.br/hc/article_attachments/15935971816727)

 Logado com o usuário SUP, acessar a tela **Administração do Servidor**, aba **Registro de Base de Dados. **

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15935971817879)

 Dentro de** 'Apelido para a Base'** dê um nome para a sua base. 

Exemplo: ***SDETESTE12***

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15935963936151)

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15936000448023)

 Em seguida defina se trata-se de uma base produção, teste ou treinamento no campo** 'Tipo da Base'**:

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15935988527895)

![4](https://ajuda.sankhya.com.br/hc/article_attachments/15936000452631)

 Clique em 'Salvar', confira os dados, em seguida clique em CONCLUIR. 

![5](https://ajuda.sankhya.com.br/hc/article_attachments/15935971825559)

 Realizada a configuração acima será possível acessar o sistema normalmente.
