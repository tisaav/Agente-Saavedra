 MENSAGEM**:

[COM_E00025] Não foi encontrado produto com o código de barras: 'X'.

[COM_E00026] Não foi encontrado produto cadastrado com o código: XXXXX e Cód. barras: XXXXX.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161970671639)

 SITUAÇÃO**:

Ao bipar ou digitar o código de barras dos produtos para realizar uma conferência, pela tela 'Fila de Conferência' ocorre a mensagem.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969271063)

 CAUSA**:

Ocorre quando o sistema não consegue identificar esse código de acordo com os cadastros atuais de produtos.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161970672663)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161970674583)

 Certifique-se de que o código de barras inserido na Fila de Conferência está correto. 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969267479)

 Caso o código esteja correto, verifique na tela de **"[Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos-)"** *(Caminho de acesso: Configurações » Cadastros » Produtos)* se o código de barras digitado corresponde ao registrado/cadastrado nos campos abaixo:

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969269015)

 Referência

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969269015)

 Cód. Barras (aba Código de Barras)

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969269015)

 Código de Barras (aba Unidade Alternativa)

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969269015)

Cód. de Barras (aba Estoque)

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161969270295)

 Caso o cadastro esteja incorreto, realize os devidos ajustes e retorne ao processo de conferência.
