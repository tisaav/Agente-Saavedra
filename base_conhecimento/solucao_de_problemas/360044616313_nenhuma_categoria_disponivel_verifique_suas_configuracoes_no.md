**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18588247335447)

 CAUSA:**

Mensagem apresentada ao acessar determinada rotina do sistema, quando houver apenas a liberação de "Consulta", e não for realizada a liberação de acesso para a "Rotina". 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18588264090647)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18588247348247)

 Configurações » Controle de Acesso » Acessos

Portal de Vendas:

- 
**Comercial** >> **ROTINAS** >> **Portal de vendas** >> Pedidos

- Comercial >> ROTINAS >> Portal de vendas >> Notas

- Comercial >> ROTINAS >> Portal de vendas >> Devolução

- Portal de Compras:

- 
**Comercial** >> **ROTINAS** >> **Portal de Compras** >> Pedidos

- Comercial >> ROTINAS >> Portal de Compras >> Notas

- Comercial >> ROTINAS >> Portal de Compras >> Devolução

- Portal de Mov.Internas:

- 
**Comercial** >> **ROTINAS** >>**Portal de Mov.Internas** >> Devoluções de Requisição

- Comercial >> ROTINAS >> Portal de Mov.Internas >> Pedidos de Requisição

- Comercial >> ROTINAS >> Portal de Mov.Internas >> Requisições

- Comercial >> ROTINAS >> Portal de Mov.Internas >> Transferências

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18588264101655)

 Realizadas as liberações acima, conforme necessidade do usuário, faça um novo teste de acesso

**Importante:**

O usuário liberador deverá estar atento ao seguinte: em “Comercial->Consulta ->" estará sendo concedido acesso apenas a tela. Para definir acesso para as rotinas existentes em cada Portal, os acessos acima deverão ser liberados.
