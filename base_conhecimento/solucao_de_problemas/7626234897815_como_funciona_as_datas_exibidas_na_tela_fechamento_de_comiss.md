SOLUÇÃO:**

A apresentação das informações na tela de **"Fechamento ****de Comissão"**, leva em conta a **forma **de pagamento de comissão para os **vendedores**.

Se a comissão é paga por regime de **competência,** é o mesmo que Pagamento de Comissão por data de Negociação configurado no cadastro dos vendedores conforme é exibido abaixo:*
*

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14680802292119)

As informações apresentadas na tela (campos datas) assumem o valor do campo DTNEG da nota.

Se a comissão é paga por **regime de caixa**, é o mesmo que Pagamento de Comissão por data de Baixa configurado no cadastro dos vendedores,

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14680835365271)

 

As informações apresentadas na tela (campos datas) correspondem as informações dos títulos do **financeiro**, logo este é o comportamento do sistema.
