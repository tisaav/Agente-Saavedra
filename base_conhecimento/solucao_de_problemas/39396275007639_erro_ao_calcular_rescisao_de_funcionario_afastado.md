# Erro ao Calcular Rescisão de Funcionário Afastado

 **MENSAGEM**

O sistema apresenta uma mensagem de atenção informando que o funcionário está afastado, impedindo o cálculo da rescisão.

 

![Situação](https://ajuda.sankhya.com.br/hc/article_attachments/39396289369111)

 **SITUAÇÃO**

Ao tentar calcular a rescisão de um funcionário, o sistema bloqueia o processo exibindo uma mensagem informando que o colaborador está com situação de **"Afastamento"**. Isso ocorre quando há registros de afastamento ativos no cadastro do funcionário que impedem o processamento da rescisão.

 

![Solução](https://ajuda.sankhya.com.br/hc/article_attachments/39396274989079)

 **SOLUÇÃO**

Para resolver o problema e permitir o cálculo da rescisão, siga os passos abaixo:

![1](https://ajuda.sankhya.com.br/hc/article_attachments/39396289370391)

 Acesse a tela **"Configuração Funcionários"** (Pessoal+ >> Cadastros >> Configuração Funcionários) e localize o funcionário desejado.

![2](https://ajuda.sankhya.com.br/hc/article_attachments/39396274990615)

 Verifique o campo **"Situação"** na aba Afastamento identifiquei se esta afastado.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/40923300856599)

![3](https://ajuda.sankhya.com.br/hc/article_attachments/39396274991383)

 Acesse a tela **"Ocorrência"** (Pessoal+ » Rotinas Folha » Ocorrências) e inclua a data fim no afastamento. 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/40923304300439)

![4](https://ajuda.sankhya.com.br/hc/article_attachments/39396274991767)

 Após o ajuste, verifique se a situação do funcionário foi atualizada para **"Atividade Normal"** no cadastro.

![5](https://ajuda.sankhya.com.br/hc/article_attachments/39396274993047)

 Retorne à tela de cálculo de rescisão e processe novamente o cálculo para o funcionário.
 

![Causa](https://ajuda.sankhya.com.br/hc/article_attachments/39396274993559)

 **CAUSA**

O erro ocorre porque o sistema identifica que o funcionário possui um **"Registro de afastamento ativo"** em seu cadastro.
