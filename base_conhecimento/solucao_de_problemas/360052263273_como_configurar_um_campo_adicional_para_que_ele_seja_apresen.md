# Como configurar um campo adicional para que ele seja apresentado no cadastro de Funcionários

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849881675543)

 Acesse MGE Configuração (ou Jiva Conf)  e selecione a opção Utilitários >> Manutenção de campos adicionais;

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849853987351)

 Busque a tabela TFPFUN [Tabela de Funcionários];

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849881683479)

 Clique em adicionar (+); 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849881683991)

 Informe o nome do campo, descrição, tipo e demais configurações de acordo com os critérios desejados para esse campo.

**Exemplo:** Ao criar um campo CNS que receberá "números", o campo Tipo deverá ser configurado = Inteiro.

![configuraçoes 06-11.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849881688087)

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849854007831)

 Feito isso o campo será apresentado na aba 'Campos Adicionais' do cadastro de Funcionários:

![funcionarios 06-11.png](https://ajuda.sankhya.com.br/hc/article_attachments/18849854009367)

 

**Importante:**

As orientações acima são básicas referente tal cadastro, existindo dúvidas e/ou necessidade de validações, um consultor de sua Franquia deverá ser acionado.
