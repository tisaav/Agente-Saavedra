 MENSAGEM:**

Limite de data para reabertura de OS excedido.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310381533079)

 SITUAÇÃO:**

Mensagem apresentada ao tentar reabrir Ordens de Serviço.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310381534999)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17378748239511)

 Ajuste o parâmetro abaixo conforme necessidade atual de limite de dias para retroação de lançamento/reabertura de O.S, para isso:

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310396074903)

 Acesse a tela de **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** (*Caminho de acesso: Configurações » Avançado » Preferências*).

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310396074903)

 Busque a chave** "SERVDIASRETRO - Limite de dias para lançamentos retroativos de sub-OS"** preencha devidamente.

 

![SERVDIASRETRO.png](https://ajuda.sankhya.com.br/hc/article_attachments/14394630079895)

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310381546903)

 **CAUSA:**

Mensagem apresentada ao reabrir Ordem de serviço com data de retroação maior que o definido no parâmetro SERVDIASRETRO.
