# NF-e complementar possui mais de uma NF referenciada

 MENSAGEM:**

[255 - Rejeição]: NF-e complementar possui mais de uma NF referenciada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482955088791)

 SOLUÇÃO:**

A SEFAZ não aceitará uma NF-e complementar com mais de um documento referenciado. Emita uma NF-e complementar para cada documento no qual se deseja referenciar.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482978608279)

 CAUSA:**

Quando for emitida uma NF-e Complementar com mais de um documento (NF-e, NFC-e ou NF) referenciado, será retornada a rejeição.
