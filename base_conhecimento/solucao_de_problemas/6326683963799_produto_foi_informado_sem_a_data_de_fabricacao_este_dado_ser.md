 MENSAGEM:**

[CORE_E01580] Produto foi informado sem a data de fabricação. Este dado será gerado no grupo de rastreamento do XML da NF-e conforme legislação.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16457145280407)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16457128886679)

 Caso o produto esteja configurado para ter o rastreamento de lote, conforme configurações detalhadas abaixo, **será obrigatório informar a data de fabricação** e também a data de validade para transmitir essas informações para Sefaz. Essa informação se torna obrigatória independente das movimentações realizada na TOP (gerar estoque ou não).

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450943942807)

 Tela **"Produtos"** *(Caminho de acesso: Configurações » Cadastros » Produtos » Produtos)*

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450943942807)

 Aba **"Geral"**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450943942807)

 Campo: **"Tem rastro de lote"**

Verifique se a configuração acima está correta, caso contrário realize os devidos ajustes e refaça o faturamento.

**Observação:** Caso o rastreio seja necessário, mantenha a marcação citada no item 1 e informe a data de fabricação no lançamento.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16457128896919)

CAUSA:**

Caso o produto esteja configurado para ter o rastreamento e não for informada data de fabricação, a mensagem será apresentada.
