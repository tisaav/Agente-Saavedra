 MENSAGEM:**

Erro no Serviço "Consulta do Status do Serviço".

Erros encontrados:

Não foi possível extrair o código da UF do xml.

erro.handshake=true

erro.interno.uf.invalida=true

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453823322903)

 SITUAÇÃO:**

No sistema MGE/Mitra, ao tentar transmitir uma NF-e, o sistema retorna a mensagem.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453839969175)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453839974167)

 Acesse *MGE/Mitra » Arquivos » Cadastros » Endereços »UF's*

- Campo '**Código IBGE': **informe um valor válido

- Para consultar, recomendamos o site do IBGE, ou solicitar informações com o contador da empresa.
[https://www.ibge.gov.br/](https://www.ibge.gov.br/)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453839977751)

 Após o ajuste, transmita novamente a NF-e.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453823337367)

 CAUSA:**

Ocorre quando no cadastro da UF não foi informado um valor válido para o campo Código IBGE.
