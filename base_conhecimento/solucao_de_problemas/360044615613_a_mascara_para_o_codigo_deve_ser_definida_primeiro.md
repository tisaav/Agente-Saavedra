 MENSAGEM**:

A máscara para o código deve ser definida primeiro.

 

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310672735383)

 **SOLUÇÃO:**

Para correção siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310672742039)

 Acesse a tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834-Prefer%C3%AAncias)"** *(Caminho de acesso: Configurações » Avançado » Preferências)*:

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310657759767)

 Pesquise pelo parâmetro: **"FPMASCDEP - Máscara para Departamentos"**.

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310657759767)

 Insira no campo Texto o formato esperado para cadastro de Departamento. 

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310657759767)

 Exemplo de Máscara para departamento: 99\.99\.99\.99;0

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310657766551)

 Após o ajuste, salve a alteração no parâmetro e volte a efetuar o lançamento.

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310657770391)

 **CAUSA**:

No **MGEImobilizado** é necessário o correto cadastro da Máscara para departamento, que deve ser cadastrado no parâmetro FPMASCDEP.
