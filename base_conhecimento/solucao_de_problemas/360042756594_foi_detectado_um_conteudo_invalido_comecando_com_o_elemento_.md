# Foi detectado um conteúdo inválido começando com o elemento 'CFOP'

 MENSAGEM:**

Validação básica Sefaz: Erros encontrados:

cvc-complex-type.2.4.a: Foi detectado um conteúdo inválido começando com o elemento 'CFOP'. Era esperado um dos '{"http://www.portalfiscal.inf.br/nfe":NCM}'.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452563037975)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452547810583)

 Para todos os itens da nota, o campo "**NCM"** no Cadastro de Produtos deve estar devidamente preenchido.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14394468926359)

 

**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452547812375)

 **Preenchida essa informação para todos os itens, redigite o cabeçalho da nota e gere um novo lote.

 

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452547815191)

 CAUSA:**

Ocorre quando ao gerar lote de NF-e e for constatado nessa, algum item sem a informação de 'NCM' configurada.
