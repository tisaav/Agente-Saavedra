# The value '' of element 'descANP' is not valid

**

![Mensagem FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443885437847)

 ****MENSAGEM:**

cvc-minLength-valid: Value '' with length = '0' is not facet-valid with respect to minLength '2' for type '#AnonType_descANPcombproddetinfNFeTNFe'. cvc-type.3.1.3: The value '' of element '**descANP**' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443885440663)

 SOLUÇÃO:**
Para correção deste erro, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443885441943)

 Acesse a tela Preferências *(Caminho de acesso à tela: Configurações » Avançado)*

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910159639)

 Habilite o parâmetro '**COMBUSTIVEL' - Distribuidor de combustível?**

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443885447575)

 Vá até a tela de "**[Cadastro de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113)":**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910159639)

 Selecione o produto a ser ajustado, e na aba** "Combustível"** preencha os campos abaixo conforme necessidade para o respectivo item:

**

![Marcador 3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910161687)

"Descrição ANP"**

**

![Marcador 3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910161687)

"Valor de Partida GLP (sem ICMS)"**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910159639)

Para os demais campos citados abaixo, atente-se ao fato de que a soma dos três deve totalizar 0 ou 100 :

**

![Marcador 3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910161687)

"Percentual de mistura GLP";**

**

![Marcador 3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910161687)

"Percentual de mistura de Gás natural nacional";**

**

![Marcador 3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910161687)

"Percentual de mistura de Gás natural importado".**

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910162455)

 IMPORTANTE:**

Os dados acima **não** são de responsabilidade do Service Desk, são informações relacionadas ao produto e de responsabilidade do cliente.

Essa validação será apenas um alerta, ou seja, o sistema permitirá que o usuário salve esse registro.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443910162967)

 CAUSA:**

Na emissão de uma NF-e na versão 4.0, caso a nota possua produtos Combustíveis e o produto estiver com o cadastro incompleto na aba: Combustível, ocorrerá a Rejeição.
