# Veja como realizar o cancelamento de NFC-e através do Sankhya Checkout

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845544343)

 Logue no Sankhya Checkout com usuário que possui liberação de acesso para Cancelamento:

 

![478.png](https://ajuda.sankhya.com.br/hc/article_attachments/360095604753)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857703831)

 Acesse a opção de **"Menu"** (lado esquerdo do topo  da tela):

 

![2.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845553943)

​

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857712407)

 Selecione a opção **'Gerenciamento NFC-e':**

 

![3.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845564183)

​

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857717911)

 Será apresentado a Tela de Gerenciamento NFC-e:

 

![4.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845570199)

​

 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845573783)

 Assim que a tela for apresentada, clique no botão atualizar e selecione o registro a ser cancelado.

 

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857728919)

 Pressione a tecla **CTRL + (D)** ou clique no botão **"Editar registro", **no topo da tela lado direito, em seguida, será apresentado a tela 'Detalhes da NFC-e 2.0'

 

![7 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857732759)

 Clique no botão **"Cancelar":**

 

![5.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857734935)

​

 

![8 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857738647)

 Informe o motivo:

 

![Imagem](/attachments/token/Gyg338olPjC4OQC0M0SHWU4Wb/?name=inline-545679605.png)

​

 

![9 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857740567)

 Pressione a tecla <F12> ou clique no botão '(F12) OK';

- Após processar, o sistema retornará para a tela de **"Gerenciamento NFC-e"** e poderá constatar que a NFC-e foi devidamente cancelada;

 

![6.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845602583)

​

 

![10 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940857747351)

 Para encerrar pressione '(ESC ) Fechar' ou clique no botão  '(ESC ) Fechar';

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16940845608855)

 IMPORTANTE:**

- A opção de cancelamento da nota vai estar presente na tela somente se a venda não foi integrada com o ERP;

- Se ela já foi integrada, o cancelamento tem que ser feito pelo ERP.
