 **MENSAGEM**:

O serviço xxxx lançado não possui componente cadastrado. Favor definir algum componente para este serviço.

 

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16309373617047)

 **SOLUÇÃO:**

Acesse a tela **"Serviço"*** (Caminho de acesso: Configurações » Cadastros » Produtos » Serviço)* e vincule no campo **"Componentes de Serviço"**, na aba **"Geral"**, um componente de serviço. 

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14330916202391)

 

Caso não haja um componente de serviço cadastrado, realize o cadastro do mesmo na tela Componentes de Serviço. 

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14331231403159)

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16309388124055)

 **CAUSA:**

O erro ocorre quando não possui o componente de serviço vinculado no campo Componentes de Serviço na tela Serviço.
