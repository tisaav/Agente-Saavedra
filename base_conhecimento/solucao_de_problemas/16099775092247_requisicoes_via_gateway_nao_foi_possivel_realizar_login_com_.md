 MENSAGEM:**

Não foi possível realizar login com ERP.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16099797364375)

 SITUAÇÃO:**

Erro ocorre ao realizar a requisição via Gateway. No caso impossibilitando que a integração realize a comunicação.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16099813173783)

 SOLUÇÃO**

De acordo com as possíveis causas da mensagem, listamos os procedimentos para correções:

**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16099791513111)

 **Acesse a tela "**Configurações Gateway**" e verifique se possui um usuário Sankhya informado no campo "**Cod. Usuário**", para a aplicação desejada.

 

**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16099797367703)

 **Esse usuário Sankhya deve possuir vinculo com **Sankhya ID**. O e-mail informado no "**Username**" na requisição deve estar vinculado neste usuário Sankhya.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/16107762556567)

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/16107791509527)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16099813175831)

 CAUSA:**

Ocorre pelo fato do USERNAME que está sendo usado na requisição ter vínculo com um usuário Sankhya e esse usuário vinculado ao SANKHYA ID. Esse usuário também deve ser informando no campo Cod. Usuário da tela Configurações Gateway, para a aplicação desejada.
