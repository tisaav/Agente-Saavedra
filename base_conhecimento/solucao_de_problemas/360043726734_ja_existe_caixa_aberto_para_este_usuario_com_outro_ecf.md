 SITUAÇÃO:**

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364294360087)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364325950359)

 Em sua maioria, esse cenário ocorre quando já existe Caixa aberto para esse usuário na retaguarda (Sankhya W/Mitra).

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364325953175)

 Para solucionar, acesse essa retaguarda (Sankhya W/Mitra) pelo mesmo usuário que está tentando abrir o Caixa.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364325955095)

 Feito o acesso clique em **sair** e verifique se é apresentada a opção de **"Fechar o Caixa"**:

*"Caixa aberto em XX/YY/ZZZZ com a conta: X - .*

*Deseja fechar o caixa?"*

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364325956887)

 Em caso positivo, clique em **sim **para que o mesmo seja fechado.

 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364325957911)

 Executado esse processo teste uma nova abertura de Caixa no Fast Service.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16364294374551)

 IMPORTANTE:**

Para evitar que essa situação seja recorrente, instrua os usuários Caixa da empresa a sempre abri-lo primeiramente pelo FAST e, só após essa abertura, realizar o acesso pelo usuário caixa na retaguarda.
