 MENSAGEM:**

[PROD_E00238] Unidade de medida 'XX' não cadastrada para a matéria-prima XXX.

[PROD_E00423] Unidade de medida 'XX' não cadastrada para a matéria-prima XXX.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18860949689495)

 SITUAÇÃO:**

Ao informar a unidade de uma matéria prima a mensagem é apresentada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18860902916631)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18860902925079)

 Verifique se a MP possui a unidade de medida devidamente configurada no cadastro dos **produtos ***(Configurações » Cadastros » Produtos » Produtos)*, na aba geral:

 

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/9858614230551)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18860902931095)

 Para utilizar uma unidade alternativa, é necessário configurar uma nova unidade para o produto. Para fazer isso, acesse a aba "Unidade Alternativa" na tela de Cadastro do Produto.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/9858611778967)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18860902933143)

CAUSA:**

Ocorre quando a unidade informada na matéria prima não está devidamente configurada.
