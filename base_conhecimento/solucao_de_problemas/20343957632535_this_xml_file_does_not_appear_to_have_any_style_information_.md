![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/20343986838039)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/21017715416471)

 Acesse a tela **Preferências** (*Configurações » Avançado*), verifique o parâmetro **"Código Usuário Convidado - CODUSUVISITA"** qual o usuário convidado está vinculado ao envio do e-mail;

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/20343957625239)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/21017717735575)

 Após identificar, acesse a tela **Usuários** *(Configurações » Controle de Acesso » Usuários) » *aba **Identificação ***»* campo - **Data limite de acesso**, verifique se data registrada não está em um período anterior as datas enviadas no e-mail. 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/20343986839575)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/20343986840343)

CAUSA:**

Pode ocorrer devido a falta de configuração de usuário no parâmetro: **"Código Usuário Convidado - CODUSUVISITA"** ou por divergência na data limite de acesso do usuário vinculado.
