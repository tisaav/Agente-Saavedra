 **MENSAGEM:**

[WMS_E01003] Não foi selecionada uma linha que está relacionada a uma tarefa do WMS

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31092671841175)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36747824770839)

 Acesse a tela ****[''Gerência do WMS''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045120453-Ger%C3%AAncia-do-WMS)** **(WMS » Gerência » Gerência do WMS).

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36747824771863)

 Verifique se existe tarefas geradas em Itens do Recebimento.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36747824772503)

 Acesse a tela ****[''Tarefa de Recebimento''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045120453-Ger%C3%AAncia-do-WMS)** **(WMS » Rotinas » Tarefas de Recebimento) e gere a tarefa de armazenagem para o recebimento.

- 

Uma vez que a tarefa existe, é possível atribuir um executante normalmente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31092671843351)

CAUSA:**

A mensagem aparece porque** **não foi gerada uma tarefa de armazenagem para o recebimento.

Sem essa tarefa, não há número de tarefa criado, impossibilitando a vinculação de um executante na tela ''Gerência do WMS''.

Portanto, a condição essencial para atribuir um operador é primeiro criar a tarefa de armazenagem.
