# COD_MUN Tamanho do Campo Inválido - Erro de Estrutura EFD ICMS IPI - Registro 0150

O **Registro 0150** da EFD ICMS IPI é responsável por cadastrar **participantes** (fornecedores, clientes, entre outros) e um dos campos exigidos nesse registro é o **código do município (COD_MUN)**, que deve ser preenchido de acordo com o código do IBGE.

SOLUÇÃO: ** 

 

Na tela** "Cidades" ***(Caminho: Configurações » Cadastros » Endereços)*, configure o Campo ** "Mun. domicílio fiscal"**

 

![COD_MUN Tamanho do Campo Inválido - Erro de Estrutura 2.png](https://ajuda.sankhya.com.br/hc/article_attachments/27060020967703)

 

Esse código é o código do Município que será encontrado no site do IBGE: [https://www.ibge.gov.br/explica/codigos-dos-municipios.php](https://www.ibge.gov.br/explica/codigos-dos-municipios.php)
