 MENSAGEM:**

[CORE_E03459]: Já existe um usuário cadastrado com este nome!

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16859697387799)

SOLUÇÃO:**

Não é permitido cadastrar um usuário com mesmo nome mais de uma vez no sistema. Sempre que isso ocorrer a mensagem será apresentada.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16859681115927)

CAUSA:**

Ocorre quando se tenta cadastrar um usuário utilizando um nome que já existe no cadastro.
