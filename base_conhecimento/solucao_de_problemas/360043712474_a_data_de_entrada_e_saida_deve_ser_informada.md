 MENSAGEM:**

[CORE_E05556]  A data de entrada e saída deve ser informada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16199196695447)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16199203175959)

 Para clientes que não trabalham com o módulo 'Orçamentário' (Controle Orçamentário e Metas) o parâmetro abaixo deverá estar desligado:

- 
Tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834)"** (*Configurações » Avançado » Preferências*)
Chave **"UTIORCDTENTSAI - Utiliza orçamento por data de entrada e saída"**

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14503356368535)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16199196702359)

 Desligado o parâmetro, prossiga com o lançamento.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17855350289943)

 IMPORTANTE:**

Caso trabalhe com o módulo Controle Orçamentário e Metas e a respectiva rotina não possua o campo "**Dt.Entrada/Saída"** para preenchimento, recomendamos a atualização do sistema para versão 3.31b143 ou superior. Se após atualizações o problema persistir, acione o Service Desk Sankhya para análises.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16199203184791)

 CAUSA:**

Mensagem apresentada ao salvar determinado lançamento financeiro no sistema, quando não informado valor para o campo Dt.Entrada/Saída e parâmetro UTIORCDTENTSAI: Ligado.
