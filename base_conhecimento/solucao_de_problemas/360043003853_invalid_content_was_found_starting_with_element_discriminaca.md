 MENSAGEM:**

Invalid content was found starting with element 'Discriminação'. One of '{"http://www.abrasf.org.br/nfse.xsd":CodigoTributacaoMunicipio}' is expected

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16455305920279)

 SOLUÇÃO:**

Para correção, siga os passos abaixo.

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16455305923607)

 Acesse a tela: "**[Serviço"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110553)** : (Caminho de Acesso: *Configurações » Cadastros » Produtos » Serviço*)

- 
Aba: "**Impostos"**

- 
Campo: "**Cód. Trib. Município NFS-e":** preencha o campo com um valor válido fornecido pela Prefeitura (buscar orientações com o Contador).

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16455322445847)

 Acesse a tela: "****[Alíquotas de ISS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601014)": (Caminho de Acesso:* Comercial » Arquivo » Cadastros » Alíquotas » Alíquotas de ISS*)

- 
Campo: "**Cód. trib. Município"**: preencha o campo com um valor válido fornecido pela Prefeitura (buscar orientações com o Contador).

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16455305928727)

 CAUSA:**

Ao gerar uma NFS-e onde as informações de ‘Tributação do Município' não estão devidamente preenchidas, ocorrerá a rejeição.
