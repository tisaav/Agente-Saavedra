 MENSAGEM:**

[IMOB_E00042] Para usar projeto no lançamento de depreciação, é necessário informar um projeto no departamento do bem.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36223230302487)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36335241557655)

 Acesse a tela ****[''Departamentos''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044610254-Departamentos) (Pessoal+ » Recrutamento e Seleção » Cadastros) vinculado ao bem.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36335241558935)

 No campo **''Projeto'' **informe o projeto correto para o processamento da rotina.

 

![image (24).png](https://ajuda.sankhya.com.br/hc/article_attachments/36335241559447)

 

![image (23).png](https://ajuda.sankhya.com.br/hc/article_attachments/36335241559831)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36335241560599)

 Após salvar o projeto no departamento, execute novamente a geração do lote de depreciação.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36223242315543)

 CAUSA:**

A mensagem ocorre porque a empresa está configurada para utilizar **Projetos** na depreciação e a rotina também foi executada com essa opção ativa.

Entretanto, **o Departamento vinculado ao bem não possui um Projeto informado**, impedindo o processamento.
