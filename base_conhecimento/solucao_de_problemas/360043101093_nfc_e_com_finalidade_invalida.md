 MENSAGEM:**

[715-Rejeição]: NFC-e com finalidade inválida.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443931185943)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28458167989399)

 Acesse o Cadastro de ****["Tipos de Operação - TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114)**"**, campo: "**Tipo de Emissão"** = **Normal**

 

![Sem_t_tulo2.png](https://ajuda.sankhya.com.br/hc/article_attachments/14359282964247)

 

Operações acobertadas por NFC-e sempre devem ter finalidade de emissão normal. Para correção se faz necessário modificar o campo para 1 na TOP utilizada pela nota. Caso a finalidade de emissão da NF-e seja diferente de Normal, opte pela emissão de uma NF-e (modelo 55).

Feita a correção, reenvie a NFC-e.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443931187607)

 CAUSA:**

Caso seja emitida uma NFC-e (modelo 65), onde o tipo de emissão é diferente de Normal, será apresentada a Rejeição.
