# TOPs não são exibidas para vinculação no Layout de Pedidos

 **SITUAÇÃO:**

Ao criar um novo layout de pedidos (Pedido Web), é possível vincular as TOPs que deverão utilizá-lo. No entanto, em alguns casos, determinadas TOPs não são exibidas na lista de seleção.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/33019581347095)

SOLUÇÃO:**

Quando esta situação ocorre é necessário analisar as seguintes possibilidades:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/33183165460119)

 Certifique que a TOP  a ser utilizada possui  o mesmo** TIPO DE MOVIMENTO**  definido  no novo  LAYOUT.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/33183175677335)

 Verifique se a TOP possui alguma restrição por usuário, pois, caso exista, ela será exibida apenas conforme as regras definidas na configuração de restrição.

 

![restrições.png](https://ajuda.sankhya.com.br/hc/article_attachments/33183165467031)

 

Para maiores informações sobre restrições e exceções acesse o manual [Tipos de Operação - TOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044603114-Tipos-de-Opera%C3%A7%C3%A3o-TOP#restricoeseexcecoes).
