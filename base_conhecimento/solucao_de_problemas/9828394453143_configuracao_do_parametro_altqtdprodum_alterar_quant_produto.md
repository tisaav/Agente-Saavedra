# Configuração do parâmetro: ALTQTDPRODUM - Alterar quant. produto para um após adicionar ao carrinho.

> **Módulo:** Solucao de Problemas | **Subseção:** Vendas  
> **Fonte Oficial:** [https://ajuda.sankhya.com.br/hc/pt-br/articles/9828394453143-Configura%C3%A7%C3%A3o-do-par%C3%A2metro-ALTQTDPRODUM-Alterar-quant-produto-para-um-ap%C3%B3s-adicionar-ao-carrinho](https://ajuda.sankhya.com.br/hc/pt-br/articles/9828394453143-Configura%C3%A7%C3%A3o-do-par%C3%A2metro-ALTQTDPRODUM-Alterar-quant-produto-para-um-ap%C3%B3s-adicionar-ao-carrinho)

Este parâmetro permite alterar a quantidade do produto selecionado, inserido no carrinho pela tela de consulta de produtos. Com o parâmetro **"Alterar quant. produto para um após adicionar ao carrinho? -ALTQTDPRODUM"** ligado, ao selecionar o item, a quantidade digitada para incluir no carrinho é alterada para 1, se desligado ele mantém a quantidade informada anteriormente. Para fazer essa alteração de quantidade siga as orientações:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18950345191959)

 Acesse a tela **Preferências*** (Caminho de acesso à tela: Configurações » Avançado » Preferências),* informe a chave do parâmetro **"Alterar quant. produto para um após adicionar ao carrinho? -ALTQTDPRODUM"**** **e coloque a opção 'Ligado'.

![PARÂMETRO 09-11.png](https://ajuda.sankhya.com.br/hc/article_attachments/18950369824151)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18950369832983)

 Em seguida, acesse a tela **Consulta de produtos*** (Caminho de acesso à tela: Comercial » Consulta » Consulta de Produtos)* e adicione um produto através da lupa.

![consulta  09-11.png](https://ajuda.sankhya.com.br/hc/article_attachments/18950369837975)
