 MENSAGEM:**

[CORE_E01861] Tipo de negociação não autorizado para este cliente! Ver Grupo autorização. Parceiro: X Tipo Negociação: Y

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811505559)

 SITUAÇÃO:**

Ao tentar efetuar o lançamento de um documento, ocorre a mensagem.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162796756375)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811510295)

 Acesse a tela **"[Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494-Cadastro-de-Parceiros)"** *(Caminho de acesso: Configurações » Cadastros)* e na aba **"Crédito"** verifique:

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811511703)

 Campo **"Grupo de Autorização": **Verifique quais são os grupos configurados

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162796760087)

 Acesse a tela **"[Tipos de Negociação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109173-Tipos-de-Negocia%C3%A7%C3%A3o)"** *(Caminho de acesso: Comercial » Arquivo » Cadastros)* e na aba **"Características"** verifique:

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811511703)

 Campo **"****Grupo de Autorização"**: Verifique o Grupo de Autorização do Tipo de Negociação

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811514391)

 Após os ajustes, redigite parceiro no documento para conseguir confirmar o documento.

 

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28458156407831)

 EXEMPLO:**

Tipo de Negociação X, o Grupo de Autorização é **A **e o Grupo de Autorização do Parceiro Y é **A, B, C**, significa que é possível usar o Tipo de Negociação X com o parceiro Y.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16162811518231)

 CAUSA:**

Ocorre quando o Grupo de Autorização do Parceiro é diferente do Grupo de Autorização do Tipo de Negociação.

**A Regra é:** Vários Grupos de Autorização no Parceiro e um único grupo de Autorização para cada Tipo de Negociação. Então, caso precise autorizar diferentes tipos de negociação, informe vários grupos de autorização no Parceiro sempre separado por vírgula.
