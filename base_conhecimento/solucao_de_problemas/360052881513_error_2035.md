 MENSAGEM**:

Error #2035.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19033777772567)

 CAUSA:**

Incidente causado por falha no carregamento da pagina devido a cache do navegador.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585483696407)

 SOLUÇÃO:**

Geralmente essa mensagem é apresentada no carregamento de telas (nenhuma especifica), junto a barra de carregamento. Nesse caso, recomendamos:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585451439639)

 Limpe o cache do navegador (todo período);

- Com o navegador aberto, pressione as teclas CT+ SHIFT + DELETE

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/360083796814)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585483709335)

 Feito isso, acesse o sistema novamente e teste o acesso.

**Observação:**

Uma solução paliativa, que dispensa a limpeza de cache, é acessar o sistema pelo navegador em "Janela Anônima".
