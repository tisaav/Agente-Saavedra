 MENSAGEM:**

[CORE_E05688]: Pedido nro único: XXXXX não está liberado para faturamento. Separação: XXXXX. Conferência no checkout ainda não foi enviada para Doca.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16643568911511)

 SOLUÇÃO:**

Acesse a tela de expedição, selecione a separação e verifique o campo **"enviar p/ doca"**, estando este campo como **não**, acesse no coletor a opção conferência por pedido.

Feito isso, acesse a opção enviar para doca, selecione a separação e envie ela para a doca.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16643541361303)

 CAUSA:**

Esta mensagem é apresentada pois a mercadoria ainda não foi encaminhada para a doca para ser faturada.
