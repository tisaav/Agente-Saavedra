 MENSAGEM:**

[ECOM_E00076]  Não existem notas NF-e/NFC-e para gerar o arquivo.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16449140722839)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16449140729879)

 Revise todos os filtros inseridos na tela:

1.1 Tipo Arquivo
1.2 Empresa
1.3 Parceiro
1.4 Entra/Saída
1.5 Período
1.6 TOP

Certifique se **existem informações nos respectivos filtros que estão impedindo a geração do arquivo necessário**. Após ajustes, refaça a geração.

 

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/6326121244823)

**Importante:**

O filtro trará apenas "Notas Aprovadas" ou "Canceladas". Qualquer outro tipo de status de NF-e ou NFS-e não serão filtrados.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16449140731671)

CAUSA:**

Para downloads de filtros que não retornam arquivos apresenta-se uma mensagem ao usuário que não foi localizado o XML de notas para o filtro informado.
