# Para faturar vários pedidos em que algum dos pedidos usa conferência marcada com 'Detalhar lote pela conferência' é obrigatório marcar a opção  'Uma nota para cada'

 MENSAGEM:**

[CORE_E04629] Para faturar vários pedidos em que algum dos pedidos usa conferência marcada com 'Detalhar lote pela conferencia' é obrigatório marcar a opção 'Uma nota para cada'.

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19550506699671)

 SITUAÇÃO:**

Ao selecionar dois pedidos para faturar em uma única nota a mensagem é apresentada.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19550476294807)

 CAUSA:**

Ocorre ao marcar o campo "Detalhar lote pela conferência" e selecionar mais de um pedido para uma única nota.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/19550476297623)

 SOLUÇÃO:**

Verifique a tela **Configuração de Conferência*** (Caminho de acesso à tela: Comercial » Configuração » Configuração de Conferência)*, na aba geral, a configuração do campo "Detalhar lote pela conferência".

Se esta opção estiver MARCADA, o sistema obriga que ao faturar dois pedidos agrupando em uma mesma nota, a marcação "Uma nota para cada" seja marcada. Nesse sentido, se a conferência possuir esse detalhamento, não é possível agrupar em uma única nota.

![configuração de conferrencia 04-12.png](https://ajuda.sankhya.com.br/hc/article_attachments/19550476307991)

Caso seja obrigado esse detalhamento no seu processo, emita uma nota para cada pedido. Caso não seja necessário, desmarque a opção e, assim, trabalhe com o agrupamento em uma única nota.
