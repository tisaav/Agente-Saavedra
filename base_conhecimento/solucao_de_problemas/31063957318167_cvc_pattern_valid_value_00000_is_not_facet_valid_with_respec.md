 MENSAGEM:**

cvc-pattern-valid: Value '00000* is not facet-valid with respect to pattern rd(6)' for type TS-regANS: cvce-type.3.1.3: The value /00000* of element 'regANS is not valid. 

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31284209034263)

 SITUAÇÃO:**

Ao tentar enviar o evento S1210 no eSocial.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31284209037463)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31284166125591)

 Acesse a tela **"Plano de Saúde"*** (Pessoal+ » Cadastros » Plano de Saúde)* e verifique o campo** "Reg. Ag. Nac. Saúde"**, se estiver com quantidade maior que 6 dígitos, faça a devida correção;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31284209040535)

 Após a correção, faça uma nova geração dos eventos do eSocial.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/31284166128151)

 CAUSA:**

Registro na Agência Nacional de Saúde - ANS precisa conter um número de registro válido. Sendo que o tamanho máximo permitido é de 6 dígitos.
