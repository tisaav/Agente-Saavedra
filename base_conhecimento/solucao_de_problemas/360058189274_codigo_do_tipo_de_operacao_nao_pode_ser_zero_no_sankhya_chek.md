 MENSAGEM**:

Ao acessar a tela *Configurações » Sankhya Checkout » Administração de Checkout* existem registros com a mensagem abaixo:

**Código do tipo de operação não pode ser Zero.**

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16271983926679)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16271983927319)

 Acesse o cadastro de TOP em: *Comercial » Arquivo » Cadastros » Tipos de Operação - TOP*:

- Verifique se existe uma TOP devidamente cadastrada, ativo para ser usado para Sangria

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16271996483223)

 Acesse o **"Preferências"** do Checkout, aba: **"Integração"**:

- Opção **"Código da TOP para sangria": **insira o código da TOP
