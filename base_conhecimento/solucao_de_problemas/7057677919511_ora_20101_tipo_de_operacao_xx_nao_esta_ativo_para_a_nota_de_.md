  MENSAGEM**:

ORA-20101: Tipo de Operação xx não está ativo para a nota de Nro Único:xxxx.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16480667004439)

 SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16480673891863)

 Verifique se o campo **"****Ativo"** está desmarcado para a TOP que está utilizando no lançamento, na tela: Comercial >> Arquivo >> Cadastros >> Tipos de Operação - TOP;

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16480673899031)

 Caso esteja desmarcado, analise se a TOP foi descontinuada e tem uma substituta ou desmarcada indevidamente, nesse caso ative-a e repita o lançamento.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16480667026455)

CAUSA:**

Ocorre quando o campo **ativo **está desmarcado para a TOP que está utilizando no lançamento na tela: Comercial >> Arquivo >> Cadastros >> Tipos de Operação - TOP.
