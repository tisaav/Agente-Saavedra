 MENSAGEM:**

[CORE_E05712]: Já existe um Usuário de Rede cadastrado com este nome!

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16583139069079)

 CAUSA:**

Ocorre ao tentar cadastrar mais de um usuário com o mesmo nome.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16583123913239)

 SOLUÇÃO:**

Não é possível cadastrar mais de um usuário com o mesmo nome, sendo assim, informe um sobrenome para diferenciar os usuários.
