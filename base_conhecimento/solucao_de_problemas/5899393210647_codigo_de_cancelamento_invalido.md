 MENSAGEM:**

[E168]: Código de cancelamento inválido. Possível solução: Informe corretamente o código de cancelamento.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16361350746007)

SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16361370377111)

 Crie novos código de cancelamento da prefeitura.
