# The value ' ' of element 'nItemPed' is not valid

 MENSAGEM:**

cvc-pattern-valid: Value ' ' is not facet-valid with respect to pattern '[0-9]{1,6}' for type #AnonType_nItemPedproddetinfNFeTNFe'. cvc-type.3.1.3: The value ' ' of element 'nItemPed' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443679291543)

SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443704200215)

 Verifique a informação inserida no campo **'Seq. no Pedido'** para todos os itens da nota:

 

![Sem_t_tulo.png](https://ajuda.sankhya.com.br/hc/article_attachments/14357857732503)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443679293335)

 Ajuste a informação para um "número" sequencial válida.  Caso não trabalhe com o envio da tag <nItemPed> no XML, limpe essa informação. Realizado o ajuste devido, redigite o cabeçalho da nota e gere um novo lote da respectiva nota. 

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16443679294615)

 IMPORTANTE:**

Caso não visualize esse campo, adicione o mesmo através do '**Configurador de Layout da nota**' , para mais detalhes: [Como inserir um campo no layout da nota?](https://ajuda.sankhya.com.br/hc/pt-br/articles/360043058973)
