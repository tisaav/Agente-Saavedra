 MENSAGEM:**

[CORE_E00100]: Os arquivos de log não foram encontrados. Inicie o monitoramento antes de baixar os arquivos com os logs.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16913177303447)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16913177305623)

 O monitor de consultas só passa a operar após apertar o botão 'Play'. Depois de ligá-lo, acesse o local onde ocorre o erro e faça o processo até o mesmo acontecer. 

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15136459849495)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16913177308951)

 Assim que o erro aparecer na tela, não feche! Volte no monitor de consulta, aperte o botão 'Stop' e depois 'Baixar arquivos de log'.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15136445001623)

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16913206148247)

 Dessa forma funcionará normalmente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16913177316247)

 CAUSA:**

Ocorre ao não executar a rotina corretamente.
