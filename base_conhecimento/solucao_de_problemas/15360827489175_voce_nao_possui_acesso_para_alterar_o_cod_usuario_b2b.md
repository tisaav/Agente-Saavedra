 MENSAGEM:**

[CORE_E05253] Você não possui acesso para alterar o 'Cód. Usuário B2B'.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16583179802519)

 CAUSA: **

Ocorre quando o usuário não tem acesso a alterar o usuário B2B.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16583179801111)

 SOLUÇÃO:**

Na tela **"Acessos**", procure pela tela de **"Parceiros"** e ative o acesso ao **"Manutenção usuário B2B".**
