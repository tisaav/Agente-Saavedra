 SOLUÇÃO:**

Para correção, siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16413951679383)

 Acesse a tela **''Parceiros'' **(Configurações » Cadastros » Parceiros).

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16413991212567)

 Na aba** ''Crédito''**, verifique o campo **''Motivo de Bloqueio''**.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14681227538839)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38640131900823)

 Considere verificar com a equipe Financeira para que seja apagada a mensagem de motivo do cadastro do parceiro, para que seja possível confirmar a Nota Fiscal.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/38640131905431)

 Após os ajustes, fature novamente a nota fiscal.

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16413936806295)

 **CAUSA:**

Ocorre quando o parâmetro "**EXIBMOTBLOQ"** esta ativo, o parâmetro "**VALPEDATRASO"** desativado, a opção **"Bloquear venda a prazo"** desmarcado no parceiro e tenha informação no campo **"Motivo de Bloqueio"** do cadastro do Parceiro.
