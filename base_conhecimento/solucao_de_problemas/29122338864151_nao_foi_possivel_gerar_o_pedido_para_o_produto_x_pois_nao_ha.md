# Não foi possível gerar o pedido para o produto X, pois não há disponibilidade de estoque para o mesmo na empresa de origem

 MENSAGEM:**

Não foi possível gerar o pedido para o produto X, pois não há disponibilidade de estoque para o mesmo na empresa de origem.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122338849175)

 SITUAÇÃO:**

Na tela **["Ressuprimento Automático de Filiais"](https://ajuda.sankhya.com.br/hc/pt-br/articles/6194716592663-Ressuprimento-Autom%C3%A1tico-de-Filiais),** aba **["Histórico"](https://ajuda.sankhya.com.br/hc/pt-br/articles/6194716592663-Ressuprimento-Autom%C3%A1tico-de-Filiais#abahist%C3%B3rico)**, ao acionar o botão **"Ver detalhes"** é exibido o pop-up **"Detalhes do processamento do Ressuprimento"**. Na aba** "Produtos não atendidos"** desse pop-up, ao selecionar o produto X, aparece a seguinte mensagem na parte inferior:

Não foi possível gerar o pedido para o produto X, pois não há disponibilidade de estoque para o mesmo na empresa de origem.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122294080407)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122338853655)

  Verifique quantidade em estoque:

- Acesse a aba ****["Estoque"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos#abaestoque) na tela de ****["Produtos"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos).

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122294086167)

 Analise os pedidos pendentes no ****["Portal de Vendas"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612654-Portal-de-Vendas):

- Acesse o Portal de Vendas.

- Verifique se há pedidos com status de pendentes que contém o produto entre os itens.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122294088343)

 Processe ou cancele os pedidos pendentes:

- Processe ou cancele pedidos com status de pendentes que têm o produto adicionado entre os itens.

- Isso garantirá que o ressuprimento automático de filiais desconsidere o pedido ao calcular o estoque total disponível do produto.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/29122294091671)

 Crie filtros personalizados:

- Utilize o Portal de Vendas para criar filtros personalizados para pedidos pendentes.

- Utilize o filtro** "Itens"** na tela para filtrar o produto específico.
