 MENSAGEM:**

[CORE_E05132]  Não foram encontradas impressões pendentes.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15819707728663)

 CAUSA: **

Ocorre quando alguma configuração não está compatível com a emissão de nota e/ou boletos.

**

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15819707731095)

 SOLUÇÃO:**

- Verificar se a TOP está configurada para fazer a impressão.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15819651206551)

- Se o tipo de título está configurado para **NÃO** realizar impressão do boleto.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15819715342615)

- Se o tipo de negociação está configurada para imprimir boleto/duplicata.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15819692208663)

 

- Se a conta bancária está configurada para emitir boletos.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15819693647127)
