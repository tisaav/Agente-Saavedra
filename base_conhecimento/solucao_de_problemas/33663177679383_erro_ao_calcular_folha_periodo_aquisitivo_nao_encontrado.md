### **Identificando o problema no período aquisitivo**

 

![Mensagem](https://ajuda.sankhya.com.br/hc/article_attachments/33955288552599)

**MENSAGEM**
A tabela de férias (TFPFER) encontra-se vazia para o funcionário. Esta é uma configuração inválida, dado que na admissão é realizada a inserção do primeiro período aquisitivo do funcionário.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/33663184576023)

 

![Causa](https://ajuda.sankhya.com.br/hc/article_attachments/33955288561175)

**CAUSA**
 

A principal causa para essa situação é a ausência de período aquisitivo vigente para o funcionário.

### 

**Ajustando período aquisitivo manualmente**

Para corrigir o período aquisitivo de um funcionário, siga os passos abaixo:
 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/33955272333719)

 Acesse a tela **"Requisições"** (Pessoal >> Rotinas Folha >> Requisições).

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/33955288558359)

 Clique no ícone **"Férias"**, localize o funcionário desejado e selecione-o.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/33955272347415)

 Clique  ícone **"Aquisitivo"** para consultar se há período aquisitivo em aberto.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/33955288560791)

  Caso não exista período aquisitivo, realize a criação do período aquisitivo para o funcionário. 

![Design sem nome.gif](https://ajuda.sankhya.com.br/hc/article_attachments/33663267619991)
