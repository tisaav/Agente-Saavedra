 MENSAGEM:**

[CORE_E01905]  Só é possível criar campo calculado com expressão SQL.

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586142092183)

 SITUAÇÃO:**

Ao criar um campo calculado a mensagem é apresentada.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586172048663)

 CAUSA:**

Inserir expressão SQL na criação do campo adicional e não selecionar o campo calculado.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586142106135)

 SOLUÇÃO:**

Sempre que inserir uma expressão SQL na criação do campo adicional é necessário marcar o campo calculado.
