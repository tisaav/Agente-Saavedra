Para adicionar e remover organizações do usuário no Sankhya ID, siga os passos abaixo: 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16474406924823)

 Entre no menu lateral **"Minhas permissões"** do Sankhya ID (login.sankhya.com.br); 

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16474386345751)

 O  usuário poderá visualizar todas as permissões que possui na organização e até mesmo retirá-la caso seja necessário. Para excluir, clique no botão desvincular permissões.

 

![Como adicionar e remover organizações do usuário no Sankhya ID 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16474485286167)

 

**Observação: **o vínculo de uma nova organização é realizado pelo administrador do **Place (place.sankhya.com.br) -> Informações cadastrais -> Dados cadastrais -> + Novo contato. **Ao incluir um novo contato o Place, irá integrar as informações da empresa ao cadastro do usuário no Sankhya ID e demais portais. 

 

![Como adicionar e remover organizações do usuário no Sankhya ID 2.png](https://ajuda.sankhya.com.br/hc/article_attachments/16474485287191)
