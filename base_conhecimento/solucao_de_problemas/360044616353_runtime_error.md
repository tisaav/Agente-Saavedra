Runtime error XXX at XXXXXXX.

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586347451927)

 **CAUSA:**

Ocorre quando nas estações  não consta a impressora Generic Text instalada e definida como padrão.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586330978455)

 SOLUÇÃO:**

Para correção seguir os passos abaixo:

Proceda, com apoio de seu T.I. a instalação e definição da impressora Generic como padrão.

Abaixo seguem orientações, baseadas em uma estação Windows 10 Pro, apenas para apoiá-los de uma forma "geral", caso existam dúvidas nesse processo, ou para a sua máquina as orientações abaixo não existam, busque por apoio de um técnico na empresa. 

- Através do Menu Iniciar busque por 'Painel de Controle'

-  Selecione a opção 'Dispositivos e Impressoras'

- Caso seja apresentada a Impressora Generic Text clique com botão direito : "Definir impressora como padrão".

- Caso essa não tenha sido instalada siga as orientações abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586347471255)

 Adicione uma impressora >> A impressora que eu quero não está na lista:

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586330986135)

 Escolha "Adicionar uma impressora local ou de rede usando configurações manuais" >> Avançar

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586347480983)

 Use porta existente:

**

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586347489303)

 **Defina a opção Generic >> Generic/ Text Only

**

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586330998167)

 **Use o driver já instalado >> Avançar.

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586331007383)

 Não compartilhar essa impressora

**

![7 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18586331014167)

 **Concluir >> Após essa conclusão clique com botão direito >> Definir essa impressora como padrão.
