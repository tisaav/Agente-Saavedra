# Para um Processo Produtivo de Desmonte o campo Processo de Produção Relacionado deve possuir um valor

 **MENSAGEM:**

[PROD_E00485] Para um Processo Produtivo de Desmonte o campo Processo de Produção Relacionado deve possuir um valor.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30939067068567)

SOLUÇÃO:**

Acesse a tela **"Processo Produtivo - Nova" ***(Produção » Cadastros » Processo Produtivo - Nova)*, dentro do processo marcado como Desmonte, vincule no campo **"Processo de Produção Relacionado"** o código do processo da produção do PA.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30939039076375)

CAUSA:**

Ocorre ao tentar salvar um processo de desmonte sem definir um processo de produção relacionado do PA.
