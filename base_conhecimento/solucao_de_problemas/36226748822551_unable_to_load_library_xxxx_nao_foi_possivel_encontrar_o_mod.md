 **MENSAGEM:**

Unable to load library 'XXXX'. Não foi possível encontrar o módulo especificado

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36226748814743)

SOLUÇÃO:**

**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36309505973015)

 **Na tela inicial do ****[''Web Connection''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044596394-Sankhya-Web-Connection), verifique qual versão ela se encontra instalada. Caso esteja utilizando a versão 64 bits, esta deve ser **desinstalada**.

**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36314227411095)

 **Certifique-se de baixar e instalar a** versão 32 bits** do **Web Connection externo**.

- 

O sistema deve operar sempre com** **o **Web Connection externo** (externo). Portanto, **desconsidere** o modo **Web Connection embarcado (interno)**. 

**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36314227413783)

 **Após** **instalar o Web Connection 32 bits, reinicie o computador.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36314227416599)

 Em seguida, clique e execute o **Web Connection externo (32 bits)****.**

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36314213005463)

 No sistema, acesse a tela** ******[''Cadastro de Equipamentos Fiscais - ECF/SAT/MFE''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110533-Cadastro-de-Equipamentos-Fiscais-ECF-SAT-MFE)** **(Comercial » Arquivo » Cadastros » Cadastro de Equipamentos Fiscais - ECF/SAT/MFE ) e realize o teste do módulo fiscal. O mesmo deverá retornar a mensagem **“SAT em operação” **confirmando o funcionamento correto.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36226748815383)

CAUSA:**

O erro ocorre quando o **Web Connection** instalado **não é compatível com o módulo fiscal (SAT/MFE)**.
