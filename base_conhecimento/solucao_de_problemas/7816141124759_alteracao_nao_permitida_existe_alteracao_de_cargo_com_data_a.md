 MENSAGEM**:

Alteração não permitida. Existe alteração de Cargo, com data anterior a data de admissão informada. Para alterar a data de admissão corrija os dados.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541234247063)

 SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541194016535)

 Na tela: Pessoal+ » Rotinas Folha » Ocorrências, filtre o funcionário;

 

![Alteração não permitida. Existe alteração de Cargo, com 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541194021143)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541194022551)

 Localize o lançamento da alteração do cargo e exclua;

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541194026135)

 Depois, faça a alteração desejada;

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16541194028183)

CAUSA:**

Na tela de ocorrência do funcionário, possui um lançamento de alteração de cargo com data anterior a data de admissão que está tentando inserir.
