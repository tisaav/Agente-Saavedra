 MENSAGEM:**

[CORE_E02284] Content is not allowed in prolog.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414143457047)

 SITUAÇÃO:**

Mensagem apresentada ao realizar importação de XML através do sistema. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414131049367)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414143458711)

 Na pasta em que salvou o XML a ser importado, clique com botão direito sobre o mesmo e selecione a opção 'Abrir com', defina o 'Internet Explorer'.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414131052055)

 Ao abrir o arquivo no Internet Explorer avalie se o mesmo está no formato de XML, conforme exemplo abaixo:

 

![64.png](https://ajuda.sankhya.com.br/hc/article_attachments/360059618213)

 

**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414131053847)

 **Caso não esteja no formato esperado, contacte o seu fornecedor, explique a situação e solicite um novo arquivo. Se o arquivo já estiver no formato correto, siga com as próximas orientações.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414143463703)

 Verifique o artigo: https://ajuda.jiva.com.br/article/14338-como-identificar-caracteres-invalidos-em-um-xml.

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414143464215)

 Localizado o caractere inválido, ajuste o mesmo diretamente no XML enviado (Bloco de Notas). Após os ajustes, efetue a importação novamente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16414143465111)

 CAUSA:**

Ao realizar a importação de XML no sistema, a mensagem poderá ser apresentada nas situações a seguir:

- XML a ser importado não está no formato esperado.

- XML a ser importado possui caracteres inválidos.
