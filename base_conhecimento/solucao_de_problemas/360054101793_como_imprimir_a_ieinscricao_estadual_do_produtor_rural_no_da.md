# Como imprimir a I.E(Inscrição Estadual) do Produtor Rural no DANFE

> **Módulo:** Solucao de Problemas | **Subseção:** Configurações

Para que seja impressa a I.E (Inscrição Estadual) do parceiro (Pessoa Física) na NF-e (DANFE), é necessário que a Classificação de ICMS do Parceiro esteja = 'PRODUTOR RURAL'

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18942206560791)

 Acesse O cadastro de **Parceiro** (*Configurações » Cadastros » Parceiros*)
Aba: Identificação
Campo: Insc. Estadual / Identidade: = [Informar I.E válida, sem traços, hifens e com zeros a esquerda se houver]
Aba: **Fiscal**
Campo: **Classificação ICMS** = [PRODUTOR RURAL]

 

![Como imprimir a I.E(Inscrição Estadual) do Produtor Rural no DANFE 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/25245738811415)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18942180845079)

 Ao realizar uma nova emissão, utilizando a Classificação de ICMS correta, o campo 'Inscrição Estadual' será devidamente impresso;
