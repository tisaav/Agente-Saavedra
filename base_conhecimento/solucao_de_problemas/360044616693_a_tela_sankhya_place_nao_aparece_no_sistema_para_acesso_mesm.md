# A tela Sankhya Place não aparece no sistema para acesso, mesmo como usuario SUP

 SITUAÇÃO:**

Ao acessar o sistema o botão de acesso ao Sankhya Place não esta sendo apresentado no Menu principal do sistema, mesmo com o usuário SUP.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18606508467607)

 CAUSA:**

Configuração do parâmetro** Ocultar logos Sankhya das telas? - OCULTALOGOSNK** inadequada.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18606508477207)

 SOLUÇÃO****:**

Configurações » Avançado » Preferências

Pesquise pelo parâmetro pela chave: **Ocultar logos Sankhya das telas? - OCULTALOGOSNK.**

Desligue o parâmetro, salve a alteração.

Deslogue e logue novamente no sistema.

O Sankhya Place apresentara no Menu Principal do Sistema

 

As configurações de permissões e acessos no Sankhya Place, fica condicionado ao cadastro dos usuários do sistema.
