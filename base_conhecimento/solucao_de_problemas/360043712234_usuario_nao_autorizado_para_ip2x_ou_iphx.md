 MENSAGEM:**

[CORE_E03517]: Usuário não autorizado para IP2X ou IPHX.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17175367765911)

 SOLUÇÃO:**

Não existem tratativas relacionadas ao sistema para essa mensagem. Trata-se de um retorno da SERASA, e ocorrerá quando o usuário não tem permissão para emitir informações por integrações. Essa mensagem não é retornada pelo sistema Sankhya.

Nesse caso, entre em contato com a SERASA para alinhamentos e solicitação das devidas liberações.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17175399864215)

 CAUSA:**

A mensagem é apresentada em função do usuário utilizado não possuir liberações junto ao Serasa para consultas integradas.
