# Para que haja um Retorno do Afastamento é necessário que o trabalhador esteja afastado

 MENSAGEM:**

[Erro 188] - Para que haja um Retorno do Afastamento é necessário que o trabalhador esteja afastado. Ações Sugeridas: - Verificar se o afastamento foi cadastrado. - Verificar a data de retorno do afastamento. A data de retorno do afastamento deve ser, sempre, maior ou igual ao afastamento.

 

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16421771449239)

 **SITUAÇÃO:**

Ao tentar enviar o S-2230 a mensagem é apresentada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16421771450647)

 SOLUÇÃO:**

Para correção, acesse a tela **"Registros de Ocorrências"** (Caminho de acesso: Lançamentos » Histórico do Funcionário » Registros de Ocorrências) clique com o botão direito do mouse sobre a ocorrência desejada e deixe desmarcada a opção **"Forçar Data Final no eSocial".**

 

![registro_de_ocorrencia.png](https://ajuda.sankhya.com.br/hc/article_attachments/14392211426071)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16421812269975)

 CAUSA:
**Este erro ocorre quando é selecionada indevidamente a opção de **"Forçar Data Final no eSocial"**, no registro da ocorrência. E com isso o afastamento S-2230 é gerado apenas com data fim.
