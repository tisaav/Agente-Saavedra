 MENSAGEM:**

cvc-pattern-valid: Value '0' is not facet-valid with respect to pattern '[0-9]{7}' for type 'tpCidade'.
cvc-type.3.1.3: The value '0' of element 'Cidade' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482544667415)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482544672279)

 Acessar: *Configurações » Cadastros » Endereços » Cidades*

- Aba: **"Geral"**

- Campo **"Mun. domicílio fiscal": **Informe o valor válido

![The_value__0__of_element__Cidade__is_not_valid.png](https://ajuda.sankhya.com.br/hc/article_attachments/14532552290967)

 

Para consultar, acesse o site do IBGE ou solicite informações com o contador da empresa.
[https://www.ibge.gov.br/](https://www.ibge.gov.br/)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482544675735)

 Após o ajuste, redigite o cabeçalho da nota e gere um novo lote.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16482535606551)

 CAUSA:**

Ocorre quando no cadastro da cidade do Parceiro, Empresa ou Transportadora da Nota, não existe um valor válido para o campo **"Mun. domicílio fiscal".**
