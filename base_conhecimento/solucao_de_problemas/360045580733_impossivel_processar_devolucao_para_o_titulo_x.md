 MENSAGEM:**

[FIN_E00287]: Impossível processar Devolução para o título 'X'. A data da baixa é posterior à data de Devolução informada.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840473111)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840477975)

 A 'Data' inserida para processar a devolução deverá ser **posterior **a data da baixa do respectivo título.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840482967)

 Atente-se a data de devolução inserida, conforme destacado abaixo:

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15470063262615)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840484247)

 Após ajustar a data, prossiga com a devolução de cheque.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840486807)

 INFORMAÇÕES ADICIONAIS:**

 

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28454015398423)

**A realização da** marcação "Permitir devolução para títulos de receitas com comissão a ser paga?"** faz com que o sistema não critique a existência de comissão ainda não paga e permite a devolução dos cheques. Se estiver desmarcada, o sistema barra a devolução de cheques quando houver comissão ainda não paga.

Dessa forma, além das orientações mencionadas acima, atente-se a essa marcação:

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15470074912279)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16538840492311)

 CAUSA:**

Mensagem apresentada quando a data inserida para processar a devolução é anterior a data da baixa do respectivo título.
