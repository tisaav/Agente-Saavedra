 MENSAGEM**:

Já existe uma base de dados de produção registrada.

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15936005212311)

 **CAUSA:**

Ao registrar uma base de dados produção, quando já houver outra registrada, a mensagem será apresentada.

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15936005215127)

 **SOLUÇÃO:**

O registro da base de dados é realizada no sistema através do menu 'Administração do Servidor' >> Aba **'Registro de base de dados', **conforme exemplo abaixo:

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15936025781271)

Porém, ao tentar registrar uma segunda base com o **TIPO =  Produção**, a mensagem será apresentada. 

Nesse caso, a equipe de Banco de Dados do Service Desk precisará analisar o contexto, compreender as especificações dessa necessidade, e assim seguir com as orientações.
