SITUAÇÃO:**

Quando o produto está vencido e não pode ser vendido, como realizar a baixa desse produto no estoque. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/23140900875671)

SOLUÇÃO:**

Gere uma ocorrência para o produto no endereço como 'Avaria' pelo coletor android/superwaba

Realize a transferência do produto para endereço de avaria.

Acesse a tela Consulta estoque com ocorrencia e transfira o produto para a perda, após executar a transferência será possível emitir uma nota de ajuste de saída (perda) para o produto.
