 **MENSAGEM:**

Não foi possível carregar o servidor.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26834951113879)

SOLUÇÃO:**

 

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26834923027607)

 O navegador Sankhya não tem suporte para login via SSO. Portanto, é necessário utilizar navegadores externos.

 

Mais informações sobre o login via IDP no manual abaixo:

[Configuração do login via IDP Microsoft Azure no Sankhya Om](https://ajuda.sankhya.com.br/hc/pt-br/articles/19540006692887-Configura%C3%A7%C3%A3o-do-login-via-IDP-Microsoft-Azure-no-Sankhya-Om)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26834951119767)

CAUSA:**

Ao utilizar login via SSO no Navegador Sankhya é apresentado erro para carregar o servidor.
