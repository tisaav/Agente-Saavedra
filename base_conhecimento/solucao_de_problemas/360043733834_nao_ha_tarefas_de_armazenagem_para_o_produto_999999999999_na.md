 MENSAGEM:**

Não há tarefas de armazenagem para o produto 999999999999 na doca 888888.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16418157891479)

 SOLUÇÃO:**

 Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16418157893655)

 Acesse *MGEWMS » Arquivos » Cadastros » Tipo de Equipamento*, aba **Tarefas que podem ser executadas por este tipo de Equipamento **e defina as tarefas conforme o tipo de Equipamento suportado. Na aba **Unidades permitidas para este tipo de Equipamento **defina as Unidades conforme o tipo de Equipamento suportado

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16418157894935)

 Acesse *MGEWMS » Arquivos » Cadastros » Definir Tarefa e Volume por usuário*, aba **Unidades permitidas para este Usuário **e defina as Unidades conforme o Usuário. Na aba **Tarefas que podem ser executadas por este Usuário **defina as tarefas que são permitidas para este Usuário.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16418180029335)

 Após os ajustes, busque novamente a tarefa no Coletor.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16418157898007)

 CAUSA:**

Ocorre quando Equipamento e/ou Usuário não esta devidamente liberado para movimentar o respectivo produto na Doca.
