 MENSAGEM**:

cvc-datatype-valid.1.2.3: 'XXXXXXXX' is not a valid value of union type 'tpFoneNulo'.
cvc-type.3.1.3: The value 'XXXXXXXX' of element 'TelefoneTomador' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453516366999)

 SOLUÇÃO**:

Para correção siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453516368791)

 Acesse a tela '****[Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494)' (Caminho de acesso:* Configurações » Cadastros*):

- Selecione o parceiro utilizado no respectivo lançamento, aba: "**Endereço"**.

- Preencha corretamente os dados do telefone, campos: "**Telefone"** e "**Celular/Fax"**.

- Salve as alterações.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453516373015)

 Redigite ou fature novamente a nota e gere novamente o lote.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16453516373911)

 CAUSA**:

Ocorre quando o telefone do TOMADOR do serviço está incorreto em seu cadastro.
