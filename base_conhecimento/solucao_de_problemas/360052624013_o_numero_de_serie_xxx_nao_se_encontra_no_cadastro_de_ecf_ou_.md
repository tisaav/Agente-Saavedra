 MENSAGEM:**

O número de série XXX não se encontra no cadastro de ECF ou está inativo. O caixa não será aberto.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416998607639)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416998613015)

 Acesse: *Comercial » Arquivo » Cadastros » Cadastro de Equipamentos Fiscais - ECF/SAT/MFE*

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416998617367)

 Verifique se a respectiva série relatada no erro está inativa ou não está cadastrada.

Campo: **"ativo" **(se estiver desmarcado, marque e salve a alteração)
Se o número de série não for encontrado, faça o cadastro com todos os dados possíveis.

 CAUSA:**

Ocorre quando o cliente esta utilizando uma nova ECF- Impressora Fiscal e a mesma ainda não foi cadastrada no sistema e/ou não esta ativa.
