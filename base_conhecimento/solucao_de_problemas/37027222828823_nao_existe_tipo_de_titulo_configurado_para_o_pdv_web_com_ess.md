# Não existe Tipo de Titulo configurado para o PDV WEB com esse Subtipo

 **MENSAGEM:**

Não existe Tipo de Titulo configurado para o PDV WEB com esse Subtipo

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/37027222823959)

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37027222824215)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038316959767)

 Acesse a tela ****[''Tipos de Título''](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044606494-Tipos-de-T%C3%ADtulo)** **(Financeiro » Arquivos » Cadastros » Tipos de Título » Tipos de Título).

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038316961047)

 Localize e edite o **Tipo de Título** que está sendo utilizado causando o erro no PDV Web.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038316962839)

 Na aba **''Fast Service"**, localize e marque o campo **''****Utiliza no Fast Service?''**.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038316965271)

 Salve as alterações.

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038316966679)

 Feche e reabra o PDV Web.

![6 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37038286238487)

 Em seguida, realize a operação novamente com o subtipo ou tipo de título corrigido.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/37027222825751)

CAUSA:**

O erro ocorre porque o Tipo de Titulo utilizado no PDV Web não possui a opção ''Utiliza no Fast Service?''  marcada em sua aba de configuração, que é obrigatória para que o sistema reconheça o título corretamente.
