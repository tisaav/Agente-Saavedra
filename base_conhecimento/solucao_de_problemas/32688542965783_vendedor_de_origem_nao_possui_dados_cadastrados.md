 **MENSAGEM:**

Vendedor de origem não possui dados cadastrados.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/33049161283351)

 SOLUÇÃO:**

No cadastro de **Vendedores/Compradores >> configurações >> Cadastros ** existe uma rotina (outras opções) que permite **COPIAR** todos os parceiros vinculados há  um vendedor** (na aba PARCEIROS)** e passar para outro **VENDEDOR**. 
Essa rotina é utilizada em uma eventual troca de **VENDEDORES**, possibilitando passar todos os PARCEIROS do VENDEDOR **'A'** para o VENDEDOR** 'B'.**

Ao  clicar sobre esta opção, sistema apresentará  um POP-UP   para preenchimento dos campos  **VENDEDOR ORIGEM**  e  **VENDEDOR DESTINO** 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/32688572024727)

 

A mensagem será  apresentada caso o** VENDEDOR DE ORIGEM** não possua nenhum **CODIGO DE PARCEIRO** registrado na aba** PARCEIRO.**

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/32688542957207)

OBSERVAÇÃO:**

Esta copia não verifica o campo  **VENDEDOR PREFERENCIA**  existente no Cadastro do Parceiro. 

Ela verifica  a aba **PARCEIROS   **existente no CAD. VENDEDORES que é utilizada na aba **SEQUENCIA DE VISITAS.**
