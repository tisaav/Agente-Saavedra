 MENSAGEM**:

Informe o Tipo de Operação para CTe-OS em Outras Opções > Preferências para Importar CTe > CT-e de Terceiros > Tipo de Operação CTe-OS.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540838654999)

 SOLUÇÃO:**

Para a resolução do erro, siga os passos abaixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540838658071)

 Entre no portal de importação de XML clique no botão: Outras opções -> Preferências para Importar CTe > CT-e de Terceiros,

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540822116887)

 Em seguida, informe o tipo de operação utilizado para importar documentos do modelo 67 no campo **"****Tipo de Operação CTe-OS"**;

 

![Informe o Tipo de Operação para CTe-OS em Outras Opções 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540822119703)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540822121623)

 Caso não encontre a TOP que configurou para tal documento lembre-se que o tipo de operação precisa ter uma configuração específica em alguns campos:

****

****

****

| 1-Modelo do documento(Aba NF-e/NFC-e): '67- Conhecimento Transporte Eletrônico Outros Serviços'; 2-NF-e(Aba NF-e/NFC-e): 'Terceiros'; 3-Tipo de movimento: 'I-Financeiro'; |
| --- |

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16540822125975)

CAUSA:**

O erro ocorre pois ao tentar processar o xml de um documento modelo CT-e OS no portal de importação de xml, caso existe uma top informada no campo Tipo Operação CT-e OS (Outras Opções > Preferências para Importar CTe > CT-e de Terceiros).
