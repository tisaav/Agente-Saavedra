 MENSAGEM:**

S-2240 / Erro 180 - O Vínculo Trabalhista não foi localizado. Ação Sugerida: Utilize o evento de admissão para cadastramento do vínculo trabalhista.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653294871)

 SOLUÇÃO:**

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450697995031)

 Pessoal +**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653297943)

 Acesse o cadastro na tela **"Ambiente de Trabalho",** aba **"Funcionários que desempenham suas atividades neste ambiente"** e verifique a data que está no campo **"Data Inicio Condição"** para o funcionário que está com o erro.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653300119)

 Deve constar uma data igual ou posterior a data de admissão/transferência do funcionário

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15832215349655)

 

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450697995031)

 MGE Pessoal**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653297943)

 Acesse o cadastro do ambiente, menu Rotinas > SESMT > Ambiente de trabalho > aba **"Funcionários que desempenham suas atividades neste ambiente"** e verifique a data que está no campo **"Data Inicio Condição"** para o funcionário que está com o erro.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653300119)

 Deve constar uma data igual ou posterior a data de admissão/transferência do funcionário

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15832201300631)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16981653308951)

 CAUSA:**

Ocorre quando é configurado com data anterior a admissão do funcionário.

**Exemplo:** Funcionário com data de admissão 07/04/2022 e a data de início condição está 01/04/2022.
