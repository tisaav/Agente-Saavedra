 MENSAGEM:**

[COM_E00149] Não é possível faturar mais de uma nota, com moedas diferentes.

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18694834520983)

 SITUAÇÃO:**

Ao selecionar mais de uma nota para faturar a mensagem é apresentada.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18694834528023)

 CAUSA:**

Ocorre ao selecionar notas com moedas diferentes.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18694834535063)

 SOLUÇÃO:**

Acesse o **Portal de Vendas*** (Caminho de acesso à tela: Comercial » Consulta » Portal de Vendas)* e verifique a moeda nas notas que deseja faturar juntas. Pois, não é possível selecionar notas com moedas diferentes para realizar o faturamento.

![portal.png](https://ajuda.sankhya.com.br/hc/article_attachments/18694872078359)
