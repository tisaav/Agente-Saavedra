**MENSAGEM: **

O parâmetro **"Código Usuário Convidado - CODUSUVISITA"** deve ser informado nas configurações do sistema.

**

![Situa__o.png](https://ajuda.sankhya.com.br/hc/article_attachments/16071924248471)

 SITUAÇÃO:**

O erro é apresentado ao clicar no link para responder o questionário referente ao "Planejamento de Pesquisa"

**

![3.png](https://ajuda.sankhya.com.br/hc/article_attachments/16071945495191)

 SOLUÇÃO:**

Para resolver o erro siga os passos:

![1__1_.png](https://ajuda.sankhya.com.br/hc/article_attachments/16071936990871)

 Acesse o parâmetro **"Código Usuário Convidado - CODUSUVISITA"**  e configure um código de usuário Sankhya.

![2__1_.png](https://ajuda.sankhya.com.br/hc/article_attachments/16071932002455)

 Caso mesmo com o parâmetro **"Código Usuário Convidado - CODUSUVISITA"**  configurado e o erro permaneça, verifique o parâmetro **"Endereço para acesso externo ao WGE - ENDACESSEXTWGE"** está configurado com o endereço para acesso externo para o ambiente desejado (Produção, Teste ou Treinamento).

**

![2.png](https://ajuda.sankhya.com.br/hc/article_attachments/16071945497239)

 CAUSA:**

O erro pode ocorrer por falta de um usuário Sankhya configurado no parâmetro **"Código Usuário Convidado - CODUSUVISITA"****.**

Outra possível causa poderá ser o parâmetro **Endereço para acesso externo ao WGE - ENDACESSEXTWGE** configurado com endereço divergente.
