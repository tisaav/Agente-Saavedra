 MENSAGEM:**

The value '0 ' of element 'nVol' is not valid.

 

** 

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16088525423511)

 SOLUÇÃO:**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16088510735255)

 Verifique/ajuste informações inseridas no campo "**Numeração de Volumes**" da aba **Transporte da nota**. Caso não trabalhe com o envio dessa informação para a SEFAZ, limpe o conteúdo informado.

 

![central_de_vendas2.png](https://ajuda.sankhya.com.br/hc/article_attachments/14660671986199)

 

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16088510737431)

 Realizado o ajuste, gere um novo lote da nota.

 

** 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16088525436567)

 CAUSA:**

Ocorre ao tentar aprovar NF-e com informações indevidas no campo Numeração do Volume.
