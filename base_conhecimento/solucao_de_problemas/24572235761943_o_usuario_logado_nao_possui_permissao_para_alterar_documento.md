 **MENSAGEM:**

[CORE_E02774] O usuário logado não possui permissão para alterar documentos do tipo "XXXXX"

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/24572235750807)

SOLUÇÃO:**

Entre na tela **"Acessos" **(Caminho: Configurações » Controle de Acesso » Acessos), busque pela rotina desejada, selecione o usuário em questão e conceda a ele a permissão necessária para executar a ação interrompida pelo erro. 

 

![O usuário logado não possuipermissão para alterar documentos do tipo XXXXX.png](https://ajuda.sankhya.com.br/hc/article_attachments/24572235754007)

 

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/24572219300247)

**CAUSA:**

O erro é apresentado ao usuário quando ele tenta realizar uma ação para a qual ele não possui a devida permissão na tela Acessos.
