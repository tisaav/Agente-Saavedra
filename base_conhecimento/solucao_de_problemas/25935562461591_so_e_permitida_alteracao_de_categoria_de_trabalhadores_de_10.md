# Só é permitida alteração de categoria de trabalhadores de [102,103,105,106,107,108,111] para [101] ou de [101,103] para [111].

 MENSAGEM:**

Aviso: Só é permitida alteração de categoria de trabalhadores de [102,103,105,106,107,108,111] para [101] ou de [101,103] para [111]. Não pode ser alterada nos demais casos.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/25948211804695)

 SITUAÇÃO:**

Ao tentar alterar a categoria do cadastro de um trabalhador sem vínculo empregatício  para uma categoria de empregado  [101],  a mensagem é apresentada.

 

![Solução FINAL.png](https://lh7-rt.googleusercontent.com/docsz/AD_4nXcFyon8Bim5etMj-QHHuBjCFmnWpHNbpY8Tv9Vsei-vuw4_jbKjdZEjSe0bIB3RTk5WSo42VJaopFwm6Orriy0TREi_hzWphrcnSWKmfCdDnqAMd94zOf8EoP2zG_Tqf_M1uOV4T1jfDEoCwS6qnbcth_mK?key=Shv6wYCdrdyQQxAaUdNMWQ)

** SOLUÇÃO:**

Desta forma, se o trabalhador for passar a ter vínculo empregatício com empresa, informe o fim do vínculo anterior e realize um novo cadastro com a categoria desejada.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/25948239228951)

 CAUSA:**

De acordo com a [REGRA_ALTERA_CATEG eSocial versão S-1.2](https://www.gov.br/esocial/pt-br/documentacao-tecnica/leiautes-esocial-v-1-2-versao-s-1-2-nt-04-2024/regras.html) a alteração de categoria do eSocial, "Só é permitida alteração de categoria de trabalhadores de [102,103,105,106,107,108,111] para [101] ou de [101,103] para [111]. Demais casos não podem serem alterados.”
