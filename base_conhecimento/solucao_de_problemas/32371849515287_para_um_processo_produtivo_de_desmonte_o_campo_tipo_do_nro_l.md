# Para um processo produtivo de desmonte o campo tipo do nro. lote deve ser manual

 **MENSAGEM:**

[PROD_E00488] Para um Processo Produtivo de Desmonte o campo Tipo do Nro. Lote deve ser Manual. 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/32371849511447)

SOLUÇÃO:**

Acesse a tela **"Processo Produtivo - Nova",** selecione o processo produtivo em questão e, no campo **"Tipo do Nro. Lote", **escolha a opção **"Manual".**

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/32371843390231)

CAUSA:**

Ocorre quando o Processo Produtivo com a flag de **"Desmonte"** está configurado com o tipo de Nro de lote definido como **"Automatico"**.
