 SITUAÇÃO:**

Ao tentar consultar OS a mensagem é apresentada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18851371052823)

 SOLUÇÃO:**

Esta é uma **validação utilizada pelo Sankhya OM **para conferir se o usuário tem aptidão para realizar o serviço em questão. Para fazer a correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18851393092375)

 Realize o cadastro na tela** Serviços por Executante ***(Configurações » Cadastros » Serviços por Executante).*
