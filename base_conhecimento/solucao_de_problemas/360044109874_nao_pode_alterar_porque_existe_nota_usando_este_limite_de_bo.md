 MENSAGEM:**

[CORE_E03737] Não pode alterar porque existe nota usando este limite de bonificação.

 

![Situação.png](https://ajuda.sankhya.com.br/hc/article_attachments/15533915613847)

 **SITUAÇÃO:**

Ao tentar alterar limites na tela **"[Limites de Bonificação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044599894-Limites-de-Bonifica%C3%A7%C3%A3o)"** é apresentada a mensagem.

 

![3.png](https://ajuda.sankhya.com.br/hc/article_attachments/15533915619095)

 **SOLUÇÃO:**

![1.png](https://ajuda.sankhya.com.br/hc/article_attachments/15533902031127)

 Este bloqueio impede que os usuários possam manipular valores das Bonificações, caso estes valores já tenham sido utilizados em alguma operação.  

![2.png](https://ajuda.sankhya.com.br/hc/article_attachments/15533915627543)

 Caso seja necessário uma nova  liberação com valores acima do  estabelecido, crie um novo limite para o usuário. Se o usuário possuir duas linhas de limites ou mais, ao solicitar a liberação o sistema vai perguntar qual dos limites o usuário deseja utilizar.

 

![2.png](https://ajuda.sankhya.com.br/hc/article_attachments/15533902045079)

 **CAUSA:**

Mensagem apresentada ao tentar alterar limites de bonificação, visto que a rotina não permite esse procedimento.
