 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585574999703)

 Acesse: *Configurações » Controle de Acesso » Acessos - C*ampo pesquisa: Relatório formatado. Adicione o usuário ou o grupo em questão e permita os acessos.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585590031511)

 Na mesma tela: *Campo pesquisa* localizar pelo nome do relatório ex.: [ Preview - Danfe Retrato]. Caso este tenha sido criado um 'Lançador'.

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18856580375703)

 Adicione o usuário ou grupo em questão e conceda as permissões de acesso. Uma vez concluído, o conteúdo estará disponível para visualização na central.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18585590005143)

 CAUSA:**

A mensagem é apresentada quando determinado usuário, que não possui os acessos liberados para o respectivo relatório, tenta visualizá-lo.
