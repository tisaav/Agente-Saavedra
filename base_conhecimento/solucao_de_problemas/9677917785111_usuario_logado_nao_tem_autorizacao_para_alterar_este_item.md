 MENSAGEM:**

[CORE_E02038] Usuário logado não tem autorização para alterar este item!

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18856952537751)

 SITUAÇÃO:**

Ao atualizar os cadastros de parceiros ou qualquer outra rotina a mensagem é apresentada.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18856984023191)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18856952551191)

 Localize a tela de **Acessos** *(Configurações » Controle de Acesso » Acessos)*, selecione a rotina utilizada, filtre o usuário que está tentando fazer a alteração e, então, marque a opção de Alterar.

 

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/9677882331543)

Após a conclusão deste processo, o usuário terá a permissão necessária para efetuar modificações na rotina mencionada.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18856984030743)

CAUSA:**

Ocorre quando o usuário não possui permissão para edição.
