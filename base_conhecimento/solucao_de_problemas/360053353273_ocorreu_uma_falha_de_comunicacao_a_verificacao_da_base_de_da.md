 MENSAGEM**:

Ocorreu uma falha de comunicação, a verificação da base de dados não pôde ser feita.

Realize o registro assim que possível para evitar a indisponibilidade do sistema que pode ocorrer a partir de 29 dias.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15916479555991)

 CAUSA:**

Ao atualizar o sistema para versão 3.31 ou superior no primeiro acesso será necessário registrar a base atualizada, informando um apelido e o 'Tipo da Base'. 

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15916479558295)

 **SOLUÇÃO:**

![1](https://ajuda.sankhya.com.br/hc/article_attachments/15916479562135)

 Logado com o usuário SUP,  acesse a tela 'Administração do Servidor', Aba** 'Registro de base de dados'**:

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15916375715479)

 

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15916432742551)

 Dentro de** 'Apelido para a Base'** dê um nome para a sua base. 

Exemplo: ***SDETESTE12***

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15916461223703)

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15916479566743)

 Em seguida defina se trata-se de uma base produção, teste ou treinamento no campo** 'Tipo da Base'**:

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15916448780823)

![4](https://ajuda.sankhya.com.br/hc/article_attachments/15916479568407)

 Clique em 'Salvar', confira os dados, em seguida clique em CONCLUIR. 

![5](https://ajuda.sankhya.com.br/hc/article_attachments/15916432752663)

 Realizada a configuração acima será possível acessar o sistema normalmente.
