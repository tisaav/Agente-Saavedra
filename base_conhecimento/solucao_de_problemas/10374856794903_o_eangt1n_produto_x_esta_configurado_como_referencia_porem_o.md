 MENSAGEM:**

O EAN/GT1N Produto 'X' está configurado como Referencia, porém o campo Referencia deste produto está vazio.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18613784856087)

 CAUSA:**

Quando lançado uma nota com produto configurado com EAN/GTIN = Referência e a referência não for informada, a mensagem será apresentada.

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18613784862359)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18613760156695)

 Acesse o cadastro do respectivo produto :

Tela 'Produtos'*(Configurações » Cadastros » Produtos)*

- Aba: Impostos

- Campo: **'EAN/GTIN produto p/ NF-e'**

![produtos impostos.png](https://ajuda.sankhya.com.br/hc/article_attachments/18613784872471)

- ****

| Certifique-se que a configuração acima esteja assertiva. Caso para esse produto não deva ser informado EAN/GTIN ajuste para 'Não Informar' e refaça o lançamento. |
| --- |

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/18613784878871)

 Caso a configuração realmente deva ser 'Referência', preencha esse campo no cadastro do produto, conforme abaixo:
