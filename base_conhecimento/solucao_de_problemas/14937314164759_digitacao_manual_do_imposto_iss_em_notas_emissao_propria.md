# Digitação manual do imposto ISS em notas Emissão Própria.

Para realizar a digitação manual do imposto ISS em um lançamento a TOP de NF-e de Emissão Própria deve ter o "Cálculo de ICMS, IPI e ISS" do tipo "**Não calcula e digita**":

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/42618624262679)

Siga os procedimentos descritos abaixo na tela de **"Central de Vendas"** (Comercial >> Consulta >> Central de Vendas) para lançamento da nota:

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/42618640633367)

 Acesse a tela **"Central de Vendas"** (Comercial >> Consulta >> Central de Vendas) e localize ou inicie o lançamento da nota fiscal desejada.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/42618624263319)

 Na grade de itens, selecione o produto e acesse a aba **"Impostos"**.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/42618640634135)

 Preencha manualmente os campos necessários para o lançamento do ISS, garantindo que estejam devidamente informados:

- 
**Valor do ISS:** informe o valor desejado para o imposto.

- 
**Base de Cálculo do ISS:** informe a base de cálculo correspondente ao lançamento.

- 
**CST do ISS:** informe o código de situação tributária aplicável.

Certifique-se de que os três campos estejam preenchidos corretamente antes de prosseguir com o lançamento.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/42618640634647)

 Após realizar as alterações, clique no **"Botão Salvar"** para confirmar as informações inseridas na nota.

 

### **Observações importantes sobre a digitação**

A digitação manual do valor do ISS pode ser bloqueada caso o **"Tipo de Operação - TOP"** (Comercial >> Arquivo >> Cadastros >> Tipos de Operação - TOP) esteja configurado para realizar o cálculo automático dos impostos. Caso o campo esteja desabilitado, revise as configurações da **"TOP"** na aba **"Impostos"**, verificando a marcação **"Cálculo de ICMS, IPI, ISS, IBS, CBS e IS"**.
