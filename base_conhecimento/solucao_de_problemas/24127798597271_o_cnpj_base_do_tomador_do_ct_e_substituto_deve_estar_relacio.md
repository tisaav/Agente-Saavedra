# O CNPJ base do tomador do CT-e substituto deve estar relacionado nos papeis do CT-e substituído para a alteração de tomador

 **MENSAGEM:**

Rejeição: O CNPJ base do tomador do CT-e substituto deve estar relacionado nos papeis do CT-e substituído para a alteração de tomador.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/24127758103959)

SOLUÇÃO:**

Neste caso, o CNPJ base do tomador informado deve estar relacionado no CT-e substituído como um dos papéis existentes (remetente, destinatário, recebedor, expedidor ou tomador).

Por exemplo, o tomador que está incluindo deve estar associado ao primeiro CT-e com um dos seguintes papéis, a fim de realizar o CT-e de substituição:

 

 

![O CNPJ base do tomador do CT-e substituto deve estar relacionado 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/24128496341527)

 

Ou ter o CNPJ base em um desses papéis, como por exemplo, a matriz teria que estar no primeiro CT-e. 

![O CNPJ base do tomador do CT-e substituto deve estar relacionado 2.png](https://ajuda.sankhya.com.br/hc/article_attachments/24128532302999)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/24127798596375)

CAUSA:**

Quando o CNPJ base do tomador informado não está relacionado no CT-e substituído como um dos papéis existentes (remetente, destinatário, recebedor, expedidor ou tomador).
