# CNPJ Entidade Qualificadora é obrigatório quando o campo 'Contratação indireta de Aprendiz' está desmarcado

> **Módulo:** Solucao de Problemas | **Subseção:** Pessoal+  
> **Fonte Oficial:** [https://ajuda.sankhya.com.br/hc/pt-br/articles/30965238878103-CNPJ-Entidade-Qualificadora-%C3%A9-obrigat%C3%B3rio-quando-o-campo-Contrata%C3%A7%C3%A3o-indireta-de-Aprendiz-est%C3%A1-desmarcado](https://ajuda.sankhya.com.br/hc/pt-br/articles/30965238878103-CNPJ-Entidade-Qualificadora-%C3%A9-obrigat%C3%B3rio-quando-o-campo-Contrata%C3%A7%C3%A3o-indireta-de-Aprendiz-est%C3%A1-desmarcado)  
> **ID:** `30965238878103` | **Última Atualização:** 2026-08-27T18:31:58Z

O erro ocorre quando se está cadastrando um funcionário Aprendiz e a opção **"Contratação indireta para Aprendiz"** está desmarcada, mas o sistema exige o preenchimento do campo **"CNPJ Entidade Qualificadora".**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238866583)

 Acesse a tela **"Configuração de Funcionários"** *(Pessoal + > Configuração de Funcionários),* vá até a aba **"Admissão" **e certifique-se de que os campos abaixo estão preenchidas com as seguintes opções: 

 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238867351)

  Campo **"Categoria p/ eSocial"** está com o código 103 - Empregado Aprendiz

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238867351)

 Campo **"Vínculo"** está com o código 55 - Menor Aprendiz

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238869527)

 Verifique as duas opções abaixo: 

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238867351)

 Para contratação direta: **

- Mantenha desmarcada a opção de **"Contratação Indireta Aprendiz", **na aba **"Contrato";**

- Preencha o campo **"CNPJ Entidade Qualificadora" **(aba Contrato) com o CNPJ da instituição responsável pela qualificação do aprendiz.

**

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30965238867351)

 Para contratação Indireta: **

- Quando a contratação é direta (feita pelo próprio estabelecimento), é obrigatório informar apenas o CNPJ da entidade qualificadora;

- Quando a contratação é indireta, são necessárias as informações da instituição empregadora. 

 

**Observação importante:   **

Importante realizar uma revisão e, caso necessário, ajuste a configuração dos campos na tela. Segue passo a passo: 

- Na tela de Configuração de Funcionário clique na engrenagem: 

![CNPJ Entidade Qualificadora é obrigatório quando o campo 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/31061857552023)

 

- Conforme indicado no print, no campo serão exibidos os campos disponíveis para configuração, os quais poderão ser arrastados para a aba correspondente:

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/30965238870295)
