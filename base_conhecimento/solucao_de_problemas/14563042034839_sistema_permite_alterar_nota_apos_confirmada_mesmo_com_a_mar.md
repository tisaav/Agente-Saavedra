# Sistema permite alterar nota após confirmada, mesmo com a marcação na TOP "Permitir Alteração após confirmar" desmarcada

 SOLUÇÃO: **

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16865903004183)

 Verifique na tela de **"Usuários"**, se o usuário que realizou o lançamento possui a marcação **"Altera registros confirmados"**, na aba **"Segurança". **Mesmo que a TOP não permita alterações após confirmação, o sistema concederá a alteração do movimento.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16865903008919)

 Se a TOP permitir alteração, o sistema não usa esta marcação do cadastro de usuários e permite que todos os usuários alterem notas confirmadas.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16865893716759)

 A marcação Altera registros confirmados, na aba Segurança do cadastro de usuários permite que mesmo a top estando contrária, o sistema aceite a alteração dos movimentos já confirmados.
