# Parceiro a 'X' dias sem negociar. Há liberação pendente

 MENSAGEM:**

Parceiro a 'X' dias sem negociar. Há liberação pendente.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143118430231)

 SOLUÇÃO:**

A liberação de evento para esse caso é solicitada devido configurações abaixo:

- Evento 9 - Tempo Inativo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143118432919)

 Tela **"[Preferências](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601834)"** *(Configurações/Avançado*) >> Chave "**DIASSEMVENDA"** - Nro de dias p/avisar que o cliente está sem venda:

- Tempo em dias, a partir do qual o sistema avisa que o cliente está sem negociar com a empresa.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/12125828746519)

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143150492311)

 Tela **"[Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494)"** *(Configurações/Cadastros)* >>

- Aba "**Crédito** ":  Campo **"Prazo p/ contato**"

- Configure o tempo, em dias, para contato com o cliente.

 

![Parceiro_a__X__dias_sem_negociar._H__libera__o_pendente.png](https://ajuda.sankhya.com.br/hc/article_attachments/14686593742743)

 

**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143150493975)

 EXEMPLO:**

Ao lançar uma Venda, sendo ultrapassado o tempo configurado acima, o sistema apresenta a mensagem "Cliente inativo desde...", bloqueia a Venda e é aberto o pop-up de solicitação de Liberação de Limites.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143150496151)

 Caso não deseje trabalhar com a liberação do evento acima, deixe em branco o parâmetro "**DIASSEMVENDA**."

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143150498455)

 Caso essa configuração seja válida, libere o evento com o usuário/liberador configurado para tal.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17874215877271)

 IMPORTANTE:**

A funcionalidade do parâmetro "**DIASSEMVENDA**", tanto para avisar, quanto para bloquear a venda para parceiros que não compram a X dias, não é aplicada em Tipos de Negociação à vista.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16143118445463)

 CAUSA:**

Ocorre quando o parceiro está há muito tempo sem efetuar negociação de compra/venda, causando a solicitação de liberação de limites, geralmente usado para revisar cadastro e/ou refazer análise de crédito.
