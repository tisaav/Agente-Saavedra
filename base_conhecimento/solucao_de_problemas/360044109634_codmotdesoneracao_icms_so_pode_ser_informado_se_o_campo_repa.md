 MENSAGEM:**

[CORE_E02112] Cód.Mot.Desoneração ICMS" só pode ser informado se o campo "Repassar para o cliente" for "Redução do imposto" ou "ICMS".

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416482758039)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416482762903)

 Se preenchido o campo **"Cód.Mot.Desoneração ICMS"**,  na seção "Repassar para o cliente" deve-se marcar a opção "**Redução do imposto**" ou a opção"**ICMS**":

- Tela **"Alíquotas de ICMS"** (Caminho de acesso: Comercial » Arquivo » Cadastros » Alíquotas)
Aba **"Geral"** » Campo **'Repassar para o cliente'**
Aba **"Geral"** » Campo **'Cód.Mot.Desoneração ICMS'**

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14684058239767)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416482771095)

 Atente-se as configurações acima, conforme necessidade da respectiva alíquota de ICMS. Após ajustes salve o cadastro.

 

**

![Observação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416470825111)

 OBSERVAÇÕES:**

Para mais detalhes sobre configurações relacionados a desoneração de ICMS veja o artigo: [Desoneração do ICMS](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597834).

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16416470830487)

 CAUSA:**

Caso na seção Repassar para o cliente esteja marcada a opção Redução da BASE e o campo Cód.Mot.Desoneração ICMS  esteja preenchido, o sistema deverá apresentar a mensagem.
