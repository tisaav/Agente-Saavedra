 MENSAGEM:**

The value '' of element 'Email' is not valid.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16454055224471)

 SITUAÇÃO:**

Ao gerar lote de uma NFS-e é apresentada a mensagem de rejeição.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16454052730647)

 SOLUÇÃO:**

Para correção siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16454055229207)

 Acesse: "****[Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494)" (Caminho de acesso:* Configurações » Cadastros » Parceiros*)

- Aba "**NF-e/NFS-e/CT-e"**,

- Campo "**E-mail p/ envio NF-e/NFS-e/CT-e"**: informe os e-mail's do parceiro

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16454052736407)

 Após o ajustes, gere o lote da nota novamente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16454055233431)

 CAUSA:**

Ocorre quando o e-mail do parceiro não está devidamente informado/cadastrado. Podem ocorrer rejeições como:

- EL35: O campo e-mail não foi preenchido para um novo tomador 
Conforme o manual: O preenchimento do e-mail é obrigatório para um novo tomador. 

1. EL40: Campo E-mail do tomador informado incorretamente. 
Conforme o manual: O campo E-mail do tomador deverá ter tamanho máximo de 80 caracteres.
