SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/23156960571927)

 Verifique se o Web Connection embarcado ou externo esta iniciado:

No Navegador Sankhya, clique sobre o botão **"Configurações"** 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/23130181766295)

 (ou comando Ctrl + F6), aba "**Web Connection"**, a opção **"Iniciar Web Connetion junto com o navegador"** deverá estar marcada.

 

![Animação.gif](https://ajuda.sankhya.com.br/hc/article_attachments/23130181768727)

 

**Observação:** em alguns caso após marcar a opção será necessário fechar e abrir novamente o navegador para que o Web Connection seja inicializado. 

Caso seja utilizado o Web Connection externo, deverá ser verificado na opção** "Mostrar ícones ocultos"** da barra de tarefas se o mesmo está iniciado. Se não localizar o ícone, você poderá iniciá-lo através do atalho que normalmente se encontra na área de trabalho do computador.

 

![Informação - O gateway para operações TEF não está ativo.png](https://ajuda.sankhya.com.br/hc/article_attachments/27885948728599)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/23156991410071)

 Na tela **"****Preferências"** *(Configurações » Avançado » Preferências)* verifique se o parâmetro **"TEFGATEWAY"** está configurado corretamente com o TEF utilizado. 

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/23156960590231)

 Verifique se o programa do TEF está inicializado na máquina.

 

**Observação:** os programas de TEF variam de acordo com o sistema utilizado (Pay&Go, Sitef, Auttar). Caso não localize o software do TEF na máquina ou não consiga inicializá-lo, entre em contato com o suporte dos mesmos.

Para mais informações consulte o artigo: [TEF - Transação Eletrônica de Fundos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045108253-TEF-Transa%C3%A7%C3%A3o-Eletr%C3%B4nica-de-Fundos?source=search&auth_token=eyJhbGciOiJIUzI1NiJ9.eyJhY2NvdW50X2lkIjo5NjE4MTY4LCJ1c2VyX2lkIjo5NzY4ODgzNjQ0OTUxLCJ0aWNrZXRfaWQiOjM0NjYwNywiY2hhbm5lbF9pZCI6NjMsInR5cGUiOiJTRUFSQ0giLCJleHAiOjE3MDgxODQzODl9.X6bU761uiMmD4LHftnLqcFSN2IYnrJ9uL9ExiyZscSM).

Falha na comunicação com o gateway do TEF.
