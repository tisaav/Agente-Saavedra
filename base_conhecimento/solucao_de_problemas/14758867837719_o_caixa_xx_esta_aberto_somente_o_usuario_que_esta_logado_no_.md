 MENSAGEM:**

[CORE_E04077]: O Caixa XX está aberto! Somente o usuário que está logado no caixa tem permissão para excluir este Movimento Bancário.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16780038784535)

 SOLUÇÃO:**

De fato não será possível realizar a exclusão, uma vez que a conta caixa é bem limitada, específica e exclusiva, é o comportamento padrão do sistema ter essas travas para manter a segurança e a rastreabilidade das informações.
Nesse caso, o recomendado é realizar um lançamento de suprimento nesse caixa (um lançamento contrário a esse) para que seja feita a correção.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16780033510167)

 CAUSA:**

Ocorre ao tentar excluir um lançamento na conta caixa.
