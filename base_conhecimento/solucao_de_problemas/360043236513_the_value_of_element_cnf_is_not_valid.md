 MENSAGEM:**

The value ' ' of element 'cNF' is not valid.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452168391959)

 SOLUÇÃO:**

Para correção siga os passos abaixo.

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452168393751)

 Realize a consulta da chave NF-e gerada, nos Portais Nacional e Estadual da SEFAZ, certificando-se que essa não foi recebida:

['Consulta Chave NF-e Completa'](http://www.nfe.fazenda.gov.br/Portal/consultaRecaptcha.aspx?tipoConsulta=completa&tipoConteudo=XbSeqxE8pl8=)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452168396439)

 Diante do Status 'Aguardando Correção', com a rejeição acima, inutilize e exclua a nota rejeitada.

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452168398615)

 Emita uma nova nota, na qual a chave será gerada conforme dados atuais, gere o lote.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16452168400407)

 CAUSA:**

Realizada emissão de NF-e na qual o código numérico que compõe a chave de acesso, 'Número Aleatório' gerado pelo emitente foi gerado incorretamente, será apresentada a rejeição
