 MENSAGEM/DÚVIDA**:

Sistema não está importando corretamente o evento para o movimento quando o código possui 3 dígitos.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16272953221527)

 SOLUÇÃO:**

Realize o seguinte processo a baixo:

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16272936520471)

 Acesse: avançado >> preferências >> todas as preferências, localize o parâmetro **"****CONSI3DIGEVEN** **- considerar 3 dig. para cod. evento na importação",** assinale o mesmo e confirme.
Em seguida, saia e entre novamente no sistema.

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16272936523671)

 Realize uma nova importação do arquivo e verifique se os dados ficaram corretos.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16272953238807)

 CAUSA:**

O problema ocorre quando o parâmetro CONSI3DIGEVEN está desligado.
