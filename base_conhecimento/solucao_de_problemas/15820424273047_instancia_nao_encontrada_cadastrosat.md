 MENSAGEM:**

[CORE_E04746] Instancia não encontrada: CadastroSat.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15820428169751)

 CAUSA:**

Ocorre quando a versão do sistema está diferente da versão do dicionário de dados fazendo com que vários campos criados não sejam disponíveis por divergência de versão. 

**

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15820408556695)

 SOLUÇÃO:**

Entre em contato com o responsável pelo seu servidor de banco/aplicação, realize a atualização e padronizando das duas versões. Se possível também já atualize para última release disponível, evitando assim algum possível erro futuro.
