 MENSAGEM:**

Formato do arquivo de escrituração não é valido.

Data inválida - usar formato "ddmmaaaa". (0000 DT_FIN).

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17004328567319)

SOLUÇÃO:**

Essa mensagem é retornada quando o validador utilizado para esse processo não é compatível com o arquivo gerado.

 

**Exemplos:**

- Utilizando um 'Validador EFD ICMS-IPI' para validar um arquivo EFD CONTRIBUIÇÕES.

- Utilizando um 'Validador EFD Contribuições' para validar um arquivo EFD ICMS/IPI.

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17004328573847)

 Realize o download do validador compatível com o arquivo gerado e refaça a validação. Em caso de dúvidas acione o contador de sua empresa.
