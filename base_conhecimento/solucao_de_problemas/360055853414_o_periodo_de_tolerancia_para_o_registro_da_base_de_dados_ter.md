 MENSAGEM:**

Registro de Base de Dados
O período de tolerância para o registro da base de dados terminou.
A partir de agora algumas funcionalidades do sistema estarão indisponíveis.
Realize o registro da base de dados para que o sistema volte à operação normal.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282329784727)

 CAUSA:**

Ao atualizar o sistema para versão 3.31 ou superior no primeiro acesso será necessário registrar a base atualizada, informando um apelido e o 'Tipo da Base'. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282360568983)

 SOLUÇÃO:**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282360570903)

 Logado com o usuário SUP,  acesse a tela **"Administração do Servidor"**, aba** "Registro de base de dados"**:

 

![438.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282329765271)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282360576919)

 Dentro de** "Apelido para a Base"** dê um nome para a sua base. 

Exemplo: **SANKHYA PROD**

 

***

![2.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282329769495)

***

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282360588183)

 Em seguida, defina se trata-se de uma base produção, teste ou treinamento no campo** "Tipo da Base"**:

 

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282329776663)

 Clique em 'Salvar', confira os dados, em seguida clique em **Concluir**. 

 

![5 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17282360594199)

 Realizada a configuração acima será possível acessar o sistema normalmente.
