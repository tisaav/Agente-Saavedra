 MENSAGEM:**

[CORE_E01288] O produto conferido não existe no pedido/nota.

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014787991)

 SITUAÇÃO:**

Ao realizar o processo de conferência através da rotina **“[Fila de Conferencia](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044612074-Fila-de-Confer%C3%AAncia)”**, ocorre a mensagem.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16108999460247)

 SOLUÇÃO:**

Para correção, siga os passos abaixo:

**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014794135)

** Verifique se o código do produto que está sendo conferido está em conformidade com o código do produto inserido no pedido ou nota.

**

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16108999464727)

** Se o produto estiver correto, verifique na tela **"[Cadastro de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Cadastro-de-Produtos-)"** se o código de barras cadastrado no produto é o mesmo registrado nos campos **“Referência”, "Cód. Barras"** (aba Código de Barras), **"Código de Barras"** (aba Unidade Alternativas) ou **"Cód. de Barras"** (aba Estoque).

**

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014797847)

** Acesse a tela **"[Consulta de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045109353-Consulta-de-Produtos)"**, digite o código de barras e observe se será apresentado mais de um produto com o mesmo código de barras.

**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014798743)

** Caso seja apresentado mais de um produto, verifique qual deles está com o código de barras informado incorretamente.

**

![Marcador 2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014798743)

** Acesse o cadastro do produto com o código incorreto e corrija seu código de barras.

**

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16108999478679)

** Finalizados os ajustes, retorne ao processo de conferência. 

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16109014807703)

 CAUSA:**

Ocorre quando o sistema não localiza no cadastro de produtos o código e/ou código de barras informado.
