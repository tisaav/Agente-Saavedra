# Dashboard é apresentado na tela de acesso e pesquisa mesmo após a exclusão, saiba como proceder

 SITUAÇÃO:**

Foi excluído um Dashboard do sistema, porem ainda é apresentado no sistema em Acessos e continua visível na pesquisa.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310710508823)

 SOLUÇÃO:**

Quando um Dashboard for excluído do sistema, caso já tenha sido criado um 'atalho 'para acessá-lo, exclua também este atalho no menu do sistema.

Para isso, acesse a tela **"[Menu do Sistema](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112053-Menu-do-Sistema-)"** (*Caminho para acesso: Configurações » Avançado » Menu do Sistema*) e pesquise pelo caminho onde foi salvo o Dashboard no Menu do Sistema. Exclua o registro no botão **"Remover Item"**.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16310710510615)

 CAUSA:**

Ocorre quando um Dashboard já lançado como um atalho no menu do sistema foi excluído seu registro e não houve a exclusão do 'atalho' do registro no Menu do sistema.
