 MENSAGEM**

[CORE_E02510] Overflow Numérico

 

**

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292829277207)

 SITUAÇÃO**

Após inserir os dados no filtro e gerar o relatório é apresentado a mensagem.
 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292829284503)

 SOLUÇÃO**

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292829299223)

 Identifique qual relatório está apresentando o erro (exemplo: relatório 902 - Extrato Bancário Conciliado).
 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/42080321473303)

 Entre em contato com a equipe de **"Unidade"** responsável pela customização de relatórios.
 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/42080306369431)

 Solicite que seja realizada a adaptação do relatório no **"iReport"** ou no modelo **"JRXML"**, ajustando o tamanho dos campos para comportar adequadamente as informações.

**

![Observação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292829308951)

 OBSERVAÇÃO:**

A mensagem 'Overflow Numérico' pode ocorrer em outras rotinas da aplicação. Neste caso recomenda-se realizar a abertura do chamado pelo Portal do Cliente, inserindo o Log do sistema para análise.

 

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/17292829305623)

 CAUSA**

Esta mensagem ocorre geralmente quando o relatório possui campos, como NRO.NOTA ou NRO.DOC com tamanho insuficiente para receber informação.
