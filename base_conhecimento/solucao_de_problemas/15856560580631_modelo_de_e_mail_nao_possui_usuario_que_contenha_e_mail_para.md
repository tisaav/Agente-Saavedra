 MENSAGEM:**

[CORE_E04067] Modelo de E-mail " não possui usuário que contenha e-mail para resposta.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15856545171479)

 CAUSA:**

Ocorre ao não informar um usuário no campo 'Cód. Usuário Remetente' no modelo de E-mail.

**

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15856514605847)

 SOLUÇÃO:**

Acesse a tela **Modelo de E-mail** *(Configurações » Cadastros » Modelo de E-mail) *aba geral, informe um usuário no campo 'Cód. Usuário Remetente'.
