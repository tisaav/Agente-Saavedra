 **MENSAGEM:**

Cvc-type.3.1.3: The value ' of element 'CodigoNbs' is not valid

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30561432281623)

SOLUÇÃO:**

Acesse o site das ****[Nomenclatura Brasileira de Serviços](https://www.gov.br/mdic/pt-br/assuntos/comercio-e-servicos/nbs-nomenclatura-brasileira-de-servicos) ou verifique com a contabilidade o **Código NBS correto.**

Acesse a tela **"Serviço"**,  aba **"Imposto"**, e preencha corretamente o campo  **"Código NBS". **Depois gere o novo lote da nota para que a mesma seja aprovada.

 

![Cvc-type.3.1.3 The value ' of element 'CodigoNbs' is not valid 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/30589953518359)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30561470561175)

CAUSA:**

O erro ocorre porque foi informado incorretamente o Código NBS.
