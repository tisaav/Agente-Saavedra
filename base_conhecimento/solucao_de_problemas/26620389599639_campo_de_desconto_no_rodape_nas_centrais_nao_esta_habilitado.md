# Campo de desconto no rodapé nas centrais não está habilitado para digitação

> **Módulo:** Solucao de Problemas | **Subseção:** Vendas

O rodapé da **"Central de Compras"** (Configurações >> Cadastros >> Parceiros) exibe informações importantes sobre os totais do pedido, incluindo valores de desconto, seguro, frete e outros campos financeiros. Quando o campo de desconto não está habilitado para digitação no rodapé, isso geralmente está relacionado à configuração de um parâmetro específico do sistema.

![Situação FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26670891457175)

** SITUAÇÃO**

Campo de desconto no rodapé nas centrais não está habilitado para digitação.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/26620389583767)

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26620389591575)

** CAUSA **

Esse problema ocorre quando o parâmetro **"DESCTOT - Aceita desconto no pé da nota"** está desligado.

 

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/26620389590167)

**SOLUÇÃO**

Para que o campo de desconto fique disponível para edição no rodapé das centrais de compras, siga os passos abaixo:

![1](https://ajuda.sankhya.com.br/hc/article_attachments/42389285135895)

 Acesse a tela de **"Parâmetros do Sistema"** (Configurações >> Avançado >> Parâmetros do Sistema).

![2](https://ajuda.sankhya.com.br/hc/article_attachments/42389258146327)

 Localize o parâmetro **"DESCTOT - Aceita desconto no pé da nota"**.

![3](https://ajuda.sankhya.com.br/hc/article_attachments/42389258146711)

 Altere o status do parâmetro **"DESCTOT"** para **"Ligado"**.

![4](https://ajuda.sankhya.com.br/hc/article_attachments/42389285137431)

 Salve as alterações realizadas.

![5](https://ajuda.sankhya.com.br/hc/article_attachments/42389258147351)

 Saia da tela da **"Central de Compras"** (Comercial >> Consulta >> Central de Compras).

![6](https://ajuda.sankhya.com.br/hc/article_attachments/42389285138327)

 Entre novamente na **"Central de Compras"** para que as alterações sejam aplicadas.
