 MENSAGEM:**

[CORE_E03127] Já existe um produto equivalente cadastrado para este parceiro, produto equivalente, controle e cód. barras parceiro.

**

![2](https://ajuda.sankhya.com.br/hc/article_attachments/15854073676567)

 CAUSA:**

Quando alguns produtos equivalentes já se encontram cadastrados para o parceiro ou os parâmetros acima estão configurados diferente do sugerido acima.

**

![3](https://ajuda.sankhya.com.br/hc/article_attachments/15854073679639)

 SOLUÇÃO:**

Será necessário avaliar os seguintes parâmetros e ajustá-los conforme exemplo abaixo:

**'CONSEMPIMPXML-Considerar empresa na importação XML?:'** Ligado
**'VALCODBARREPET-Validar códigos de barra repetido?:'** Desligado
