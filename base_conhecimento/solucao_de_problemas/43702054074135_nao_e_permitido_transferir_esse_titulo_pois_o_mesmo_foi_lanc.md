 **SITUAÇÃO:**

Este bloqueio ocorre ao tentar realizar a transferência de um cheque ou título entre contas de usuários diferentes que operam como caixas.
 

##### 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/43702029684759)

**SOLUÇÃO: **

Para permitir a movimentação do título e corrigir o erro, siga os passos abaixo:

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/43702045170071)

 Acesse a tela Configurações » Avançado » Preferências 

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/43702045170071)

Pesquise pelo parâmetro **TRANSFCHQLIVRE** (Permitir transf. cheque mesmo de outros caixas).

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/43702045170071)

Ative este parâmetro.

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/43702045170071)

Salve as alterações e tente realizar a transferência do título novamente.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/43814763679767)

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/43702054067863)

 **CAUSA:**

Por padrão de segurança e controle, o sistema restringe a movimentação de títulos que foram lançados no caixa de terceiros. Para que essa operação seja possível, é necessário que o sistema esteja explicitamente configurado para aceitar a transferência livre entre caixas.
