Mensagem:**

[CORE_E00255] Usuário possui restrição para realizar liberação para XX da nota.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161511511319)

Solução:**

Para correção, siga os passos abaixo:

 

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161511511959)

 Acesse a tela **"[Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874)"** *(Caminho de acesso: Configurações » Controle de Acesso):*

- Selecione o usuário que está sendo validado

- Na aba "**Validações**" identifique o código da Regra vinculada ao usuário

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14523612754455)

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161481316503)

 Acesse a tela **"[Central de Certificações](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110053)"** *(Caminho de acesso: Comercial » Avançado » Certificações)*:

- Pesquise pelo código da regra vinculado ao usuário e identifique a restrição imposta.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/14523604154903)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161511516951)

 Verifique com o gestor sobre a restrição e se realmente ela é válida para o usuário.

![4 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161481359255)

 Revise as restrições e após os ajustes efetue o procedimento novamente.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16161511519127)

Causa:**

Ocorre quando o usuário possui restrição pela regra da Central de Certificação, vinculado ao seu cadastro.
