 MENSAGEM:**

[CORE_E02842] O usuário não possui alçada para o evento com o valor solicitado de ''.

[CORE_E02844] O evento X não está cadastrado para o usuário.

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16476187815959)

CAUSA:**

Mensagem apresentada quando o usuário definido para liberação do evento não possui limite suficiente para tal. 

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16476144635927)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16476187807895)

 Acesse o cadastro do **"Usuário"** responsável pela liberação, selecione: **"Outras Opções", **depois clique em:** "Limites para Liberação"**:

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28450957020567)

 Verifique se para o Evento a ser liberado, o 'Limite' configurado para esse usuário é suficiente para concluir a operação. 

 

![O usuário não possui alçada para o evento com o valor solicitado 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16476144647703)

 

Valide com os responsáveis pela alçada de liberação na empresa, se esse valor deve ser ajustado, seguindo com a liberação após ajustes.  Caso o limite não possa ser aumentado, redefina o usuário liberador para um com alçada suficiente. 

Para redefinir o usuário liberador clique em: "Outras Opções..."/"Ver solicitações de liberação", dentro da Central de Notas, no PopUP Liberações solicitadas, selecione um liberador pelo campo de pesquisa conforme imagem.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/16474179906839)
