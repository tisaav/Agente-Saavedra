# Não é possível enviar a notificação com as solicitações de liberação pois o liberador 'X' não possui e-mail cadastrado

 MENSAGEM:**

[CORE_E03071]:  Não é possível enviar a notificação com as solicitações de liberação pois o liberador ' 'não possui e-mail cadastrado. Verifique se está cadastrado na tela de Destinatários e preencha o campo "e-mail".

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609862844055)

 SOLUÇÃO:**

**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609910024727)

 **Na tela **"Usuários"** selecione o usuário que foi definido como liberador do evento solicitado.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609910025495)

 Na aba **"Identificação"** preencha o campo **"Email p/ solicitação liberação"** com os dados de e-mail do usuário:

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15021407398935)

 

![3 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609862849943)

 Realizado esse cadastro de e-mail, teste o envio de solicitação de liberação de limites novamente.

 

**

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609910027543)

 IMPORTANTE:**

Caso não deseje trabalhar com o envio de solicitações por e-mail, desmarque a opção abaixo para os usuários liberadores.

- Tela 'Usuários' » Outras Opções » Limites para liberação » **Enviar e-mail**

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/15021445412247)

 

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16609910033687)

CAUSA:**

Ao enviar solicitação para liberação de limites, caso não exista e-mail configurado para tal, será apresentada a mensagem.
