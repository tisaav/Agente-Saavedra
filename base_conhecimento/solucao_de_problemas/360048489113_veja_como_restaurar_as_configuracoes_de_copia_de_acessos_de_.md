 Acesse a tela **"Usuários"** (*Caminho de acesso: **Configurações » Controle de Acesso » Usuários*):

- Botão Outras Opções » Restaurar Configurações

- Localize a linha que corresponde a data/horário da configuração de usuário que deseja restaurar.

- Clique em **"Restaurar Configurações"**:

![Marcador 1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/28454040449175)

 Restaurar Configurações:**

Recurso útil para manter históricos de cópias realizadas e/ou restaurar as configurações dos usuários para uma determinada data. Para confirmar se a restauração foi efetuada, acesse o sistema com o usuário que teve os seus acessos originais retornados e confira os acessos.
