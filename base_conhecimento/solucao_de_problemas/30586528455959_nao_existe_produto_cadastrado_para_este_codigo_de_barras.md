 **MENSAGEM:**

Não existe produto cadastrado para este código de barras!

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30586506819095)

SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30591933676055)

 Verifique a informação que está preenchida no campo "**EAN/GTIN Produto p/ NF-e**", aba **"Impostos"** da tela **"Produtos (Cadastro)".** O sistema usa a informação deste campo para o código de barras. 

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/30586528453271)

 

**

![Marcador 1 FINAL.png.png](https://ajuda.sankhya.com.br/hc/article_attachments/30591950331287)

 Exemplo:** se a opção estiver definida como **"Referência"**, é necessário que o campo **"Referência"** na aba **"Geral"** do produto contenha a referência desejada.

 

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/30591933679895)

  Após realizar o ajuste acima, sincronize as configurações com o **Sankhya Checkout**.

Esse processo deve ser feito na tela "**Administração de Checkout" **(*Configurações > Sankhya Checkout > Administração de Checkout)*. Depois, é preciso aguardar a sincronização para o **Sankhya Checkout**.

Quando a sincronização for concluída, um aviso será exibido no ícone correspondente. Para finalizar, selecione a opção **"Atualizar agora"** e a atualização dos dados será iniciada.

CAUSA:**

Mensagem ocorre quando não existe informações no campo próprio seguindo a configuração do campo EAN/GTIN Produto p/ NF-e no cadastro do produto.
