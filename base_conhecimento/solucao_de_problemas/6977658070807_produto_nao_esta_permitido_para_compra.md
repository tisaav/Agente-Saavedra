 MENSAGEM:**

[CORE_E03240] Produto não está permitido para compra.

**

![Causa FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16478315343639)

CAUSA:**

Mensagem apresentada ao tentar lançar item que não está permitido para compra em um lançamento com tipo de movimento compra.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16478270070679)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16478270074263)

 Verifique no cadastro do produto, no aba **"Geral"**, se o campo **"Permite comprar este produto?"** está marcado

- Tela **"Produtos"** *(Caminho de acesso: Configurações » Cadastros » Produtos » Produtos)*

- Aba** "Geral"**

- Campo **"Permite comprar este produto"**

 

![Produto não está permitido para compra 1.png](https://ajuda.sankhya.com.br/hc/article_attachments/16478270080791)

 

Feita a marcação, siga com o lançamento.
