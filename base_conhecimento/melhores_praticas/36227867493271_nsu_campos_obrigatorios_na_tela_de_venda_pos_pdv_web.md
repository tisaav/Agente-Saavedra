# NSU - Campos obrigatórios na tela de venda POS – PDV Web

Ao efetuar uma **venda com cartão POS** no **PDV Web**, é exibida a tela de informações da transação solicitando os dados do cartão, conforme imagem abaixo:

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/36227826028183)

 

Essa obrigatoriedade é controlada pela configuração da tela ''**Tipo de Título''** vinculado à operação.

 

**

![Solução FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36503017257495)

 SOLUÇÃO:**

![1 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36503017259287)

 Acesse a tela ****["Tipos de Título"](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044606494-Tipos-de-T%C3%ADtulo)** **(Financeiro » Arquivos » Cadastros » Tipos de Título).

![2 FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/36503017260567)

 Na aba **''Geral''** verifique a opção** ****“Informar NSU opcional”.**

- 

Quando a opção está **marcada**, o sistema **não exige** o preenchimento do campo NSU, ou seja, ele se torna opcional.

- 

Quando a opção está **desmarcada, **o preenchimento da NSU passa a ser obrigatório durante** **a venda/recebimento no PDV Web.

 

![nsu.png](https://ajuda.sankhya.com.br/hc/article_attachments/36503737164695)
