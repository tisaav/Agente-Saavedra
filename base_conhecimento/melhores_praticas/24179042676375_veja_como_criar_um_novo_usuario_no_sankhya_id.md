# Veja como criar um novo usuário no Sankhya ID

> **Módulo:** Melhores Praticas | **Subseção:** Configurações

Primeiramente, é importante ressaltar que o convite para o cadastro do Sankhya ID deve ser enviado **apenas pelo usuário SUP**. 

Portanto, ao acessar o sistema com as credenciais do usuário SUP, vá para a tela **"Usuários" ***(Caminho: Configurações » Controle de Acesso » Usuários)*, insira o endereço de e-mail a ser vinculado e, em seguida, clique no botão **"Enviar convite"**.

 

![Veja como criar um novo usuário no Sankhya ID.png](https://ajuda.sankhya.com.br/hc/article_attachments/27761864649879)

 

Após o envio do convite, um e-mail é enviado para que você possa completar o seu cadastro. Clique em 'Criar Agora'.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/26398622817303)

 

Preencha as informações solicitadas e, em seguida, escolha uma senha de acesso.

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/26398622820375)

 

Feito isso, faça login no Sankhya Om utilizando os dados do Sankhya ID (E-mail ou CPF).

 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/24179042671639)
