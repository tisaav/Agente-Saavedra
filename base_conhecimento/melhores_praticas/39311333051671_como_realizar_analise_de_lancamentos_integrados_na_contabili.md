O processo de conferência dos lançamentos que foram devidamente integrados ao módulo contábil é essencial para garantir a integridade das informações fiscais e financeiras. Siga as instruções abaixo para extrair o relatório no sistema Sankhya.

### **Passo a passo para extração do relatório**

Para consultar os lançamentos, acesse a tela **"Livro Diário"** (Contabilidade>>Consultas>>Livro Diário):

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/39311333037079)

 Utilize os filtros da tela para selecionar o período contábil desejado e a empresa de referência.
 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/39311333038359)

 Clique no **"Visualizar Relatório"** para gerar a visualização dos dados.
 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/39311343403799)

 Verifique se os registros constam com o status de integrado. Caso identifique alguma divergência, consulte a tela **"Integração Contábil"** (Contabilidade Rotinas Integração Contábil) para validar se houve erro no processo de geração dos lançamentos.
 

### **Melhores práticas na conferência contábil**

Recomenda-se que a conferência seja realizada periodicamente, preferencialmente ao final de cada dia ou semana, para evitar o acúmulo de inconsistências que possam impactar o fechamento mensal.
