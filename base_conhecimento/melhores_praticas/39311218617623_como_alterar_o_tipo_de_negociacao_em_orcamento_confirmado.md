# Como alterar o tipo de negociação em orçamento confirmado?

O sistema Sankhya possui uma **limitação nativa** que impede a alteração do **"Tipo de Negociação"** em pedidos ou orçamentos que já foram confirmados. Esta restrição existe para **garantir a integridade das informações** financeiras e fiscais registradas no sistema.

Quando um orçamento é confirmado, o sistema bloqueia alterações no tipo de negociação para preservar a consistência dos dados. Esta é uma medida de segurança que evita inconsistências em documentos já processados.

 

### **Quando ocorre o bloqueio de alteração**

O bloqueio para alteração do **"Tipo de Negociação"** acontece nas seguintes situações:

- 

Quando o orçamento já foi **confirmado**.

- 

Quando o pedido foi **faturado** parcial ou totalmente.

- 

Quando houve **baixa parcial de provisão** gerada pelo pedido.

- 

Quando a alteração comprometeria a **integridade das informações** do sistema.

 

### **Soluções alternativas disponíveis**

Para contornar esta limitação, considere as seguintes alternativas:

![1](https://ajuda.sankhya.com.br/hc/article_attachments/39311207687575)

**Verificar o status do documento:** confirme se o orçamento realmente está confirmado.

![2](https://ajuda.sankhya.com.br/hc/article_attachments/39311218613271)

**Criar um novo orçamento:** Se for necessário utilizar outro tipo de negociação, crie um novo orçamento com as informações corretas e o **"Tipo de Negociação"** adequado.

![3](https://ajuda.sankhya.com.br/hc/article_attachments/39311218613783)

**Cancelar o orçamento atual:** Se possível e se ainda não houver sido processado completamente, considere o cancelamento do orçamento atual e a criação de um novo com o tipo de negociação correto.

 

### **Recomendações importantes**

Para evitar este tipo de situação, siga estas boas práticas:

- 

**Verifique o tipo de negociação antes de confirmar** o orçamento ou pedido.

- 

Certifique-se de que todas as **informações estão corretas** antes de iniciar o faturamento.

- 

Mantenha o sistema **atualizado** para ter acesso às correções mais recentes.

- 

Documente os **procedimentos internos** para evitar erros de cadastro.

Esta limitação existe para **preservar a consistência das informações financeiras e fiscais**, garantindo a confiabilidade dos dados registrados no sistema.
