O acesso ao cartão é dado pela tela **"Acessos > Configurações > Cartões inteligentes"**.

O cartão apresenta em percentual cada status de ordem de produção da planta e também disponibiliza um link com a tela [Ordens de Produção - Nova](https://ajuda.sankhya.com.br/hc/pt-br/articles/360058023454-Ordens-de-Produ%C3%A7%C3%A3o-Nova) para aprofundar nas informações.

Confira a seguir  as opções disponíveis nos cartões:

- 
**Personalizar:** aqui, você poderá escolher uma ou mais empresas para monitorar;

- 
**Recarregar:** nesta opção, será possível atualizar as informações do cartão;

- 
**Ocultar cartão:** caso não tenha interesse em um determinado cartão, utilize essa opção para ocultá-lo;

- 
**Gerenciamento de acessos:** essa opção é restrita para usuários com acessos avançados;

- 
**Enviar feedback:** utilize essa opção, caso queira registrar alguma opinião, sugestão e/ou dúvidas sobre esse cartão.

Sabendo disso, no cartão inteligente Status OP's, você poderá monitorar os prazos acordados e verificar o percentual de cada status das Ordens de Produção do Plano de Manufatura.
