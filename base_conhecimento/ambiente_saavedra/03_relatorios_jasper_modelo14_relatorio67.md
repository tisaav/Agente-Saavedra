SELECT

## 3. Consulta SQL Blindada do Sub-relatório (`ITENS_PEDIDO_DE_VENDA.jrxml`)

Esta consulta inclui a proteção com `NULLIF` contra divisão por zero e formatação de datas:

```sql
SELECT
    ITE.CODPROD
    , CONCAT(PRO.DESCRPROD, ' | REF: ', PRO.REFFORN, ' | ', ITE.OBSERVACAO) AS DESCRPROD
    , ITE.USOPROD
    , ITE.VLRSUBST
    , ITE.BASESUBSTIT
    , ITE.VLRIPI
    , (CASE
        WHEN VOA.CODPROD IS NULL THEN ITE.QTDNEG
        WHEN VOA.DIVIDEMULTIPLICA = 'D' THEN ITE.QTDNEG * VOA.QUANTIDADE
        ELSE ITE.QTDNEG / NULLIF(VOA.QUANTIDADE, 0)
    END) AS QTDNEG
    , (CASE
        WHEN VOA.CODPROD IS NULL THEN ITE.VLRUNIT
        WHEN VOA.DIVIDEMULTIPLICA = 'D' THEN ITE.VLRUNIT / NULLIF(VOA.QUANTIDADE, 0)
        ELSE ITE.VLRUNIT * VOA.QUANTIDADE
    END) AS VLRUNIT
    , ITE.CODVOL
    , ITE.VLRDESC
    , ITE.QTDNEG * ITE.VLRUNIT AS TOTALITEM
    , ITE.VLRTOT - ITE.VLRDESC + ITE.VLRSUBST AS TOTLIQ
    , CAST(0 AS DECIMAL(10,2)) AS VLRFRETEUNIT
    , PRO.MARCA
    , ITE.SEQUENCIA
    , ITE.VLRICMS
    , PRO.AD_RMS
    , CONVERT(VARCHAR, PRO.AD_DTRMS, 103) AS AD_DTRMS
    , CASE 
        WHEN ITE.CONTROLE IS NOT NULL AND ITE.CONTROLE != '' AND ITE.CONTROLE != ' ' 
        THEN '| LOCAL:' + CAST(ITE.CODLOCALORIG AS CHAR(8)) + ' | LOTE:' + ITE.CONTROLE + ' VAL:'
        ELSE '' 
    END AS CONTROLE
    , (SELECT TOP 1 COALESCE(CODPROPARC, NULL) FROM TGFPAP WHERE CODPARC = CAB.CODPARC AND CODPROD = ITE.CODPROD) AS COD
    , (SELECT TOP 1 COALESCE(DESCRPROPARC, NULL) FROM TGFPAP WHERE CODPARC = CAB.CODPARC AND CODPROD = ITE.CODPROD) AS TIPO
    , ITE.DTINICIO AS PREVENTREGA
    , ITE.CODCFO AS CFOP
FROM TGFITE ITE
INNER JOIN TGFPRO PRO ON (ITE.CODPROD = PRO.CODPROD)
LEFT JOIN TGFVOA VOA ON (
    VOA.CODPROD = ITE.CODPROD 
    AND VOA.CODVOL = ITE.CODVOL 
    AND ((ITE.CONTROLE IS NULL AND VOA.CONTROLE = ' ') OR (ITE.CONTROLE IS NOT NULL AND ITE.CONTROLE = VOA.CONTROLE))
)
INNER JOIN TGFCAB CAB ON (CAB.NUNOTA = ITE.NUNOTA)
WHERE ITE.NUNOTA = $P{NUNOTA} 
  AND ITE.SEQUENCIA > 0
ORDER BY ITE.CODPROD
```

## 4. Parâmetros e Variáveis do JasperReports

### Campos Críticos no XML:
* **CRM:** Deve ser declarado como `<field name="CRM" class="java.lang.String"/>` (nunca como Integer, para suportar pedidos sem CRM preenchido).
* **AD_NUMAFP:** Deve ser declarado como `<field name="AD_NUMAFP" class="java.lang.String"/>`.
* **AD_DTRMS:** Deve ser declarado como `<field name="AD_DTRMS" class="java.lang.String"/>` recebendo a data formatada via SQL.
* **VLRFRETEUNIT:** Tipado como `<field name="VLRFRETEUNIT" class="java.math.BigDecimal"/>`.
