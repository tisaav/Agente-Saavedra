No [Analytics Studio](https://ajuda.sankhya.com.br/hc/pt-br/articles/25648251050647-Analytics-Studio), a configuração de componentes é dividida em três partes principais: **"View (Dados)"**, **"Personalização"** e **"Interações"**. Essas etapas são essenciais para definir o comportamento de cada componente, de acordo com suas necessidades.

### **Área View (Dados)**

A área View é responsável por inserir a consulta que alimentará o componente com dados. Existem três principais opções de configuração para a View:

- **View de SQL:** permite a criação manual de consultas diretamente em SQL, utilizando as tabelas do seu database no Analytics Studio.

- **View de Análise de Dados:** é uma opção no-code do Analytics Studio, que possibilita montar consultas de análise de dados de forma rápida, através da definição de métricas e eixos desejados para visualização.

- **View de Cadastro:** esta opção no-code permite marcar um cadastro e retornar todos os seus atributos automaticamente, facilitando a edição e manipulação do cadastro.

Qualquer uma dessas opções pode ser utilizada para configurar a View conforme as necessidades do componente.

### **Personalização**

A personalização do componente depende do tipo escolhido. O Analytics Studio oferece os seguintes componentes:

- Funil;

- Mapa;

- Pizza;

- Barras;

- Velocímetro;

- Progresso;

- Card;

- Tabela;

- Label;

- Organograma;

- Grupo de Cards;

- Seletor;

- Container;

- Imagem;

- Lista;

- Board;

- Timeline;

- Calendário;

- Abas;

- Stepper;

- Header;

- Formulário;

- Botão;

- Inputs (incluindo input de texto, texto grande, numérico, data, checkbox, radio button, droplist, anexo e input com view).

### **Interações**

As principais interações disponíveis são:

- **Ação**: executa uma ação no-code do Analytics Studio.

- **Ação de Database**: dispara uma interação com o banco de dados escrita em formato DML (INSERT, DELETE, UPDATE).

- **Filtrar outros componentes**: permite filtrar dados em outros componentes com base na interação.

- **Formulário**: exibe um formulário para entrada de dados.

- **Modal de Detalhes**: abre um modal focado na edição de um item com várias possibilidades de personalização.

- **Modal**: exibe um modal personalizado.

Com essas três áreas devidamente configuradas, o componente estará pronto para ser utilizado na aplicação desenvolvida no Analytics Studio.
