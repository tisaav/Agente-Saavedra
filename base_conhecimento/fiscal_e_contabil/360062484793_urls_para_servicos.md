Nesta tela, você poderá cadastrar URL's para o Serviço GNRE.

![urls_para_servi_os.jpg](https://ajuda.sankhya.com.br/hc/article_attachments/360103048253)

Assim, defina o **"Cód. Unidade Federativa"**, o **"Serviço"** e o **"Tipo"** no Painel Principal.

Na aba **"Geral"**, insira as URL's a serem utilizadas nos campos **"URL Produção"** e **"URL Homologação"**.

**Importante:** é preciso cadastrar ao menos uma linha com o código 0 (zero) no campo Cód. Unidade Federativa, pois o sistema interpreta o 0 (zero) como uma configuração para todas as UF's.
