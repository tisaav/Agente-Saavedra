Esta tela possibilita que você configure um modelo de nota que será utilizado como um facilitador para que não seja preciso uma nota em cada movimento realizado.

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360077093074)

No campo **"Modelo NF."** você deverá selecionar o modelo da Nota Fiscal que será utilizado.

Insira no campo **"Descrição"** um nome para o modelo de nota que melhor se encaixa para sua utilização.

Nos campos **"Serviço"**, **"CFOP"** e **"Conta Bancária"** você poderá vincular um [Serviço](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045110553-Servi%C3%A7o), [CFOP](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044600714-CFOP) e [Conta Bancária](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045115113-Contas) que foram previamente cadastrados.

 

**Aba Critério de Conf. Modelo**

Nesta aba você deverá definir um critério para utilização do Modelo de Notas.

**Observação:** o modelo poderá ser selecionado para lançar qualquer nota no sistema, de acordo com o que você configurar nos campos **"Utilizado Para"** e **"Produto"**.

No campo Utilizado Para, você poderá escolher uma das seguintes opções:

- MFD;

- Venda de Lote;

- Avaliação Locação;

- Correspondente Bancário;

- Proposta;

- Venda;

- Avaliação Venda.

Já no campo Produto, temos as opções a seguir:

- Administração;

- Locação;

- Venda de Imóvel;

- Loteamento;

- Corresp. Bancário.
