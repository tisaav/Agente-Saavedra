### 
Painel Principal

Localizado no alto da tela, o Painel Principal reúne os dados que servirão de base para todo o restante do cadastro dos Tipos de Detalhamento.

![mceclip1.png](https://ajuda.sankhya.com.br/hc/article_attachments/360093486173)

O **"Código"** serve como chave vinculadora do Tipo de Detalhamento.

Informe a **"Descrição"** do Tipo de Detalhamento.

Efetue a marcação **"Gera Despesa"** se o Tipo de Detalhamento gerar uma despesa na [Movimentação Financeira](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601874-Movimenta%C3%A7%C3%A3o-Financeira-Atributos-da-Tela).

### 
Aba Geral

![mceclip2.png](https://ajuda.sankhya.com.br/hc/article_attachments/360093487093)

Caso o Tipo de Detalhamento tiver incidência na Taxa de Administração, efetue a marcação **"Incide na tx. adm."**, para que seja calculada no título financeiro quando este for gerado.

Efetue a marcação **"Incide no IRRF"** se o Tipo de Detalhamento incidir no IRRF, para que seja calculado no título financeiro quando este for gerado.

Se o Tipo de Detalhamento tiver a incidência de juros e multas, efetue a marcação **"Incide em juros e multa"**.

No campo **"Recebe de"**, selecione quem é o pagador da despesa e no campo **"Repassa para"** informe quem receberá.

Efetue a marcação **"Garantido"** para que seja garantido o recebimento ou pagamento.

Caso o Tipo de Detalhamento tiver incidência na Taxa mínima de Administração, efetue a marcação **"Incide tx. mínima adm."**, para que seja calculada no título financeiro quando este for gerado.

Aba Financeiro

Nesta aba, você seleciona a **"Natureza"** já cadastrada para o Tipo de Detalhamento, para que possam ser gerados os relatórios referente ao detalhamento ou ao grupo.

### 
Aba Loteamento

![mceclip5.png](https://ajuda.sankhya.com.br/hc/article_attachments/360093489593)

Habilite a marcação **"Incide Valor Principal"** caso o detalhamento tenha incidência no valor principal do lote.

Caso o detalhamento tenha incidência no FPP, efetue a marcação **"Incide no FPP?"**, para que este seja calculado no título que o esteja gerando.
