Nesta tela, você cadastra os Tipos de Imóveis que serão vinculados na tela de [Imóveis](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044608914-Im%C3%B3veis), podendo também, controlar o Tipo de Imóvel que será apresentado nos Portais Web, caso seja necessário.

![mceclip3.png](https://ajuda.sankhya.com.br/hc/article_attachments/360091325014)

Informe a **"Descrição"** que se enquadre no Tipo do Imóvel.

No campo **"Tipo do Imóvel"**, selecione a opção do Tipo do Imóvel que melhor se enquadra para o controle interno.

Efetue a marcação **"Exige Seguro Incêndio"** se o Tipo do Imóvel exige o seguro de incêndio. O sistema validará essa informação no [Contrato de Locação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045117213-Contrato-de-Loca%C3%A7%C3%A3o) para exigir o seguro antes de gerar os aluguéis.

Caso o Tipo de Imóvel possua integração com os Portais Web (Viva Real, ZAPImóveis / OLX, Wimoveis / Imovelweb, Cliquei Mudei), selecione na aba **"Portais Web"**, o tipo no qual será realizada a integração para que, no momento do controle, fique simplificado e adequado à integração personalizada.
