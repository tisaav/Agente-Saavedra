Esta rotina permite o cadastro de Grupos de Produção analíticos e sintéticos. Grupo sintético é um grupo que contém outros grupos, ou seja, grupos filhos. Para um grupo ser sintético, basta cadastrá-lo com a marcação **"Analítico"** desabilitada.

![gp1.png](https://ajuda.sankhya.com.br/hc/article_attachments/8839322858007)

A tela possui os seguintes campos:

**Código:** informe o código do grupo de produção.

**Descrição:** neste campo, realize o preenchimento do nome do grupo de produção.

**Ativo:** esta marcação indica se o grupo esta ativo ou inativo.

**Analítico:** quando marcada, significa que o grupo é analítico; por outro lado, quando desmarcada significa que o grupo é sintético.

**Estrutura de Produção:** produtos pertencentes ao mesmo Grupo de Produção devem compartilhar a mesma estrutura de produção, desta forma, efetue o preenchimento deste campo, de modo a definir a qual Estrutura de Produção o grupo pertence. As estruturas de produção são cadastradas previamente na tela [Estrutura de Produção](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044611034). Este campo está envolvido no processo apresentado no link [Compartilhamento de OP's entre Planejamentos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044601754).

A aba **"Produtos" **apresenta todos os produtos associados ao grupo.
