# Como cadastrar um vínculo de pessoa jurídica (PJ)?

> **Módulo:** Pessoas+ | **Subseção:** Vínculos Específicos do Colaborador  
> **Fonte Oficial:** [https://ajuda.sankhya.com.br/hc/pt-br/articles/7108064062359-Como-cadastrar-um-v%C3%ADnculo-de-pessoa-jur%C3%ADdica-PJ](https://ajuda.sankhya.com.br/hc/pt-br/articles/7108064062359-Como-cadastrar-um-v%C3%ADnculo-de-pessoa-jur%C3%ADdica-PJ)

Algumas empresas possuem como apoio na execução das rotinas trabalhistas, a assistência de um escritório de contabilidade ou profissional que registra e suporta todos os encargos para execução de um serviço.

Pensando nisso, foi criada uma rotina no módulo Pessoal+ para permitir que esses usuários, de regime de trabalho Pessoa Jurídica (PJ) possam ter acesso ao sistema de forma controlada, ou seja, apenas nas atividades que realmente façam parte de suas atribuições pré-contratadas.

![vinculo-pj.png](https://ajuda.sankhya.com.br/hc/article_attachments/33322658334999)

Como sabemos, o Pessoal+ foi desenhado por meio de personas, sendo uma delas, o Departamento Pessoal (DP), que é o responsável pelas rotinas trabalhistas no sistema. Assim sendo, para definir um usuário com esta persona, é necessário cadastrá-lo como funcionário da empresa. Como o usuário PJ não faz parte do quadro de funcionários da organização, entende-se a necessidade de se criar uma tela exclusiva para fazer a inclusão e indicação de que esse profissional será o responsável pelas rotinas da folha de pagamento. Dessa forma, antes de cadastrar um PJ nesta tela é necessário criar o seu usuário.

Então, primeiramente, acesse a tela [Usuários](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044597874-Usu%C3%A1rios) e clique no botão 

![Botão Novo FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16593501909399)

 **"Cadastrar Usuário"**. Informe o **"Nome"** e a sua **"Senha"**, que serão os mesmos para acessar o sistema posteriormente. Preencha os campos obrigatórios destacados com (*****) e caso você deseje, também é possível inserir uma foto para esse usuário. Clique em** "Salvar"**.

![usu.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119252699543)

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16593501916695)

 Cada usuário pode estar vinculado a apenas um cadastro PJ por vez.

Após isso, acesse a tela **Vínculo PJ** para fazer o vínculo desse usuário e clique no botão 

![Novo](https://ajuda.sankhya.com.br/hc/article_attachments/15496932918807)

 **"Adicionar Vínculo"**.

![vinculo.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119255737239)

Preencha os dados do usuário PJ anteriormente cadastrado na tela Usuários; **"Nome"**, **"CPF"**, **"Data Nascimento"**, **"Sexo"**, **"Código Usuário"** e a **"Data de Início" **da prestação de serviços. 

O campo** "Data do Fim"** só deverá ser preenchido quando finalizar o contrato entre a empresa e prestador, mesmo que já esteja pré-definida a data de encerramento.

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16593501916695)

O cadastro de PJ não cabe apenas para profissionais de outras empresas que realizam as suas rotinas de folha de pagamento. Também pode ser usado para funcionários internos, contratados pela empresa para gerir alguma outra área.

Os campos **"Código da Empresa"** e **"Código do Departamento"** deverão ser preenchidos com os dados da empresa para a qual ele está prestando serviços, ou seja, a empresa em que executará as atividades. Por exemplo, a empresa **"Contabilidade X"** faz a folha de pagamento da Sankhya, então no campo Empresa, indica-se a Sankhya.

Se esse usuário for executar as rotinas de Departamento Pessoal, lembre-se ainda de efetuar a marcação **"Pertence ao DP/RH" **e realizar a liberação das telas de atuação no sistema para realização dos procedimentos na tela Acessos.

Ainda é preciso informar os dados de contato desse usuário, como o **"Telefone"** e **"E-mail"**. Caso deseje cadastrar algum dado adicional, utilize o campo** "Observação"**.

Aqui também é possível fazer a inclusão de uma foto do vinculado PJ:

![vinculo2.png](https://ajuda.sankhya.com.br/hc/article_attachments/7119345473175)

Após salvar, o sistema retornará para a tela principal, apresentando o card com o novo PJ cadastrado:

![vinculo3.png](https://ajuda.sankhya.com.br/hc/article_attachments/7119317027223)

Caso deseje cadastrar novos Vínculos PJ, basta repetir o processo.

**Observação:**** **verifique na tela de [Parceiros](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044594494-Cadastro-de-Parceiros) se esse PJ está cadastrado como parceiro da empresa, para maior controle dos associados.

Após isso, será necessário incluir esse usuário PJ também a um Grupo de Decisores. Para isso, acesse a tela Painel de Configurações e clique no menu [Grupos de Decisores](https://ajuda.sankhya.com.br/hc/pt-br/articles/14999187265559-Painel-de-Configura%C3%A7%C3%B5es#gruposdedecisores). Adicione o usuário a um grupo de decisor, mas caso não exista esse grupo, realize a inclusão, clicando em **"Adicionar novo grupo"** e, no campo **"Grupo de decisores"** informe uma descrição que identifique esse grupo:

![decisores.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119371088279)

![Atenção FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16593501916695)

 Lembre-se de indicar a **"Empresa"** para a qual ele executará as atividades:

![decisores2.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119405148055)

Após criar o grupo e vincular o usuário, faça a [Configuração de permissões](https://ajuda.sankhya.com.br/hc/pt-br/articles/14999187265559-Painel-de-Configura%C3%A7%C3%B5es#Configura%C3%A7%C3%A3odepermiss%C3%B5es). Assim, considere que para esse usuário serão liberados todos os** "Cálculos"**, então, selecione o card correspondente a tela [Cálculos](https://ajuda.sankhya.com.br/hc/pt-br/articles/20441795691031) e [Gerenciador de Folhas](https://ajuda.sankhya.com.br/hc/pt-br/articles/4424800696599), respectivamente.

![config.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119408771095)

Ative a liberação para todos os tipos de cálculos, utilizando a opção **"Selecionar todas"** e, em seguida, salve-as:

![config2.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119431101463)

Faça esse mesmo procedimento para as demais rotinas que o usuário executará como atividades no Pessoal+.

Para outros procedimentos e processos em que o usuário necessite de permissão, como, por exemplo, iniciar ou aprovar uma requisição, acesse o menu [Configuração de processos](https://ajuda.sankhya.com.br/hc/pt-br/articles/14999187265559-Painel-de-Configura%C3%A7%C3%B5es#Configura%C3%A7%C3%A3odeprocessos) desse painel, para a liberação ou bloqueio de acesso a recursos do Pessoal+:

![config3.png](https://ajuda.sankhya.com.br/hc/article_attachments/7119464126999)

Caso o seu usuário PJ seja líder de algum funcionário da empresa, é possível também fazer o relacionamento entre usuários. Para isso, acesse a tela [Acessos Pessoal Mais](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044610574), selecione o funcionário e acione o botão 

![atribuir.png](https://ajuda.sankhya.com.br/hc/article_attachments/7119467257495)

 **"Atribuir/Remover Líder"** como demonstrado abaixo:

![acessos.gif](https://ajuda.sankhya.com.br/hc/article_attachments/7119470113303)

Pronto! O usuário PJ será o gestor de um funcionário interno da empresa e poderá fazer requisições e aprovações para o mesmo.       

```text
                                      
O cadastro de Vínculo PJ no Pessoal+ será apenas para fazer a gestão da folha 
de pagamento e liderança, portanto, não é possível ainda realizar cálculo de 
uma folha PJ, pois se entende que ele não pertence ao quadro de funcionários 
da empresa.          
```
