# Cadastro de Feriados

> **Fonte Oficial:** [https://ajuda.sankhya.com.br/hc/pt-br/articles/14046499261719-Cadastro-de-Feriados](https://ajuda.sankhya.com.br/hc/pt-br/articles/14046499261719-Cadastro-de-Feriados)

```text
 Módulo: Pessoal+ > Cadastros
```

Esta tela permite o lançamento dos dias que o sistema irá considerar como feriado. Este cadastro é importante, pois impacta nos cálculos dos descansos semanais remunerados.

![Feriados.png](https://ajuda.sankhya.com.br/hc/article_attachments/18745177751447)

Inicie o cadastro, acionando o botão 

![Botão Novo FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/16590229220887)

 **"Cadastrar Feriado"** e preencha os dados abaixo:

Defina o **"Tipo"** de categoria do feriado, se é **"Municipal"**, **"Estadual"**, **"Nacional"** ou **"Internacional"**.

Selecione o **"País"**, **"Estado" **e **"Cidade"** conforme o Tipo definido.

Informe também a **"Data do feriado"**, e o nome deste no campo **"Descrição"**.

### **Aba Geral**

A marcação **"Obrigatório"** indica se o feriado é ou não ponto facultativo.

Quando um feriado acontece todo ano, deve-se efetuar a marcação **"Recorrente"** para deixá-lo cadastrado para cada ano.

A marcação **"Usar no Ponto/Pessoal"** aponta a data como feriado no extrato de ponto.

Finalizado o cadastro, clique em 

![botão Salvar.FINAL.jpg](https://ajuda.sankhya.com.br/hc/article_attachments/23967347694871)

 **"Salvar [F7]"**.

**Nota:** com o parâmetro **"Considerar Feriado no DSR? - FPFERDSR"** desligado, caso o funcionário tenha alguma falta no mês que tenha feriado, será incluído no cálculo da folha o desconto de DSR. Por exemplo, se o funcionário faltar em 14/11, e 15/11 for um feriado nacional, o sistema descontará 2 dias de DSR.

Se estiver ligado, os feriados são desconsiderados no cálculo do DSR; o sistema descontará apenas 1 dias de DSR correspondente ao dia de falta.
