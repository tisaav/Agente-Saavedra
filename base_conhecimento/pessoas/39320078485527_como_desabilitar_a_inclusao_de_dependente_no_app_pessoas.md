# Como desabilitar a inclusão de dependente no app Pessoas+?

> **Módulo:** Pessoas+ | **Subseção:** App Pessoas+

Este artigo orienta sobre como desabilitar a funcionalidade que permite aos funcionários incluírem dependentes através do aplicativo Pessoal+.

 

### **Passo a passo para desabilitar a inclusão de dependente**

Para desabilitar a **"Inclusão de Dependente"** para o funcionário no aplicativo Pessoal+, siga os passos abaixo:

 

![1](https://ajuda.sankhya.com.br/hc/article_attachments/39320109823639)

 Acesse a tela **"Painel de Configurações"** (Pessoal+ Configurações).

![2](https://ajuda.sankhya.com.br/hc/article_attachments/39320109824535)

 Clique na opção **"Configuração de Processos"**.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/41329619058071)

 

![3](https://ajuda.sankhya.com.br/hc/article_attachments/39320109825815)

 Localize a opção **"Inclusão de Dependente"** na lista de processos disponíveis.

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/41329619058967)

![4](https://ajuda.sankhya.com.br/hc/article_attachments/39320078477847)

 Na seção **"Quem pode iniciar o processo"**, desabilite a opção **"Funcionário"** em todos os grupos de acesso existentes.
 

![Imagem](https://ajuda.sankhya.com.br/hc/article_attachments/41329619061015)

![5](https://ajuda.sankhya.com.br/hc/article_attachments/39320109828119)

 Salve as alterações realizadas.
 

 

### **Resultado da configuração**

Após realizar esta configuração, os funcionários não terão mais permissão para iniciar o processo de inclusão de dependentes através do aplicativo Pessoal+. Apenas os usuários com perfis administrativos configurados poderão realizar esta operação através do sistema.

 

**Observação:** Esta configuração afeta todos os funcionários da empresa. Caso seja necessário permitir que apenas alguns grupos específicos tenham acesso, configure as permissões individualmente por grupo de acesso seguindo o passa a passo do artigo ****[Painel de Configurações](https://ajuda.sankhya.com.br/hc/pt-br/articles/14999187265559-Painel-de-Configura%C3%A7%C3%B5es#gruposdedecisores).
