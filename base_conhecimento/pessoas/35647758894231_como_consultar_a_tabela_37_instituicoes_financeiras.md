# Como consultar a Tabela 37 – Instituições Financeiras?

A **Tabela 37 do eSocial** reúne os códigos oficiais das **instituições financeiras** autorizadas a realizar operações de empréstimo eConsignado **(Crédito do Trabalhador)**.

O uso do código correto da instituição é obrigatório ao enviar eventos ao eSocial que contenham rubricas de desconto consignado. Caso o código informado não exista na Tabela 37, o envio será rejeitado pelo sistema do eSocial.

### **Passo a Passo**

1. Acesse o site oficial de administração e consulta pública das [Tabelas do eSocial](https://www.gov.br/esocial/pt-br/tabelas-do-esocial) e, no menu, selecione a opção Tabelas do eSocial → Consulta tabelas do eSocial.

![tabela-37-esocial.gif](https://ajuda.sankhya.com.br/hc/article_attachments/35648178800791)

2. Localize a **Tabela 37 – Instituições Financeiras para o Empréstimo Consignado** e clique sobre ela para selecioná-la.

![selecao-tabela37-esocial.png](https://ajuda.sankhya.com.br/hc/article_attachments/35648508694807)

3. Escolha entre **Consultar** online ou **Baixar** o conteúdo.

Os códigos das instituições são disponibilizados pela DATAPREV e são os únicos aceitos pelo eSocial para envio de informações sobre crédito consignado.

#### **Pontos de Atenção**

- Utilize exatamente os códigos fornecidos pelo Portal Emprega Brasil.

- Não altere os códigos ao enviar eventos ao eSocial, pois o sistema cruza automaticamente as informações declaradas pelo empregador com os dados do empréstimo consignado previamente registrados.

- 

Além de usar o código certo, confira se o cadastro do banco no sistema está correto — ou seja, se o código está associado à instituição financeira certa. 

Um cadastro com o código correto, mas vinculado à descrição de outra instituição, não é identificado como erro pelo eSocial (o código existe na Tabela 37 e o envio é aceito normalmente).
