# Como liberar o acesso ao app Pessoas+ para os funcionários?

> **Módulo:** Pessoas+ | **Subseção:** App Pessoas+  
> **Fonte Oficial:** [https://ajuda.sankhya.com.br/hc/pt-br/articles/18895816234391-Como-liberar-o-acesso-ao-app-Pessoas-para-os-funcion%C3%A1rios](https://ajuda.sankhya.com.br/hc/pt-br/articles/18895816234391-Como-liberar-o-acesso-ao-app-Pessoas-para-os-funcion%C3%A1rios)  
> **ID:** `18895816234391` | **Última Atualização:** 2026-09-27T20:22:55Z

---

Para liberar o acesso ao aplicativo pessoas + para os funcionários, precisamos liberar dentro do sistema o acesso ao portal RH. Porém não são todos os funcionários que possuem acesso ao sistema. 

Para o colaborador acessar o aplicativo do Pessoas + é necessário ter um Usuário do Sankhya OM cadastrado.

Esse usuário  é cadastrado na tela de **Usuários** *(Configurações » Controle de Acesso » Usuários)*, pois, é vinculado ao funcionário em questão e os acessos dos colaboradores são liberados na tela de "Acessos Pessoal Mais".
