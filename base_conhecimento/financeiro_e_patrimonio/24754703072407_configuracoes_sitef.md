 Para visualizar esta tela, é necessário configurar o parâmetro** "Gateway de recebimento com cartão (TEF) - TEFGATEWAY"** como **"Sitef"**.

Ao clicar no botão 

![Botão Configrações Final.png](https://ajuda.sankhya.com.br/hc/article_attachments/24756105485463)

 **"Configurações"**, esta tela possibilita o acesso ao** "TEF Admin"** do** "Client Modular"** do Sitef, para configurar detalhes específicos no terminal. 

![Cliente Modular.png](https://ajuda.sankhya.com.br/hc/article_attachments/24756088830871)

Este recurso também está disponível na tela [PDV Web](https://ajuda.sankhya.com.br/hc/pt-br/articles/8046603009047-PDV-Web) para facilitar a configuração e o gerenciamento do terminal.

**Compatibilidade do Client SiTef:** Para garantir o correto funcionamento e o registro completo das transações, é crucial que o **Client SiTef (SiTef PDV CliSitef)** esteja na versão **V1.2.0.53**. Versões anteriores, como a **V1.2.0.52**, podem apresentar problemas no preenchimento do código de autorização em transações TEF.

**Importante:** se houver problemas com o cliente modular, é recomendado acionar o suporte da integração TEF Sitef.
