**Importante:** Para ter acesso a essa tela, você deve possuir a licença para o produto **30638 - Incorporadoras/W**.

Para iniciar o processo de Recebimento de títulos, você deve, primeiramente, cadastrar as moedas e fórmulas utilizadas pela construtora na tela [Valores de Moedas](https://ajuda.sankhya.com.br/hc/pt-br/articles/360044604754-Valores-de-Moedas).

A solução permite a configuração de várias fórmulas de cálculo para os reajustes, estas fórmulas são cadastradas na tela Fórmulas para Cálculo Civil. 

Na imagem abaixo, temos um exemplo da fórmula de reajuste do CUB:

![mceclip0.png](https://ajuda.sankhya.com.br/hc/article_attachments/360083068654)

**Nota:** As fórmulas básicas são cadastradas na implantação, mas podem ser criadas outras fórmulas caso o implementador seja certificado.

**Importante:** Para o reajuste das parcelas, utilize a tela [Cálculo Prestação](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045113853-C%C3%A1lculo-Presta%C3%A7%C3%A3o). Para a alteração de fórmulas de reajuste, acesse [Atualização de Fórmula e Moeda](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045113873-Atualiza%C3%A7%C3%A3o-de-F%C3%B3rmula-e-Moeda).
