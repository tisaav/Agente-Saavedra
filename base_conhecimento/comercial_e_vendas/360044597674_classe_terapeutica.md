Através desta tela pode-se cadastrar a classe terapêutica de cada medicamento, ou seja, em qual classificação se enquadra a finalidade do medicamento. Para que esta tela esteja disponível para configuração, o parâmetro **"Habilitar Aba de Medicamentos no Cad Produto? - MEDICAMENTOS"** deve estar ligado.
