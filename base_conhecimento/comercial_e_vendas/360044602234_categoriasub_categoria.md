Esta tela permite o cadastramento da classe a qual o medicamento pertence, ou seja, se o medicamento possui marca, é genérico ou ainda um similar. 

Tem-se como exemplo o Maleato de Enalapril (princípio ativo) que possui como genérico o Enalapril e similares os Enaprotec, Glioten, Pressel, Vasopril, entre outros.

Essa tela estará disponível para configuração, quando o parâmetro **"Habilitar Aba de Medicamentos no Cad Produto? - MEDICAMENTOS"** encontrar-se habilitado.

![Categoria-sub-categoria.png](https://ajuda.sankhya.com.br/hc/article_attachments/22040588924439)

Para inserir uma nova categoria, acione o botão 

![Botão Novo FINAL.png](https://ajuda.sankhya.com.br/hc/article_attachments/22343407930647)

 **"Cadastrar categoria do medicamento"** e faça a sua **"Descrição"**. 

O campo **"Código"** pode ser preenchido de forma automática pelo sistema ou de forma manual, dependendo da configuração realizada no botão 

![botão-configuração-da-tela-FINAL.jpg](https://ajuda.sankhya.com.br/hc/article_attachments/22343424788631)

 **"Configuração da Tela"**, opção **"Numeração"**.

Já, o **"Cód. Usuário"** será preenchido automaticamente com o código do usuário que realizou o cadastro.

Na aba **"Sub-Categoria Medicamento"**, deve-se inserir no campo **"Descrição"** o nome da sub-categoria desse medicamento.

Acesse no [Cadastro de Produtos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Produtos-), a aba [Medicamentos](https://ajuda.sankhya.com.br/hc/pt-br/articles/360045112113-Produtos-#abamedicamentos) para conhecer os produtos identificados como medicamentos.
